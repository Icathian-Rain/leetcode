- 适用条件：题目要求按顺序处理字符或操作，并且当前操作会依赖、撤销或比较最近的有效状态。
- 核心骨架：维护一个“有效历史”结构；普通状态进入历史，特殊操作回退或合并最近状态；每一步都保证历史结构只保存仍然有效的内容。
- 关键边界：空历史时不能继续回退或匹配；处理结束后要检查是否还有未匹配状态；如果需要比较结果，要区分“有效长度”和原始容器长度。

```cpp
class Solution {
public:
    bool historyRollbackTemplate(string s) {
        vector<char> history;

        for (char ch : s) {
            if (/* ch 是普通状态 */) {
                history.push_back(ch);
            } else if (/* ch 要撤销最近状态 */) {
                if (!history.empty()) {
                    history.pop_back();
                }
            } else {
                // 根据题目要求处理匹配、合并或非法状态。
            }
        }

        return history.empty();
    }
};
```

- 复杂度：时间通常为 `O(n)` 或 `O(L)`，其中 `L` 是输出长度；空间通常为 `O(n)` 或 `O(L)`，取决于保存的上下文和输出规模。

```cpp
class Solution {
public:
    string nestedContextTemplate(string input) {
        vector<string> outerContexts;
        string current;

        for (char ch : input) {
            if (/* 进入新层 */) {
                outerContexts.push_back(current);
                current.clear();
            } else if (/* 退出当前层 */) {
                string finished = current;
                current = outerContexts.back();
                outerContexts.pop_back();
                current += finished;
            } else {
                // 普通 token 更新当前层状态。
                current.push_back(ch);
            }
        }

        return current;
    }
};
```

### 通用解题模板

- 适用条件：题目围绕括号合法性提问，但目标不只是判断真假，而是要求补齐数量、删除位置或最长合法片段。
- 核心骨架：先明确输出目标；只要数量时维护计数即可，需要构造结果时保存下标，需要最长片段时保存边界位置；遇到非法右括号时立即结算或更新边界，剩余左括号最后处理。
- 关键边界：开头非法右括号、结尾剩余左括号、从下标 `0` 开始的合法片段、非括号字符保留规则，都要单独检查。
- 复杂度：时间通常为 `O(n)`；空间从 `O(1)` 到 `O(n)`，取决于是否需要保存下标或构造结果。

```cpp
class Solution {
public:
    int parenthesesStateTemplate(string s) {
        int unmatchedLeft = 0;
        int answer = 0;

        for (char ch : s) {
            if (ch == '(') {
                ++unmatchedLeft;
            } else if (ch == ')') {
                if (unmatchedLeft > 0) {
                    --unmatchedLeft;
                } else {
                    // 当前右括号无法匹配：根据题目目标补数量、标记删除或更新边界。
                    ++answer;
                }
            }
        }

        // 剩余左括号也需要根据题目目标结算。
        return answer + unmatchedLeft;
    }
};
```

- 核心骨架：维护一组尚未找到答案的候选；当前元素如果能解决栈顶候选，就持续弹出并回填答案；无法解决的当前元素加入等待集合。
- 关键边界：严格更大时相等不能结算；环形数组通常扫描两轮但每个下标只需要入栈一次；答案需要距离、天数或位置时，栈里保存下标而不是值。
- 复杂度：时间 `O(n)`，空间 `O(n)`；每个元素最多入栈、出栈一次。

```cpp
class Solution {
public:
    vector<int> nextGreaterTemplate(vector<int>& nums) {
        vector<int> ans(nums.size(), -1);
        vector<int> waitingIndexes;

        for (int i = 0; i < (int)nums.size(); ++i) {
            while (!waitingIndexes.empty() && nums[waitingIndexes.back()] < nums[i]) {
                int previous = waitingIndexes.back();
                waitingIndexes.pop_back();
                // 如果题目要返回值，写 nums[i]；如果要距离，写 i - previous。
                ans[previous] = nums[i];
            }
            waitingIndexes.push_back(i);
        }

        return ans;
    }
};
```
