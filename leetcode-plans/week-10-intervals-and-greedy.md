# 第 10 周 - 区间与贪心

## 本周目标

本周训练排序后的区间处理和局部选择证明。你需要从“看起来可以贪”推进到“为什么这个局部选择不会破坏全局答案”。到本周结束时，你应该能说清排序依据、当前维护的边界、何时合并、何时丢弃、何时扩张，以及局部决策背后的不变量。

## 与前面主题衔接

区间题会复用数组排序、双指针扫描和二分边界意识；贪心题会复用动态规划里的“状态是否真的需要保留”。如果一个题能用局部变量表达足够信息，就不必上完整 DP。本周重点是学会为这种简化给出理由。

## 前置知识

- 能按左端点、右端点、结束位置或事件时间排序。
- 能区分合并区间、选择区间、删除区间和插入区间。
- 能用一个变量维护当前最远、当前结尾或当前剩余能力。
- 能解释为什么某个局部选择更安全。
- 能识别需要排序后再扫描的题面信号。

### 通用解题模板

- 适用条件：沿左端点有序处理闭区间，需要把相交区间合并为互不重叠的覆盖段。56 先排序；57 原列表已有序且互不重叠，只需围绕新区间处理。
- 核心骨架：维护当前覆盖段。下一段严格位于右侧时，当前段可定稿；否则扩张右端点。排序或输入顺序保证后续区间不可能回头连接更早的已定稿段。
- 关键边界：闭区间 `nextLeft <= currentRight` 视为相交；包含关系用 `max` 避免右边界缩小；显式维护当前段时不要漏掉末尾输出。57 第一段用严格 `<`，左右端点均需更新。
- 复杂度：已排序后的扫描为时间 `O(n)`；下方骨架不计返回结果为 `O(1)` 辅助空间，含结果 `O(n)`。56 加上排序后时间 `O(n log n)`、常见排序栈 `O(log n)`；57 直接扫描为时间 `O(n)`、辅助空间 `O(1)`。

```cpp
class Solution {
public:
    // 前提：输入已按左端点非递减排列；无序输入需先排序。
    vector<vector<int>> mergeSorted(const vector<vector<int>>& ordered) {
        vector<vector<int>> result;
        for (const auto& interval : ordered) {
            if (result.empty() || result.back()[1] < interval[0]) {
                result.push_back(interval);
            } else {
                // 只有最后一段仍可能扩张，端点相等也需要合并。
                result.back()[1] = max(result.back()[1], interval[1]);
            }
        }
        return result;
    }
};
```

该骨架用于概括今日共同模式。57 的专用三段写法可直接复用输入顺序，无需为了套骨架重新排序。

### 通用解题模板

- 适用条件：区间之间需要做“保留/丢弃/分组”决策，且决策只依赖一个随扫描单调推进的边界值。排序后每个新区间只与这个边界比较一次，无需回退。
- 核心骨架：选定排序键（左端点或右端点，取决于哪一端决定“安全”），一趟扫描维护一个边界变量；新区间越过边界时计数并推进边界，否则按题意收缩边界或直接跳过。
- 关键边界：比较符由端点语义决定——端点相接算重叠时用 `>` 判新组，不算重叠时用 `>=`；同起点排序时按另一端降序可让长区间先出现；比较器只用 `<`，避免极端坐标相减溢出；首区间直接计入答案，依赖 `n >= 1` 的约束。
- 复杂度：时间 `O(n log n)`，空间 `O(log n)`（排序栈，不计输入）。

```cpp
class Solution {
public:
    // 前提：按题意选定排序键与比较符；boundary 的含义由排序方向决定。
    int intervalScanExample(vector<vector<int>>& intervals) {
        sort(intervals.begin(), intervals.end(), [](const vector<int>& a, const vector<int>& b) {
            return a[1] < b[1]; // 以右端点为例；比较器只用 <，防溢出
        });
        int ans = 1;
        int boundary = intervals[0][1]; // 当前决策边界，随扫描单调推进
        for (int i = 1; i < static_cast<int>(intervals.size()); i++) {
            if (intervals[i][0] >= boundary) { // 比较符按端点语义调整
                ans++;
                boundary = intervals[i][1];
            }
        }
        return ans;
    }
};
```

该骨架概括今日三题的共同形态：435 与 452 直接同构（只差一个比较符），1288 把边界换成“历史最大右端点”并统计被覆盖对象。

### 通用解题模板

- 适用条件：需要沿一个方向逐步推进，且每一步“能推进到哪里”只依赖一个随扫描单调不减的边界值。不涉及排序，边界由当前位置的候选对象（跳跃力、覆盖范围）在线扩张。
- 核心骨架：维护“当前层边界”与“本层候选能延伸到的最远处”两个变量。扫描每个位置时先收集候选扩张最远值；走到层边界时结算一次（计数加一，层边界推进到最远值）。
- 关键边界：判定“能否推进”时比较当前位置与最远值（相等即卡死或出现空隙）；计数题中终点位置不再触发新一次结算（循环扫到 `n-2` 或用提前出口）；候选为 0 时最远值不延伸，依赖初始化表达“只覆盖自身”。
- 复杂度：时间 `O(n)`，空间 `O(1)`；若需要先把对象转成“每个位置的最远延伸”则增加 `O(n)` 空间。

```cpp
class Solution {
public:
    // 前提：reach[i] 表示从位置 i 出发能延伸到的最远处（跳跃题即 i+nums[i]，覆盖题需预处理）。
    int boundaryAdvanceExample(int n, const vector<int>& reach) {
        int ans = 0;
        int far = 0;       // 本层候选能延伸到的最远处
        int boundary = 0;  // 已结算 ans 次后恰好推进到的位置
        for (int i = 0; i < n; i++) {
            far = max(far, reach[i]);
            if (far <= i) return -1; // 推进中断：出现无法覆盖/到达的空隙
            if (i == boundary) {     // 走到层边界，结算一次
                ans++;
                boundary = far;
                if (boundary >= n - 1) break; // 已能到达终点，提前结束
            }
        }
        return ans;
    }
};
```

该骨架概括今日三题的共同形态：55 只用“最远值”判定可达；45 加层边界结算次数；1326 先把区间覆盖预处理成“每个位置的最远延伸”再复用同一骨架。

class Solution {
public:
    // 前提：canPop 组装本题的弹出条件；postProcess 处理扫描后的收尾。
    string monotonicStackExample(const string& input) {
        string stk; // 栈内即已选前缀
        for (char c : input) {
            // 弹出条件由题意组装：更大/更小、之后还会出现、配额未用尽
            while (!stk.empty() && stk.back() > c /* && 其他约束 */) {
                stk.pop_back();
            }
            stk.push_back(c);
        }

    }

- 适用条件：全局可行性可以拆成“局部动作 + 一句不损失最优性的理由”。局部动作要么是“能放就放/能给就给”，要么是“失败时整体排除一段候选”，要么是“从当前最小对象开始消耗”。

class Solution {
public:
    // 前提：check(i) 是局部合法判断；act(i) 后推进方式由题意决定（跳格/跳段/消耗组）。
    int localFeasibilityExample(vector<int>& items) {
        int total = 0; // 全局累计量，用于最终充要判定
        for (int i = 0; i < static_cast<int>(items.size()); ) {
            if (check(items, i)) {
                total++;
                i += 2;  // 动作后推进：本例动作使下一格必然不可用
            } else {
                i++;
            }
        }
        return total;
    }
};

### 通用解题模板

- 适用条件：多个区间同时存在，需要知道“每一时刻有多少个/多少量在进行中”，或判断瞬时量是否超过上限。区间端点即事件：进入带来增量，离开带来减量。
- 核心骨架：把每个区间拆成进入/离开两个事件，按时间排序后扫描；维护当前瞬时量，按题意取历史峰值或与上限比较。同一时刻的次序由端点语义决定（通常先离开后进入，让相接的区间可复用资源）。
- 关键边界：同刻事件次序要与端点语义一致（半开区间先减后加；若相接算冲突则先加后减）；峰值只可能出现在进入事件后；事件变化量可从 ±1 推广到任意权重；值域已知且小时可用差分数组替代事件排序。
- 复杂度：事件排序版时间 `O(n log n)`、空间 `O(n)`；差分版时间 `O(n + T)`、空间 `O(T)`（`T` 为值域上界）。

```cpp
class Solution {
public:
    // 前提：每个区间 [start, end) 带权重 w；needPeak 为 true 时求峰值，false 时与 limit 比较。
    int eventScanExample(vector<vector<int>>& intervals, int limit, bool needPeak) {
        vector<pair<int, int>> events; // {时刻, 变化量}
        for (const auto& iv : intervals) {
            events.push_back({iv[0], 1});  // 进入
            events.push_back({iv[1], -1}); // 离开；同刻排在进入前，先释放后占用
        }
        sort(events.begin(), events.end());
        int total = 0, ans = 0;
        for (const auto& [time, delta] : events) {
            total += delta;
            ans = max(ans, total); // 峰值判定；上限判定改为与 limit 比较
        }
        return ans;
    }
};
```

### 通用解题模板

- 适用条件：全局最优可以拆成若干个方向独立、逐位可判定的局部约束；或者全局收益可以拆成逐段独立贡献。每个约束/贡献只依赖相邻或已排序的少量对象。
- 核心骨架：按约束方向分别扫描（双向约束各扫一遍，逐位取必要下限后合并；收益拆分类则逐段累加局部贡献）；或按对象属性排序后依序放置，每次放置利用"先放者对后放者的关系已确定"。
- 关键边界：双向约束取 max 而非相加（两个下限的较大者同时满足两侧）；相等对象是否触发约束要按题意显式判定（评分相等、身高相等的处理各不相同）；排序同键时的次键方向决定放置顺序的正确性。
- 复杂度：扫描类时间 `O(n)`、空间 `O(n)`（可滚动压缩）；排序放置类时间 `O(n log n)` 或 `O(n^2)`（依放置操作）、空间 `O(n)`。

```cpp
class Solution {
public:
    // 前提：约束只作用于相邻对象；a[i] 表示对象 i 的属性，less(a,b) 表示"b 应比 a 多"。
    int twoPassExample(vector<int>& a) {
        int n = static_cast<int>(a.size());
        vector<int> fwd(n, 1);
        for (int i = 1; i < n; i++) {
            if (a[i] > a[i - 1]) fwd[i] = fwd[i - 1] + 1; // 正向约束
        }
        int ans = 0, bwd = 0;
        for (int i = n - 1; i >= 0; i--) {
            if (i < n - 1 && a[i] > a[i + 1]) bwd++;
            else bwd = 1;                                  // 反向约束
            ans += max(fwd[i], bwd); // max 是双向约束下的必要下限
        }
        return ans;
    }
};
```

该骨架概括今日核心形态：135 是双向扫描的直接实例；122 是"收益拆成逐段贡献"的单向版本；406 则是骨架的排序放置变体——"先放的人对后放者的关系已确定"与"先扫方向的约束已固化"同源。
