# 第 10 周 - 区间与贪心

## 本周目标

本周训练排序后的区间处理和局部选择证明。你需要从“看起来可以贪”推进到“为什么这个局部选择不会破坏全局答案”。到本周结束时，你应该能说清排序依据、当前维护的边界、何时合并、何时丢弃、何时扩张，以及局部决策背后的不变量。

## 与前面主题衔接

区间题会复用数组排序、双指针扫描和二分边界意识；贪心题会复用动态规划里的“状态是否真的需要保留”。如果一个题能用局部变量表达足够信息，就不必上完整 DP。本周重点是学会为这种简化给出理由。

## 前置知识

- 能按左端点、右端点、结束位置或事件时间排序。
- 能区分合并区间、选择区间、删除区间和插入区间。
- 能用一个变量维护当前最远、当前结尾或当前剩余能力。
- 能解释为什么某个局部选择更安全。
- 能识别需要排序后再扫描的题面信号。

### 通用解题模板

- 适用条件：沿左端点有序处理闭区间，需要把相交区间合并为互不重叠的覆盖段。56 先排序；57 原列表已有序且互不重叠，只需围绕新区间处理。
- 核心骨架：维护当前覆盖段。下一段严格位于右侧时，当前段可定稿；否则扩张右端点。排序或输入顺序保证后续区间不可能回头连接更早的已定稿段。
- 关键边界：闭区间 `nextLeft <= currentRight` 视为相交；包含关系用 `max` 避免右边界缩小；显式维护当前段时不要漏掉末尾输出。57 第一段用严格 `<`，左右端点均需更新。
- 复杂度：已排序后的扫描为时间 `O(n)`；下方骨架不计返回结果为 `O(1)` 辅助空间，含结果 `O(n)`。56 加上排序后时间 `O(n log n)`、常见排序栈 `O(log n)`；57 直接扫描为时间 `O(n)`、辅助空间 `O(1)`。

```cpp
class Solution {
public:
    // 前提：输入已按左端点非递减排列；无序输入需先排序。
    vector<vector<int>> mergeSorted(const vector<vector<int>>& ordered) {
        vector<vector<int>> result;
        for (const auto& interval : ordered) {
            if (result.empty() || result.back()[1] < interval[0]) {
                result.push_back(interval);
            } else {
                // 只有最后一段仍可能扩张，端点相等也需要合并。
                result.back()[1] = max(result.back()[1], interval[1]);
            }
        }
        return result;
    }
};
```

该骨架用于概括今日共同模式。57 的专用三段写法可直接复用输入顺序，无需为了套骨架重新排序。

### 通用解题模板

- 适用条件：区间之间需要做“保留/丢弃/分组”决策，且决策只依赖一个随扫描单调推进的边界值。排序后每个新区间只与这个边界比较一次，无需回退。
- 核心骨架：选定排序键（左端点或右端点，取决于哪一端决定“安全”），一趟扫描维护一个边界变量；新区间越过边界时计数并推进边界，否则按题意收缩边界或直接跳过。
- 关键边界：比较符由端点语义决定——端点相接算重叠时用 `>` 判新组，不算重叠时用 `>=`；同起点排序时按另一端降序可让长区间先出现；比较器只用 `<`，避免极端坐标相减溢出；首区间直接计入答案，依赖 `n >= 1` 的约束。
- 复杂度：时间 `O(n log n)`，空间 `O(log n)`（排序栈，不计输入）。

```cpp
class Solution {
public:
    // 前提：按题意选定排序键与比较符；boundary 的含义由排序方向决定。
    int intervalScanExample(vector<vector<int>>& intervals) {
        sort(intervals.begin(), intervals.end(), [](const vector<int>& a, const vector<int>& b) {
            return a[1] < b[1]; // 以右端点为例；比较器只用 <，防溢出
        });
        int ans = 1;
        int boundary = intervals[0][1]; // 当前决策边界，随扫描单调推进
        for (int i = 1; i < static_cast<int>(intervals.size()); i++) {
            if (intervals[i][0] >= boundary) { // 比较符按端点语义调整
                ans++;
                boundary = intervals[i][1];
            }
        }
        return ans;
    }
};
```

该骨架概括今日三题的共同形态：435 与 452 直接同构（只差一个比较符），1288 把边界换成“历史最大右端点”并统计被覆盖对象。

### 通用解题模板

- 适用条件：需要沿一个方向逐步推进，且每一步“能推进到哪里”只依赖一个随扫描单调不减的边界值。不涉及排序，边界由当前位置的候选对象（跳跃力、覆盖范围）在线扩张。
- 核心骨架：维护“当前层边界”与“本层候选能延伸到的最远处”两个变量。扫描每个位置时先收集候选扩张最远值；走到层边界时结算一次（计数加一，层边界推进到最远值）。
- 关键边界：判定“能否推进”时比较当前位置与最远值（相等即卡死或出现空隙）；计数题中终点位置不再触发新一次结算（循环扫到 `n-2` 或用提前出口）；候选为 0 时最远值不延伸，依赖初始化表达“只覆盖自身”。
- 复杂度：时间 `O(n)`，空间 `O(1)`；若需要先把对象转成“每个位置的最远延伸”则增加 `O(n)` 空间。

```cpp
class Solution {
public:
    // 前提：reach[i] 表示从位置 i 出发能延伸到的最远处（跳跃题即 i+nums[i]，覆盖题需预处理）。
    int boundaryAdvanceExample(int n, const vector<int>& reach) {
        int ans = 0;
        int far = 0;       // 本层候选能延伸到的最远处
        int boundary = 0;  // 已结算 ans 次后恰好推进到的位置
        for (int i = 0; i < n; i++) {
            far = max(far, reach[i]);
            if (far <= i) return -1; // 推进中断：出现无法覆盖/到达的空隙
            if (i == boundary) {     // 走到层边界，结算一次
                ans++;
                boundary = far;
                if (boundary >= n - 1) break; // 已能到达终点，提前结束
            }
        }
        return ans;
    }
};
```

该骨架概括今日三题的共同形态：55 只用“最远值”判定可达；45 加层边界结算次数；1326 先把区间覆盖预处理成“每个位置的最远延伸”再复用同一骨架。
