### 通用解题模板

- 适用条件：节点集合与连接关系明确（显式编号图或网格坐标图），需要判断可达性、扩散同类区域或统计连通块数量。
- 核心骨架：先定节点与边的含义（编号节点 + 邻接表，或网格坐标 + 四方向邻居），再从起点出发 BFS/DFS 扩展，每个节点至多访问一次。扩展时统一用方向数组（网格）或邻接表遍历（编号图），越界与合法性判断放在邻居生成处。
- 关键边界：访问标记的时机决定正确性——连通性判定中标记不撤销；网格题可借用"改写原图"当标记（改色、沉岛），前提是改写后的值不再满足扩展条件；入队即标记防止重复入队。原值等于目标值的短路判断（如 733 原色等于新色）是扩散题的必备前置检查。
- 复杂度：时间 `O(n + m)`（编号图）或 `O(m × n)`（网格），空间同阶（邻接表 + 标记，或队列/递归栈最坏情况）。

```cpp
class Solution {
public:
    // 前提：isTarget(cur) 判断是否满足扩展/统计条件；mark(cur) 在入队/进入时立即标记。
    int gridTraversalExample(vector<vector<char>>& grid) {
        int m = static_cast<int>(grid.size());
        int n = static_cast<int>(grid[0].size());
        const int dx[] = {1, -1, 0, 0}, dy[] = {0, 0, 1, -1};
        int ans = 0;
        for (int x = 0; x < m; x++) {
            for (int y = 0; y < n; y++) {
                if (grid[x][y] != '1') continue;
                ans++;                  // 外层每遇到一次即一座新连通块
                queue<pair<int, int>> q;
                grid[x][y] = '0';       // 入队即改写原图，改写即访问标记
                q.push({x, y});
                while (!q.empty()) {
                    auto [cx, cy] = q.front(); q.pop();
                    for (int i = 0; i < 4; i++) {
                        int nx = cx + dx[i], ny = cy + dy[i];
                        if (nx >= 0 && nx < m && ny >= 0 && ny < n && grid[nx][ny] == '1') {
                            grid[nx][ny] = '0'; // 防止重复入队
                            q.push({nx, ny});
                        }
                    }
                }
            }
        }
        return ans;
    }
};
```

该骨架概括今日三题的共同形态：1971 是编号图版本（邻接表 + visited）；733 是单源扩散版（改色即标记）；200 是多连通块统计版（沉岛即标记）。三题的访问标记写法各有一句话，值得并排记忆。
