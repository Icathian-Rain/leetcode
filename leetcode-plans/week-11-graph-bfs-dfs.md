### 通用解题模板

- 适用条件：节点集合与连接关系明确（显式编号图或网格坐标图），需要判断可达性、扩散同类区域或统计连通块数量。
- 核心骨架：先定节点与边的含义（编号节点 + 邻接表，或网格坐标 + 四方向邻居），再从起点出发 BFS/DFS 扩展，每个节点至多访问一次。扩展时统一用方向数组（网格）或邻接表遍历（编号图），越界与合法性判断放在邻居生成处。
- 关键边界：访问标记的时机决定正确性——连通性判定中标记不撤销；网格题可借用"改写原图"当标记（改色、沉岛），前提是改写后的值不再满足扩展条件；入队即标记防止重复入队。原值等于目标值的短路判断（如 733 原色等于新色）是扩散题的必备前置检查。
- 复杂度：时间 `O(n + m)`（编号图）或 `O(m × n)`（网格），空间同阶（邻接表 + 标记，或队列/递归栈最坏情况）。

```cpp
class Solution {
public:
    // 前提：isTarget(cur) 判断是否满足扩展/统计条件；mark(cur) 在入队/进入时立即标记。
    int gridTraversalExample(vector<vector<char>>& grid) {
        int m = static_cast<int>(grid.size());
        int n = static_cast<int>(grid[0].size());
        const int dx[] = {1, -1, 0, 0}, dy[] = {0, 0, 1, -1};
        int ans = 0;
        for (int x = 0; x < m; x++) {
            for (int y = 0; y < n; y++) {
                if (grid[x][y] != '1') continue;
                ans++;                  // 外层每遇到一次即一座新连通块
                queue<pair<int, int>> q;
                grid[x][y] = '0';       // 入队即改写原图，改写即访问标记
                q.push({x, y});
                while (!q.empty()) {
                    auto [cx, cy] = q.front(); q.pop();
                    for (int i = 0; i < 4; i++) {
                        int nx = cx + dx[i], ny = cy + dy[i];
                        if (nx >= 0 && nx < m && ny >= 0 && ny < n && grid[nx][ny] == '1') {
                            grid[nx][ny] = '0'; // 防止重复入队
                            q.push({nx, ny});
                        }
                    }
                }
            }
        }
        return ans;
    }
};
```

该骨架概括今日三题的共同形态：1971 是编号图版本（邻接表 + visited）；733 是单源扩散版（改色即标记）；200 是多连通块统计版（沉岛即标记）。三题的访问标记写法各有一句话，值得并排记忆。

### 通用解题模板

- 适用条件：网格连通块的三类任务——块内累积统计量（面积等）、块外局部性质（周长等边界特征）、按位置资格筛选块（飞地等）。前两类和第三类的差别在于是否需要知道“块与边界的关系”。
- 核心骨架：累积类沿用第 1 天的沉岛 BFS，在入队时同时计数；边界特征类完全不需要搜索，逐格检查邻居即可；资格筛选类反向处理——从边界收集起点，一次搜索清除所有“不合格”的块，剩余即答案。
- 关键边界：判断“这题是否真的需要搜索”——周长是逐格局部性质，面积才是块级性质；反向筛选时清除阶段不能同时计数（那时分不清资格）；边界起点只有 `O(m+n)` 个，可先收集再统一启动。
- 复杂度：三题均为时间 `O(m × n)`、空间 `O(1)`（463）或 `O(m × n)`（队列/栈最坏）。

```cpp
class Solution {
public:
    // 前提：资格筛选类。从边界收集起点，一次清除所有与边界连通的块，剩余即答案。
    int boundaryCollectExample(vector<vector<int>>& grid) {
        int m = static_cast<int>(grid.size());
        int n = static_cast<int>(grid[0].size());
        const int dx[] = {1, -1, 0, 0}, dy[] = {0, 0, 1, -1};
        queue<pair<int, int>> q;
        // 先收集边界起点：能离开的块必与边界陆格连通
        for (int x = 0; x < m; x++) {
            for (int y = 0; y < n; y++) {
                if ((x == 0 || x == m - 1 || y == 0 || y == n - 1) && grid[x][y] == 1) {
                    grid[x][y] = 0; // 入队即沉岛
                    q.push({x, y});
                }
            }
        }
        while (!q.empty()) {
            auto [cx, cy] = q.front(); q.pop();
            for (int i = 0; i < 4; i++) {
                int nx = cx + dx[i], ny = cy + dy[i];
                if (nx >= 0 && nx < m && ny >= 0 && ny < n && grid[nx][ny] == 1) {
                    grid[nx][ny] = 0;
                    q.push({nx, ny});
                }
            }
        }
        int ans = 0;
        for (const auto& row : grid) for (int cell : row) ans += cell; // 剩余即飞地
        return ans;
    }
};
```
