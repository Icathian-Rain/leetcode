# 第 11 周 - 图论 BFS 与 DFS

## 本周目标

本周目标是把“树上的遍历”推广到一般图和网格图。到本周结束时，你应该能判断题目是在求连通性、连通块数量、最短层数、可达区域，还是需要从边界或多个源头同时出发。你还要能稳定处理访问标记，避免重复搜索和环导致的无限递归。

资料依据：默认扩展主题顺序与核心题池参考 `.agents/skills/leetcode-weekly-coach/references/topic-ladders.md`；题号、英文题名和难度按本地训练题池整理，记录日期为 2026-06-29。做题或生成点评时，再按单题继续核对官方信息。

## 与前面主题衔接

树周练的是无环结构，回溯周练的是路径搜索，动态规划周练的是状态复用。图论会把这些能力合在一起：你需要建模节点和边，明确访问状态，决定按深度推进还是按层推进。本周特别关注“从哪里开始搜”。

## 前置知识

- 能用邻接表表示图。
- 能在网格中把位置看作节点，把上下左右看作边。
- 能区分 DFS 适合扩展整片区域，BFS 适合按层找最短步数。
- 能维护 `visited`，并说清何时标记。
- 能处理无向图中的双向边和重复访问。

## 每日计划

### 第 1 天 - 图遍历入口

1. `1971. Find if Path Exists in Graph` (`简单`) - 练习从边列表建立连接关系，并判断两个点是否可达。
2. `733. Flood Fill` (`简单`) - 练习在网格中扩展同类区域。
3. `200. Number of Islands` (`中等`) - 练习统计多个互不相连的区域。

### 第 2 天 - 网格连通块

1. `695. Max Area of Island` (`中等`) - 练习在每个连通块中累积面积。
2. `463. Island Perimeter` (`简单`) - 练习从格子邻居关系中统计边界。
3. `1020. Number of Enclaves` (`中等`) - 练习从边界出发排除可逃离区域。

### 第 3 天 - 图复制与状态映射

1. `133. Clone Graph` (`中等`) - 练习在遍历图的同时建立新旧节点映射。
2. `138. Copy List with Random Pointer` (`中等`) - 回顾带随机指针结构中的节点映射意识。
3. `399. Evaluate Division` (`中等`) - 练习带权连接关系中的路径查询。

### 第 4 天 - 多源按层扩散

1. `994. Rotting Oranges` (`中等`) - 练习多个起点同时按层扩散。
2. `542. 01 Matrix` (`中等`) - 练习从多个已知位置向外更新距离。
3. `286. Walls and Gates` (`中等`) - 练习从多个门出发填充最近距离。

### 第 5 天 - 反向搜索与边界思维

1. `417. Pacific Atlantic Water Flow` (`中等`) - 练习从目标边界反向标记可达区域。
2. `130. Surrounded Regions` (`中等`) - 练习保留和边界相连的区域。
3. `1254. Number of Closed Islands` (`中等`) - 练习判断一个区域是否触碰边界。

### 第 6 天 - 最短路径与状态扩展

1. `1091. Shortest Path in Binary Matrix` (`中等`) - 练习网格中的按层最短路径。
2. `127. Word Ladder` (`困难`) - 练习字符串状态之间的最短转换。
3. `752. Open the Lock` (`中等`) - 练习在隐式状态图中避开不可用状态。

### 第 7 天 - 综合复盘与图建模

1. `785. Is Graph Bipartite?` (`中等`) - 练习在遍历时维护节点分组状态。
2. `547. Number of Provinces` (`中等`) - 练习从矩阵关系中统计连通块。
3. `1293. Shortest Path in a Grid with Obstacles Elimination` (`困难`) - 练习在路径状态中加入额外资源维度。

## 本周关注清单

- 每题先说明节点是什么、边是什么。
- 搜索前明确起点：所有格子、边界、多个源头，还是某个给定节点。
- DFS 题注意递归终止和访问标记；BFS 题注意层数何时增加。
- 网格题统一方向数组和边界判断。
- 隐式图题不要急着建全图，先看能否按状态生成邻居。
- 每天至少复盘一次：为什么这题用 BFS 或 DFS 更合适。

## 本周节奏建议

- 第 1 天：从简单建图和网格遍历开始。
- 第 2 天：巩固连通块统计和边界判断。
- 第 3 天：处理遍历过程中的映射关系。
- 第 4 天：集中练多源 BFS。
- 第 5 天：练反向思维和边界保护。
- 第 6 天：进入最短路径和隐式图。
- 第 7 天：混合图建模和状态扩展。
