### 通用解题模板

- 适用条件：一组"谁在谁之前"的有向关系（先修、信任、解锁），问"能否排出全序""给出一个合法顺序"或"找出某个由出入度刻画的特殊节点"。关系的方向可以先翻译成"完成 v 解锁 u"的邻接语义再动手。
- 核心骨架：入度数组记录每个节点的未满足前置数；入度 0 者全部入队（多源一次入队，与第 11 周多源 BFS 同构）；出队 u 时对其解锁的后继入度减 1，减到 0 则入队。每个节点恰入队一次——入队即写入结果（210）或只计数（207）。判环不需要显式找回环：入队总数（结果长度）不足节点数即存在环。
- 关键边界：入队时点的选择——入队顺序与出队顺序一致，两种写入时点等价；箭头方向在 Kahn 里固定走"完成→解锁"方向，语义是"入度清零 = 前置条件齐备"；特殊节点判定（997 型）只靠度数计数即可，不需要建邻接表，且两个度数条件缺一不可（入度 n-1 防缺票，出度 0 防假法官）。
- 复杂度：时间 `O(V + E)`，空间 `O(V + E)`（度数计数题退化到 `O(n)` 空间）。

```cpp
class Solution {
public:
    // 前提：edges 为 [后继, 先修] 形态；onReady(i) 在节点入队瞬间执行
    //（计数、写入结果或判定性质）。
    int topoExample(int n, vector<vector<int>>& edges) {
        vector<vector<int>> next(n); // next[v]: 完成 v 后解锁的节点
        vector<int> indeg(n, 0);
        for (const auto& p : edges) {
            next[p[1]].push_back(p[0]); // 建边方向固定"完成 -> 解锁"
            indeg[p[0]]++;
        }
        queue<int> q;
        int done = 0;
        for (int i = 0; i < n; i++) {
            if (indeg[i] == 0) { // 入度清零即条件齐备：可入队
                q.push(i);
                done++;           // 这里换成 push 进结果数组即 210 形态
            }
        }
        while (!q.empty()) {
            int u = q.front(); q.pop();
            for (int v : next[u]) {
                if (--indeg[v] == 0) { // 前置全部满足：轮到 v
                    q.push(v);
                    done++;
                }
            }
        }
        return done == n ? 1 : 0; // 数量不齐 = 有环
    }
};
```

该骨架是今日三题的统一形态：997 只取其中"度数计数"的前半段（不入队、不建邻接表）；207 取全部结构但结果只留一个计数；210 把计数换成按入队顺序写入的数组。三题从"静态点性质 → 可行性 → 全序输出"恰好构成入度视角的三级台阶。

### 通用解题模板

- 适用条件：有向依赖关系问"顺序/可行性/可达性"，且有向图的**终点/目标集**定义了"安全或完成"的语义——从谁出发能全部收敛，先修链是否可达，字符序是否可排。
- 核心骨架：Kahn 清零不变量的**方向泛化**：入队条件永远是"某个待满足计数归零"，但计数装什么、建图用正图还是反图，由"谁在等谁"决定。第 1 天是"后继等先修"（正图 + 入度清零）；今天 802 是"前驱等后继"（**反图 + 出度清零**）；1462 在清零步骤外挂传递闭包列合并；269 把节点对象换成字符。
- 关键边界：闭包/计数转移必须发生在"来源节点已出队"的时刻（1462：u 出队时其先修列已完整，向 v 合并不遗漏）；多字母/多对象题先定义全集（269 的 vis），入队与环判定都对全集负责；全对建图与相邻对建图在本题规模下等价，冲突检测有"矩阵即时判"与"长度不足兜底"两个时机。
- 复杂度：`O(V + E)` 为骨架基线；外挂闭包 `O(E·V)`（bitset 可除以机器字长）；建图预处理 `O(n²L)` 或 `O(nL)` 按题选择。

```cpp
class Solution {
    vector<int> topologicalExample(int n, vector<vector<int>>& edges, bool reverse) {
        vector<vector<int>> adj(n), radj(n);
        vector<int> remain(n, 0);
        for (const auto& e : edges) {
            adj[e[0]].push_back(e[1]);
            radj[e[1]].push_back(e[0]);
        }
        // 方向开关：清零计数装"入度"（先修待满足）或"出度"（后继待确认）
        for (int i = 0; i < n; i++) {
            remain[i] = reverse ? static_cast<int>(adj[i].size())
                                : static_cast<int>(radj[i].size());
        }
        queue<int> q;
        for (int i = 0; i < n; i++) {
            if (remain[i] == 0) q.push(i); // 计数归零即条件齐备
        }
        while (!q.empty()) {
            int u = q.front(); q.pop();
            // 出队处理：计数、写入结果、或闭包合并（1462 形态）
            for (int v : reverse ? radj[u] : adj[u]) {
                if (--remain[v] == 0) q.push(v); // 一个依赖被满足
            }
        }
        // 终态 remain 全零 = 无环；否则存在互相等待的结构
        return {};
    }
};
```

（模板仅作复盘对照骨架，未模板化的 `reverse` 参数在实战中按语义直接二选一书写。）该骨架统摄今日三题与第 1 天三题：997 只取度数计数、207/210 是正图入度版、802 是反图出度版、1462 在出队处理处挂闭包、269 把节点域换成 26 字母。六题一个骨架——"从哪里开始搜 = 计数归零的全体"。
