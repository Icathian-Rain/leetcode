## 用户思路概述

你写了两个版本：`s1` 先保存每个位置右侧乘积，再用左侧滚动乘积合成答案；`s2` 进一步把答案数组本身当作前缀乘积容器，第二次从右往左乘上后缀乘积。最终提交走的是 `s2`。

这个思路正确命中了本题核心：不用除法，把“除自身以外”拆成当前位置左侧所有数的乘积和右侧所有数的乘积。

## 主要问题

- 没有阻塞级问题：`s2` 已经是推荐写法，时间和额外空间都达标。
- 可读性小问题：`mul` 同时表示前缀乘积和后缀乘积，逻辑没错，但命名成 `prefix` / `suffix` 会让两趟扫描的不变量更直接。
- 提交简洁度：`s1` 作为对照有学习价值，但最终 LeetCode 提交可以只保留 `s2`，减少复盘时的干扰。

## 做得好的地方

- 没有使用除法，因此天然覆盖数组里有一个或多个 `0` 的情况。
- 第二版把前缀结果直接写入 `ans`，再从右侧滚动合并后缀，达到了题目要求的 `O(1)` 额外空间。
- 两次线性扫描的边界清楚，没有把当前位置自身乘进去。

## 最优解法

推荐写法就是你当前 `s2` 的整理版。第一趟让 `ans[i]` 保存 `nums[0..i-1]` 的乘积；第二趟维护 `suffix = nums[i+1..n-1]` 的乘积，并乘回 `ans[i]`。关键不变量是：更新当前位置答案时，滚动乘积还没有包含 `nums[i]`。

- 时间复杂度：`O(n)`
- 空间复杂度：`O(1)`，不计输出数组

## 最优解代码

```cpp
class Solution {
public:
    vector<int> productExceptSelf(vector<int>& nums) {
        int n = nums.size();
        vector<int> ans(n, 1);

        int prefix = 1;
        for (int i = 0; i < n; ++i) {
            ans[i] = prefix;
            prefix *= nums[i];
        }

        int suffix = 1;
        for (int i = n - 1; i >= 0; --i) {
            ans[i] *= suffix;
            suffix *= nums[i];
        }

        return ans;
    }
};
```
