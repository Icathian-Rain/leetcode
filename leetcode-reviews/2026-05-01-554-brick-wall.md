## 用户思路概述

你没有直接枚举竖线穿过多少砖，而是把每一行内部砖块右边界的位置算成前缀和，并用哈希表统计每个缝隙位置出现了多少次。最后选择出现次数最多的缝隙，让竖线尽量沿着砖缝走，答案就是总行数减去这个最大缝隙频次。

这是本题最核心的建模：目标不是找“穿过的砖”，而是找“没有穿过的砖缝”。

## 主要问题

- 整体算法正确，命中了哈希表 + 前缀和的最优模式，没有阻塞级问题。
- `for (int j = 0; j < wall[i].size() - 1; j++)` 混用了 `int` 和 `size_t`，当前约束下每行至少一块砖，所以不会出错，但写成 `j + 1 < row.size()` 更稳，也能避免无符号减法的心智负担。
- 你用 `long long` 保存缝隙位置是稳的。旧版题面常说总宽度不超过 `INT_MAX`，但当前约束里单块宽度可到 `2^31 - 1`，用 `long long` 更有余量。

## 做得好的地方

- 正确排除了每行最后一个边界，没有误把墙的最右边界当作可选竖线。
- `cnt[r]++` 的状态含义很清晰：位置 `r` 上有多少行存在内部缝隙。
- 从 `ans = n` 开始，再用 `n - num` 更新，能自然覆盖所有行都只有一块砖的情况。

## 最优解法

推荐最优解就是统计所有内部缝隙的前缀位置。关键不变量是：`gapCount[pos]` 表示有多少行在横向位置 `pos` 存在砖缝；如果竖线画在 `pos`，这些行不会被穿过，所以穿过的砖数是 `rows - gapCount[pos]`。

- 时间复杂度：`O(B)`，`B` 为墙中砖块总数
- 空间复杂度：`O(G)`，`G` 为不同内部缝隙位置数，最坏 `O(B)`

## 最优解代码

```cpp
class Solution {
public:
    int leastBricks(vector<vector<int>>& wall) {
        unordered_map<long long, int> gapCount;
        int bestGapRows = 0;

        for (const auto& row : wall) {
            long long pos = 0;
            for (int i = 0; i + 1 < static_cast<int>(row.size()); ++i) {
                pos += row[i];
                bestGapRows = max(bestGapRows, ++gapCount[pos]);
            }
        }

        return static_cast<int>(wall.size()) - bestGapRows;
    }
};
```
