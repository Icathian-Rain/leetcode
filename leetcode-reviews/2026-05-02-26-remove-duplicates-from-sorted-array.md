## 用户思路概述

1. 先记录数组长度，并把 `slow`、`fast` 都放到下标 1。
2. `fast` 从左到右扫描数组，`slow` 表示下一个可以写入新元素的位置。
3. 当 `nums[fast]` 和当前有效前缀最后一个元素 `nums[slow - 1]` 不同时，把 `nums[fast]` 写到 `nums[slow]`，再推进 `slow`。
4. 每轮都推进 `fast`，扫描结束后返回 `slow` 作为去重后有效长度。

## 用户解法复杂度

- 时间复杂度：`O(n)`
- 空间复杂度：`O(1)`
- 复杂度来源：`fast` 对数组做一次线性扫描，只使用常数个下标变量。

## 关键理解点

| 理解点 | 用户当前表现 | 影响 | 建议 |
| --- | --- | --- | --- |
| 有效前缀含义 | `slow` 始终指向下一次写入位置，`[0, slow)` 是去重后的结果。 | 这是本题正确性的核心，当前实现保持得很好。 | 复盘时直接说“返回的是有效前缀长度，不关心后面的残留值”。 |
| 空数组边界 | 当前从 `slow = 1` 开始，若 `nums` 为空会返回 1。 | LeetCode 26 当前约束通常保证 `nums.length >= 1`，但泛化写法存在边界风险。 | 最优参考函数中补 `nums.empty()`，形成更稳的通用习惯。 |
| 比较对象 | 使用 `nums[slow - 1]` 和 `nums[fast]` 比较。 | 能避免重复值被写入有效前缀。 | 继续保持“和结果前缀最后一个值比较”的思路。 |

## 最优解法

1. 若数组为空，直接返回 0。
2. 用 `write` 表示下一个写入位置，并默认保留第一个元素。
3. 从第二个元素开始扫描，只有当当前值不同于有效前缀最后一个值时才写入。
4. 扫描结束后返回 `write`，表示有效前缀长度。

- 最优时间复杂度：`O(n)`
- 最优空间复杂度：`O(1)`

### 最优解代码

```cpp
class Solution {
public:
    int removeDuplicates(vector<int>& nums) {
        if (nums.empty()) {
            return 0;
        }

        int write = 1;
        for (int read = 1; read < static_cast<int>(nums.size()); ++read) {
            if (nums[read] != nums[write - 1]) {
                nums[write] = nums[read];
                ++write;
            }
        }

        return write;
    }
};
```
