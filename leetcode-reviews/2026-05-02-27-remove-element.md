## 用户思路概述

1. 先记录数组长度，并用 `write` 表示下一个可写入的位置。
2. 用 `read` 从左到右扫描整个数组。
3. 当 `nums[read] != val` 时，把当前元素写入 `nums[write]`，并推进 `write`。
4. 扫描结束后返回 `write`，表示删除目标值后有效前缀的长度。

## 用户解法复杂度

- 时间复杂度：`O(n)`
- 空间复杂度：`O(1)`
- 复杂度来源：`read` 对数组做一次线性扫描，只使用常数个下标变量。

## 用户代码注释版

> 只在点评文档中展示加注释版本；不要把这些注释写回 `src/*.cpp` 的用户原代码。

```cpp
class Solution {
public:
    int removeElement(vector<int>& nums, int val) {
        int n = nums.size();

        // write 表示下一个可写入位置，[0, write) 都是不等于 val 的有效元素。
        int write = 0;
        for (int read = 0; read < n; read++) {
            // 只有不是 val 的元素才保留到有效前缀中。
            if (nums[read] != val) {
                nums[write] = nums[read];
                write++;
            }
        }

        // 题目只关心前 write 个元素，后面的残留值不用处理。
        return write;
    }
};
```

## 最优解法

1. 用 `write` 维护结果有效前缀长度。
2. 用 `read` 扫描原数组。
3. 如果当前元素不是 `val`，就写入 `nums[write]` 并推进 `write`。
4. 最后返回 `write`，表示前 `write` 个元素是有效答案。

- 最优时间复杂度：`O(n)`
- 最优空间复杂度：`O(1)`

### 最优解代码

```cpp
class Solution {
public:
    int removeElement(vector<int>& nums, int val) {
        int write = 0;
        for (int read = 0; read < static_cast<int>(nums.size()); ++read) {
            // [0, write) 始终是不等于 val 的有效前缀。
            if (nums[read] != val) {
                nums[write] = nums[read];
                ++write;
            }
        }

        return write;
    }
};
```
