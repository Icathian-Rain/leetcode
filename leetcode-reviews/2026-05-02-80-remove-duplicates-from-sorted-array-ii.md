## 用户思路概述

1. 先处理长度小于 2 的数组，直接返回原长度。
2. 默认前两个元素可以保留，所以从 `slow = 2`、`fast = 2` 开始扫描。
3. 对每个 `nums[fast]`，检查它是否不同于 `nums[slow - 1]` 或 `nums[slow - 2]`。
4. 只要它不是会形成第三个重复值的元素，就写入 `nums[slow]` 并推进 `slow`，最后返回 `slow`。

## 用户解法复杂度

- 时间复杂度：`O(n)`
- 空间复杂度：`O(1)`
- 复杂度来源：`fast` 线性扫描数组，`slow` 原地维护有效前缀。

## 关键理解点

| 理解点 | 用户当前表现 | 影响 | 建议 |
| --- | --- | --- | --- |
| 最多保留两次 | 用 `slow - 1` 和 `slow - 2` 判断当前值是否还能写入。 | 能正确阻止第三个相同元素进入有效前缀。 | 复盘时可以简化为“当前值只需和有效前缀倒数第二个比较”。 |
| 短数组边界 | `n < 2` 直接返回。 | 避免访问 `slow - 2` 越界。 | 这个边界处理很好，继续保留。 |
| 条件表达 | 使用两个“不等于”条件的或关系。 | 正确，但可读性略绕。 | 推荐写成 `write < 2 || num != nums[write - 2]`，更直接表达规则。 |

## 算法优缺点

| 方案 | 优点 | 缺点 | 适用情况 |
| --- | --- | --- | --- |
| 用户解法 | 主体正确，能从第 26 题自然扩展到最多保留两次。 | 条件表达需要多想一步，可读性略弱。 | 适合当前题，提交大概率可通过。 |
| 推荐最优解 | 规则表达更统一，不需要单独维护 `fast` 下标。 | 使用范围循环时要理解写入不会影响还未读取的顺序。 | 适合作为“最多保留 K 次”类题的基础模板。 |

## 最优解法

1. 用 `write` 表示有效前缀长度。
2. 从左到右读取每个 `num`。
3. 如果当前有效前缀长度小于 2，直接写入。
4. 否则只有当 `num != nums[write - 2]` 时写入，避免出现第三个相同值。
5. 返回 `write` 作为最终有效长度。

- 最优时间复杂度：`O(n)`
- 最优空间复杂度：`O(1)`

### 最优解代码

```cpp
class Solution {
public:
    int removeDuplicates(vector<int>& nums) {
        int write = 0;
        for (int num : nums) {
            if (write < 2 || num != nums[write - 2]) {
                nums[write] = num;
                ++write;
            }
        }

        return write;
    }
};
```
