## 用户思路概述

1. 创建长度相同的 `ans`，用于保存平方后的有序结果。
2. 用 `lower_bound` 找到第一个非负数位置，把 `left` 放在负数区最后一个位置，把 `right` 放在非负数区第一个位置。
3. 每轮比较 `nums[left]` 和 `nums[right]` 的绝对值，把较小平方写入 `ans[idx]`，再移动对应指针。
4. 当一侧耗尽时，继续把另一侧剩余元素平方写入结果。

## 用户解法复杂度

- 时间复杂度：`O(n)`
- 空间复杂度：`O(n)`
- 复杂度来源：`lower_bound` 是 `O(log n)`，随后每个元素只被写入一次，总体为 `O(n)`；结果数组占 `O(n)`。

## 关键理解点

| 理解点 | 用户当前表现 | 影响 | 建议 |
| --- | --- | --- | --- |
| 结果有序性 | 从正负分界向两侧取较小绝对值，能构造递增平方结果。 | 思路正确，能覆盖负数平方变大的特点。 | 复盘时说清“靠近 0 的平方更小”。 |
| 分支复杂度 | 分别处理左侧耗尽、右侧耗尽、两侧都有值。 | 正确但分支较多，容易在边界上漏测。 | 后续可优先使用从结果末尾写入的版本，分支更少。 |
| 边界覆盖 | 全负数、全非负数、包含 0 都能进入对应分支。 | 静态检查看是安全的。 | 建议本地补这三类边界样例。 |

## 算法优缺点

| 方案 | 优点 | 缺点 | 适用情况 |
| --- | --- | --- | --- |
| 用户解法 | 思路直观，能利用有序数组的正负分界。 | 需要 `lower_bound` 和多个边界分支，代码稍重。 | 适合用来理解平方后顺序变化。 |
| 推荐最优解 | 从两端取较大平方写到末尾，循环统一，分支更少。 | 需要反向填充结果，初看不如分界合并直观。 | 更适合提交和面试表达。 |

## 最优解法

1. 新建结果数组，准备从最后一个位置向前填。
2. 把两个指针放到原数组左右两端。
3. 每次比较两端绝对值，把较大的平方放到结果当前末尾。
4. 移动被使用的一侧指针，直到结果填满。

- 最优时间复杂度：`O(n)`
- 最优空间复杂度：`O(n)`

### 最优解代码

```cpp
class Solution {
public:
    vector<int> sortedSquares(vector<int>& nums) {
        int n = static_cast<int>(nums.size());
        vector<int> ans(n);
        int left = 0;
        int right = n - 1;

        for (int pos = n - 1; pos >= 0; --pos) {
            if (abs(nums[left]) > abs(nums[right])) {
                ans[pos] = nums[left] * nums[left];
                ++left;
            } else {
                ans[pos] = nums[right] * nums[right];
                --right;
            }
        }

        return ans;
    }
};
```

## 对比与改进方向

| 对比项 | 用户代码 | 最优解代码 | 改进方向 |
| --- | --- | --- | --- |
| 状态定义 | 以正负分界为中心向两侧扩展。 | 以数组两端为候选，向中间收缩。 | 遇到平方、绝对值这类两端更大的题，可以优先考虑从结果尾部写入。 |

| 复杂度 | `O(n)` / `O(n)` | `O(n)` / `O(n)` | 两者复杂度相同，推荐解更简洁。 |
