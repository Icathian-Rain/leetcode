## 用户思路概述

1. 先对 `nums` 排序，让相同元素相邻，也让后续左右指针有明确移动方向。
2. 枚举第一个数 `nums[i]`，如果它已经大于 0，直接结束外层循环。
3. 跳过重复的 `nums[i]`，避免生成相同开头的三元组。
4. 把问题转成在 `i + 1` 到末尾之间寻找两个数，使它们的和等于 `-nums[i]`。
5. 根据两数和与目标值的大小移动 `j` 或 `k`，命中答案后跳过两侧重复值。

## 用户解法复杂度

- 时间复杂度：`O(n^2)`
- 空间复杂度：`O(log n)` 到 `O(n)`，主要来自排序实现的栈或临时空间；不计返回结果。
- 复杂度来源：排序后，外层固定一个数，内层左右指针线性扫描剩余区间。

## 用户代码注释版

> 只在点评文档中展示加注释版本；不要把这些注释写回 `src/*.cpp` 的用户原代码。

```cpp
class Solution {
public:
    vector<vector<int>> threeSum(vector<int>& nums) {
        int n=nums.size();
        vector<vector<int>> ans;
        sort(nums.begin(), nums.end());
        for(int i=0; i<n; i++) {
            if(nums[i] > 0) {
                // 排序后第一个数已经大于 0，三数和不可能再等于 0。
                break;
            }
            if(i > 0 && nums[i] == nums[i-1]) {
                // 固定数去重，避免重复三元组。
                continue;
            }
            int target = 0-nums[i];
            int j=i+1, k=n-1;
            while(j < k) {
                if(nums[j]+nums[k]<target) {
                    // 两数和偏小，左指针右移以增大和。
                    j++;
                } else if(nums[j]+nums[k]>target) {
                    // 两数和偏大，右指针左移以减小和。
                    k--;
                } else {
                    ans.push_back({nums[i], nums[j], nums[k]});
                    // 命中后跳过左右两侧重复值，避免重复答案。
                    while(j<k && nums[j] == nums[j+1]) j++;
                    while(j<k && nums[k] == nums[k-1]) k--;
                    j++;
                    k--;
                }
            }
        }
        return ans;
    }
};
```

## 关键理解点

| 理解点 | 用户当前表现 | 影响 | 建议 |
| --- | --- | --- | --- |
| 固定一位再收缩两侧 | 已经稳定使用固定 `i` 加左右指针。 | 命中本题核心模式，复杂度达到常见最优。 | 复盘时重点说清“排序后为什么能按和的大小移动指针”。 |
| 去重位置 | 固定数和命中答案后的两侧都做了去重。 | 能避免重复三元组。 | 保持“先记录答案，再跳过重复，再同时收缩”的顺序。 |
| 循环边界 | 外层写到 `i < n`，依赖内层空循环兜底。 | 正确性没问题，但表达上不如 `i < n - 2` 精确。 | 后续组合题建议让循环边界直接表达还需要几个数。 |

## 最优解法

1. 排序数组，保证相同值相邻，并获得左右移动的单调依据。
2. 枚举第一位 `i`，只枚举到 `n - 3`，并跳过重复固定值。
3. 若 `nums[i] > 0`，说明后续三数和只会更大，直接结束。
4. 在右侧区间用两个指针寻找和为 `0` 的三元组。
5. 命中后记录答案，并跳过左右两侧重复值。

- 最优时间复杂度：`O(n^2)`
- 最优空间复杂度：`O(log n)` 到 `O(n)`，不计返回结果。

### 最优解代码

```cpp
class Solution {
public:
    vector<vector<int>> threeSum(vector<int>& nums) {
        vector<vector<int>> ans;
        sort(nums.begin(), nums.end());

        int n = nums.size();
        for (int i = 0; i < n - 2; ++i) {
            if (nums[i] > 0) {
                break;
            }
            if (i > 0 && nums[i] == nums[i - 1]) {
                continue;
            }

            int left = i + 1;
            int right = n - 1;
            while (left < right) {
                int sum = nums[i] + nums[left] + nums[right];
                if (sum < 0) {
                    ++left;
                } else if (sum > 0) {
                    --right;
                } else {
                    ans.push_back({nums[i], nums[left], nums[right]});
                    // 当前三元组已记录，跳过两侧重复值避免重复答案。
                    while (left < right && nums[left] == nums[left + 1]) {
                        ++left;
                    }
                    while (left < right && nums[right] == nums[right - 1]) {
                        --right;
                    }
                    ++left;
                    --right;
                }
            }
        }

        return ans;
    }
};
```
