## 用户思路概述

1. 先排序数组，让左右指针可以根据当前和与 `target` 的大小移动。
2. 枚举固定位置 `i`，并跳过重复的固定值。
3. 对每个固定值，在右侧使用 `j` 和 `k` 形成三数和 `sum`。
4. 如果 `sum == target`，直接返回目标值。
5. 如果 `sum < target`，右移 `j`；如果 `sum > target`，左移 `k`。
6. 每次访问一个 `sum` 后，用它更新当前最接近答案 `ans`。

## 用户解法复杂度

- 时间复杂度：`O(n^2)`
- 空间复杂度：`O(log n)` 到 `O(n)`，主要来自排序实现；只用常数个额外变量。
- 复杂度来源：排序后，外层固定一位，内层左右指针线性扫描。

## 用户代码注释版

> 只在点评文档中展示加注释版本；不要把这些注释写回 `src/*.cpp` 的用户原代码。

```cpp
class Solution {
public:
    int threeSumClosest(vector<int>& nums, int target) {
        int n=nums.size();
        int ans=1e7;
        sort(nums.begin(), nums.end());
        for(int i=0; i<n; i++) {
            if(i > 0 && nums[i] == nums[i-1]) {
                // 固定值重复时跳过；对“最接近”来说，相同固定值不会带来新的和值。
                continue;
            }
            int j=i+1, k=n-1;
            while(j < k) {
                int sum=nums[i]+nums[j]+nums[k];
                if(sum == target) {
                    return target;
                } else if(sum < target) {
                    // 当前和偏小，跳过重复左值后右移，尝试增大总和。
                    while(j<k && nums[j] == nums[j+1])j++;
                    j++;
                } else {
                    // 当前和偏大，跳过重复右值后左移，尝试减小总和。
                    while(j<k && nums[k] == nums[k-1])k--;
                    k--;
                }
                // 用刚刚访问过的 sum 更新最接近答案。
                if(abs(sum-target) < abs(ans-target)) {
                    ans=sum;
                }
            }
        }
        return ans;
    }
};
```

## 关键理解点

| 理解点 | 用户当前表现 | 影响 | 建议 |
| --- | --- | --- | --- |
| 最接近答案维护 | 能用差值绝对值更新 `ans`。 | 能保留当前最优候选。 | 推荐先用前三个数初始化，避免依赖哨兵值。 |
| 指针移动依据 | 根据 `sum` 与 `target` 的大小移动左右指针。 | 移动方向正确，是本题的核心。 | 复盘时说清“偏小增大、偏大减小”。 |
| 去重策略 | 对固定值和移动端都做了重复跳过。 | 正确性一般不受影响，但本题不要求输出所有组合，去重不是必要步骤。 | 推荐先掌握不去重版本，控制流更简单。 |

## 算法优缺点

| 方案 | 优点 | 缺点 | 适用情况 |
| --- | --- | --- | --- |
| 用户解法 | 方向正确，能提前返回精确命中。 | `ans = 1e7` 是经验哨兵；更新答案放在移动后，可读性略弱。 | 提交大概率可通过，适合当前训练阶段。 |
| 推荐最优解 | 用真实三数和初始化答案，每轮先更新再移动，结构更稳。 | 没有特殊剪枝，仍是标准 `O(n^2)`。 | 更适合作为面试讲解模板。 |

## 最优解法

1. 排序数组，初始化 `best = nums[0] + nums[1] + nums[2]`。
2. 枚举第一位 `i`，在右侧区间放置左右指针。
3. 每次计算三数和 `sum` 后，先比较它是否比 `best` 更接近 `target`。
4. 如果精确命中，直接返回 `target`。
5. 若 `sum < target`，右移左指针；否则左移右指针。

- 最优时间复杂度：`O(n^2)`
- 最优空间复杂度：`O(log n)` 到 `O(n)`，不计排序以外只用 `O(1)`。

### 最优解代码

```cpp
class Solution {
public:
    int threeSumClosest(vector<int>& nums, int target) {
        sort(nums.begin(), nums.end());
        int n = nums.size();
        int best = nums[0] + nums[1] + nums[2];

        for (int i = 0; i < n - 2; ++i) {
            int left = i + 1;
            int right = n - 1;
            while (left < right) {
                int sum = nums[i] + nums[left] + nums[right];
                if (abs(sum - target) < abs(best - target)) {
                    best = sum;
                }

                if (sum == target) {
                    return target;
                }
                // 和偏小时只能增大左侧候选，和偏大时只能减小右侧候选。
                if (sum < target) {
                    ++left;
                } else {
                    --right;
                }
            }
        }

        return best;
    }
};
```

## 对比与改进方向

| 对比项 | 用户代码 | 最优解代码 | 改进方向 |
| --- | --- | --- | --- |
| 状态定义 | `ans` 用大哨兵值初始化。 | `best` 用真实可行三元组初始化。 | 避免依赖题目范围和魔法数。 |
| 更新逻辑 | 移动指针后更新刚才的 `sum`。 | 计算后立刻更新，再决定移动方向。 | 让“访问一个状态就评估一次”更直观。 |
| 边界处理 | 外层 `i < n`，空内层兜底。 | 外层 `i < n - 2`。 | 用边界表达还需要两个数。 |
| 复杂度 | `O(n^2)` / 排序额外空间 | `O(n^2)` / 排序额外空间 | 已达到常见最优。 |
