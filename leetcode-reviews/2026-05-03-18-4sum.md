## 用户思路概述

1. 先排序数组，为去重和左右指针移动建立顺序。
2. 用两层循环固定 `a` 和 `b` 两个位置。
3. 固定前两位后，在剩余区间使用 `c` 和 `d` 两个指针寻找目标四元组。
4. 对 `a`、`b` 做固定层去重，命中答案后对 `c`、`d` 两侧去重。
5. 使用 `long long` 保存前两位之和，让后续四数比较进入更安全的整数范围。

## 用户解法复杂度

- 时间复杂度：`O(n^3)`
- 空间复杂度：`O(log n)` 到 `O(n)`，主要来自排序实现；不计返回结果。
- 复杂度来源：排序后两层固定位置，内层双指针线性扫描。

## 用户代码注释版

> 只在点评文档中展示加注释版本；不要把这些注释写回 `src/*.cpp` 的用户原代码。

```cpp
using ll = long long;
class Solution {
public:
    vector<vector<int>> fourSum(vector<int>& nums, int target) {
        int n=nums.size();
        sort(nums.begin(), nums.end());

        vector<vector<int>> ans;
        for(int a=0; a<n; a++) {
            if(a>0 && nums[a] == nums[a-1]) continue;

            for(int b=a+1; b<n; b++) {
                if(b>a+1 && nums[b] == nums[b-1]) continue;
                ll sum = nums[a]+nums[b];
                // 当前题约束下前两数相加仍安全；迁移模板时更推荐在第一次加法前显式转成 long long。

                int c=b+1, d=n-1;
                while(c < d) {
                    if(sum + nums[c] + nums[d] < target) {
                        c++;
                    } else if(sum + nums[c] + nums[d] > target) {
                        d--;
                    } else {
                        ans.push_back({nums[a], nums[b], nums[c], nums[d]});
                        // 命中后跳过两侧重复值，避免重复四元组。
                        while(c < d && nums[c] == nums[c+1]) c++;
                        while(c < d && nums[d] == nums[d-1]) d--;
                        c++;
                        d--;
                    }
                }
            }
        }
        return ans;
    }
};
```

## 关键理解点

| 理解点 | 用户当前表现 | 影响 | 建议 |
| --- | --- | --- | --- |
| 四数降维 | 两层固定后使用左右指针。 | 方向正确，复杂度达到常见可接受解。 | 继续沿用“固定若干位 + 两侧收缩”的模板。 |
| 去重边界 | `a`、`b`、`c`、`d` 都有对应去重。 | 能避免重复四元组。 | 固定层去重条件写得正确，值得保留。 |
| 类型提升 | 已经用 `long long` 保存前两位之和，后续比较也在长整型中完成。 | 当前题约束下可通过；作为通用模板时，第一次加法前显式转型更稳。 | 写成 `(ll)nums[a] + nums[b]`，把类型提升位置前移。 |
| 剪枝 | 当前没有利用排序后的上下界提前跳过。 | 正确性不受影响，但会做一些无效扫描。 | 推荐加入最小可能和、最大可能和判断。 |

| 方案 | 优点 | 缺点 | 适用情况 |
| --- | --- | --- | --- |
| 用户解法 | 主体模板正确，去重完整，已经注意到四数和需要更宽类型。 | 类型提升可以更早；缺少边界剪枝。 | 可作为基础提交版本，建议再补剪枝和显式转型。 |

## 最优解法

1. 排序数组。
2. 枚举第一位 `a`，跳过重复值，并用最小四数和、最大四数和判断是否继续。
3. 枚举第二位 `b`，同样跳过重复值，并做当前层的上下界判断。
4. 固定前两位后，用 `c`、`d` 在剩余区间寻找目标和。
5. 所有求和都从第一次加法开始转成 `long long`，让模板迁移到更宽范围时也稳定。
6. 命中答案后跳过 `c`、`d` 的重复值，再同步收缩。

- 最优时间复杂度：`O(n^3)`
- 最优空间复杂度：`O(log n)` 到 `O(n)`，不计返回结果。

### 最优解代码

```cpp
using ll = long long;

class Solution {
public:
    vector<vector<int>> fourSum(vector<int>& nums, int target) {
        vector<vector<int>> ans;
        sort(nums.begin(), nums.end());

        int n = nums.size();
        for (int a = 0; a < n - 3; ++a) {
            if (a > 0 && nums[a] == nums[a - 1]) {
                continue;
            }
            // 排序后最小四数已经过大，后续 a 只会更大。
            if ((ll)nums[a] + nums[a + 1] + nums[a + 2] + nums[a + 3] > target) {
                break;
            }
            // 当前 a 搭配最大的三个数仍过小，只能换更大的 a。
            if ((ll)nums[a] + nums[n - 3] + nums[n - 2] + nums[n - 1] < target) {
                continue;
            }

            for (int b = a + 1; b < n - 2; ++b) {
                if (b > a + 1 && nums[b] == nums[b - 1]) {
                    continue;
                }
                if ((ll)nums[a] + nums[b] + nums[b + 1] + nums[b + 2] > target) {
                    break;
                }
                if ((ll)nums[a] + nums[b] + nums[n - 2] + nums[n - 1] < target) {
                    continue;
                }

                int c = b + 1;
                int d = n - 1;
                while (c < d) {
                    ll sum = (ll)nums[a] + nums[b] + nums[c] + nums[d];
                    if (sum < target) {
                        ++c;
                    } else if (sum > target) {
                        --d;
                    } else {
                        ans.push_back({nums[a], nums[b], nums[c], nums[d]});
                        // 固定前两位后，跳过两侧重复值避免重复四元组。
                        while (c < d && nums[c] == nums[c + 1]) {
                            ++c;
                        }
                        while (c < d && nums[d] == nums[d - 1]) {
                            --d;
                        }
                        ++c;
                        --d;
                    }
                }
            }
        }

        return ans;
    }
};
```

## 下一步建议

建议把这题的剪枝条件单独复盘一遍：最小可能和过大用 `break`，最大可能和过小用 `continue`；同时养成第一次加法前显式转成 `long long` 的习惯。
