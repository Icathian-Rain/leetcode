## 用户思路概述

1. 用 `l` 和 `r` 表示当前连续子数组窗口的左右边界。
2. 右指针每次纳入一个新元素，并把它累加到 `sum`。
3. 当 `sum >= target` 时，当前窗口已经满足要求，先用窗口长度更新 `ans`。
4. 之后从左侧移出 `nums[l]` 并推进 `l`，继续尝试得到更短的达标窗口。
5. 如果最终 `ans` 仍是哨兵值 `n + 1`，说明不存在达标子数组，返回 `0`。

## 用户解法复杂度

- 时间复杂度：`O(n)`
- 空间复杂度：`O(1)`
- 复杂度来源：每个元素最多被右指针加入一次、被左指针移出一次，没有额外线性存储。

## 用户代码注释版

> 只在点评文档中展示加注释版本；不要把这些注释写回 `src/*.cpp` 的用户原代码。

```cpp
class Solution {
public:
    int minSubArrayLen(int target, vector<int>& nums) {
        int n=nums.size();
        int ans=n+1;      // 用 n + 1 表示还没有找到任何达标窗口。
        int sum=0;        // 当前窗口 nums[l..r] 的元素和。
        for(int l=0, r=0; r<n; r++) {
            sum += nums[r];   // 右端扩张，先让窗口包含 nums[r]。
            while(l<=r && sum >= target) {
                // 当前窗口满足条件，记录长度后继续缩左边界。
                ans = min(ans, r-l+1);
                sum -= nums[l];
                l++;
            }
        }
        return ans==n+1 ? 0: ans;
    }
};
```

## 关键理解点

| 理解点 | 用户当前表现 | 影响 | 建议 |
| --- | --- | --- | --- |
| 窗口可收缩条件 | 能在 `sum >= target` 时持续收缩左边界。 | 抓住了正数数组里窗口和随右扩张增大、随左收缩减小的核心性质。 | 复盘时把“为什么可以一直缩到不达标”为一句固定解释。 |
| 答案更新时机 | 在每次达标后、移出左端前更新答案。 | 能避免错过最短达标窗口。 | 保持“先记录，再收缩”的顺序。 |
| 边界与返回值 | 用 `n + 1` 作为哨兵并最终转成 `0`。 | 能正确处理不存在答案的情况。 | 可以把 `sum` 写成 `long long`，对更大约束更稳。 |

## 算法优缺点

| 方案 | 优点 | 缺点 | 适用情况 |
| --- | --- | --- | --- |
| 用户解法 | 标准可变窗口，逻辑短，复杂度达到最优。 | `sum` 用 `int` 在本题约束下通常够用，但泛化时不如 `long long` 稳。 | 适合所有元素为正数、目标是最短达标连续段的题。 |
| 推荐最优解 | 与用户思路一致，变量命名更强调窗口含义，累加值更稳健。 | 本质上没有降低复杂度，主要是表达和泛化性优化。 | 适合作为后续“达标后尽量收缩”题型模板。 |

## 最优解法

1. 用 `left` 和 `right` 维护当前窗口 `[left, right]`。
2. 每次把 `nums[right]` 加入窗口和。
3. 只要窗口和达到目标，就更新最短长度。
4. 更新后移出左端元素，让窗口继续尝试变短。
5. 扫描结束后，如果没有记录过答案，返回 `0`。

- 最优时间复杂度：`O(n)`
- 最优空间复杂度：`O(1)`

### 最优解代码

```cpp
class Solution {
public:
    int minSubArrayLen(int target, vector<int>& nums) {
        int n = nums.size();
        int ans = n + 1;
        long long windowSum = 0;
        int left = 0;

        for (int right = 0; right < n; ++right) {
            windowSum += nums[right];
            while (windowSum >= target) {
                // 当前窗口已达标，先记录长度，再收缩左边界寻找更短答案。
                ans = min(ans, right - left + 1);
                windowSum -= nums[left];
                ++left;
            }
        }

        return ans == n + 1 ? 0 : ans;
    }
};
```
