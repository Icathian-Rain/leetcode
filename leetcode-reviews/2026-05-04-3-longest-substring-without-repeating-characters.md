## 用户思路概述

1. 用 `cnt` 统计当前窗口中每个字符出现次数。
2. 右指针每次加入 `s[r]`，让窗口向右扩张。
3. 如果新加入的字符导致次数大于 `1`，说明窗口出现重复。
4. 通过不断移出 `s[l]` 并推进 `l`，直到 `s[r]` 在窗口中只出现一次。
5. 每次窗口恢复无重复后，用当前窗口长度更新最长答案。

## 用户解法复杂度

- 时间复杂度：`O(n)`
- 空间复杂度：`O(1)`，字符表大小固定；如果按字符集大小记，也可写作 `O(k)`。
- 复杂度来源：左右指针都只单调向右移动，`cnt` 只保存当前窗口字符频次。

## 用户代码注释版

> 只在点评文档中展示加注释版本；不要把这些注释写回 `src/*.cpp` 的用户原代码。

```cpp
class Solution {
public:
    int lengthOfLongestSubstring(string s) {
        int n=s.length();
        vector<int> cnt(128, 0); // 当前窗口内每个 ASCII 字符的出现次数。
        int ans=0;
        for(int l=0, r=0; r<n; r++) {
            cnt[s[r]]++;         // 右端加入新字符。
            while(cnt[s[r]] > 1) {
                // 只有新加入字符重复时，窗口才非法；缩左直到它不重复。
                cnt[s[l]]--;
                l++;
            }
            ans=max(ans, r-l+1); // 当前窗口合法，更新最长长度。
        }
        return ans;
    }
};
```

## 关键理解点

| 理解点 | 用户当前表现 | 影响 | 建议 |
| --- | --- | --- | --- |
| 窗口合法性 | 用频次数组维护“窗口内无重复”。 | 正确命中本题核心，能在线性时间完成。 | 继续保持先定义合法窗口，再写收缩条件的习惯。 |
| 收缩触发点 | 只检查刚加入的 `s[r]` 是否重复。 | 逻辑是正确的，因为加入前窗口已经合法。 | 复盘时要说清这个前提，否则容易误以为要扫描整个窗口。 |
| 字符下标范围 | 使用 `vector<int> cnt(128)`。 | 本题常见输入可过；泛化到非 ASCII 或 `char` 为负的环境时不够稳。 | 更通用写法可以使用 `256` 并把字符转成 `unsigned char`。 |

## 算法优缺点

| 方案 | 优点 | 缺点 | 适用情况 |
| --- | --- | --- | --- |
| 用户解法 | 频次窗口直观，和后续频次类题迁移关系很强。 | 遇到重复字符时逐步收缩，代码上略多一个 `while`。 | 适合学习窗口合法性和频次维护。 |
| 推荐最优解 | 用上次出现位置直接跳左边界，更新更紧凑。 | 需要理解 `left` 不能回退，只能取更靠右的位置。 | 适合本题的最短表达，也适合复盘“重复字符定位”。 |

## 最优解法

1. 用 `lastSeen` 记录每个字符上一次出现的位置。
2. `left` 表示当前无重复窗口的左边界。
3. 扫描到 `right` 时，如果当前字符上次出现位置仍在窗口内，就把 `left` 跳到那个位置之后。
4. 更新当前字符的最新位置。
5. 用 `[left, right]` 的长度更新答案。

- 最优时间复杂度：`O(n)`
- 最优空间复杂度：`O(1)`，固定字符表；按字符集大小可记为 `O(k)`。

### 最优解代码

```cpp
class Solution {
public:
    int lengthOfLongestSubstring(string s) {
        vector<int> lastSeen(256, -1);
        int left = 0;
        int ans = 0;

        for (int right = 0; right < (int)s.size(); ++right) {
            unsigned char ch = static_cast<unsigned char>(s[right]);
            if (lastSeen[ch] >= left) {
                // 重复字符落在当前窗口内，左边界直接跳到上次位置之后。
                left = lastSeen[ch] + 1;
            }
            lastSeen[ch] = right;
            ans = max(ans, right - left + 1);
        }

        return ans;
    }
};
```

## 对比与改进方向

| 对比项 | 用户代码 | 最优解代码 | 改进方向 |
| --- | --- | --- | --- |
| 状态定义 | `cnt` 记录当前窗口字符次数。 | `lastSeen` 记录每个字符最近位置。 | 两种都最优；位置表更适合本题，频次表更适合后续窗口题。 |
| 更新逻辑 | 重复时逐个移出左端字符。 | 重复时左边界一次跳过旧位置。 | 理解 `left = max(left, lastSeen[ch] + 1)` 的不回退原则。 |
| 边界处理 | 空串返回 `0`，普通 ASCII 输入稳定。 | 空串返回 `0`，字符下标更稳。 | 泛化时优先避免用有符号 `char` 直接做数组下标。 |
| 复杂度 | `O(n)` / `O(1)` | `O(n)` / `O(1)` | 已达到最优。 |
