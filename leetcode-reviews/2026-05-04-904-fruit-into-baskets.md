## 用户思路概述

1. 用 `unordered_map<int, int> cnt` 统计当前窗口内每种水果的数量。
2. 右指针逐个纳入水果，并增加对应类型的计数。
3. 当窗口内水果类型超过 `2` 时，从左侧持续移出水果。
4. 某种水果计数降到 `0` 后，从哈希表中删除该类型，让 `cnt.size()` 始终等于窗口内真实类型数。
5. 每次窗口恢复到最多两类后，用窗口长度更新最大答案。

## 用户解法复杂度

- 时间复杂度：`O(n)`
- 空间复杂度：`O(1)`，窗口内最多保留少量类型计数；按类型上限泛化可记为 `O(k)`。
- 复杂度来源：左右指针都只向右移动，哈希表维护当前窗口内的水果类型和数量。

## 用户代码注释版

> 只在点评文档中展示加注释版本；不要把这些注释写回 `src/*.cpp` 的用户原代码。

```cpp
class Solution {
public:
    int totalFruit(vector<int>& fruits) {
        int n=fruits.size();
        unordered_map<int, int> cnt; // 当前窗口内每种水果的数量。

        int ans=1;                   // 题目常见约束下 fruits 非空；泛化可写成 0。
        for(int l=0, r=0; r<n; r++) {
            cnt[fruits[r]]++;        // 右端加入一个水果。
            while(cnt.size() > 2) {
                // 类型数超过篮子数量，持续移出左端水果直到重新合法。
                cnt[fruits[l]]--;
                if(cnt[fruits[l]] == 0) {
                    cnt.erase(fruits[l]);
                }
                l++;
            }
            ans=max(ans, r-l+1);     // 当前窗口合法，更新最多水果数。
        }
        return ans;
    }
};
```

## 最优解法

1. 用哈希表记录当前窗口内每种水果的数量。
2. 右指针逐个加入水果。
3. 如果不同水果类型超过两个，就不断移出左端水果。
4. 移出后若某类水果数量为 `0`，立刻删除该键。
5. 窗口合法后更新最大长度。

- 最优时间复杂度：`O(n)`
- 最优空间复杂度：`O(1)`，本题最多维护三个左右的类型；泛化为最多 `K` 类时是 `O(K)`。

### 最优解代码

```cpp
class Solution {
public:
    int totalFruit(vector<int>& fruits) {
        unordered_map<int, int> count;
        int left = 0;
        int ans = 0;

        for (int right = 0; right < (int)fruits.size(); ++right) {
            ++count[fruits[right]];
            while (count.size() > 2) {
                // 窗口内类型超过两个，持续移出左端水果直到重新合法。
                --count[fruits[left]];
                if (count[fruits[left]] == 0) {
                    count.erase(fruits[left]);
                }
                ++left;
            }
            ans = max(ans, right - left + 1);
        }

        return ans;
    }
};
```
