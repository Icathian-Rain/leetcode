## 用户思路概述

1. 用 `cnt0` 统计当前窗口里 `0` 的数量。
2. 右指针逐个扩张，把新的元素纳入窗口。
3. 如果窗口内 `0` 的数量超过 `k`，就移动左指针，并在移出 `0` 时同步减少 `cnt0`。
4. 当窗口重新满足“最多包含 `k` 个 `0`”后，用当前窗口长度更新答案。

## 用户解法复杂度

- 时间复杂度：`O(n)`
- 空间复杂度：`O(1)`
- 复杂度来源：每个元素最多被右指针加入一次、被左指针移出一次，只维护常数个变量。

## 用户代码注释版

> 只在点评文档中展示加注释版本；不要把这些注释写回 `src/*.cpp` 的用户原代码。

```cpp
class Solution {
public:
    int longestOnes(vector<int>& nums, int k) {
        int n=nums.size();
        int cnt0 = 0; // 当前窗口内 0 的数量，也就是需要翻转的数量。
        int ans = 0;
        for(int l=0, r=0; r<n; r++) {
            if(nums[r] == 0) cnt0++;
            while(cnt0 > k) {
                // 0 的数量超出 k，窗口非法；移出左端直到重新合法。
                if(nums[l] == 0) cnt0--;
                l++;
            }

            // 此时窗口满足最多翻转 k 个 0，可以更新最长长度。
            ans = max(ans, r-l+1);
        }
        return ans;
    }
};
```

## 最优解法

1. 维护一个左右边界组成的连续窗口。
2. `zeroCount` 记录窗口内 `0` 的数量，也就是把窗口变成全 `1` 所需的翻转次数。
3. 右端扩张后，如果 `zeroCount > k`，持续移动左端直到窗口重新合法。
4. 每次窗口合法后，用窗口长度更新最长答案。

- 最优时间复杂度：`O(n)`
- 最优空间复杂度：`O(1)`

### 最优解代码

```cpp
class Solution {
public:
    int longestOnes(vector<int>& nums, int k) {
        int left = 0;
        int zeroCount = 0;
        int ans = 0;

        for (int right = 0; right < (int)nums.size(); ++right) {
            if (nums[right] == 0) {
                ++zeroCount;
            }

            while (zeroCount > k) {
                // 窗口内 0 的数量超限，移动左边界直到重新合法。
                if (nums[left] == 0) {
                    --zeroCount;
                }
                ++left;
            }

            ans = max(ans, right - left + 1);
        }

        return ans;
    }
};
```
