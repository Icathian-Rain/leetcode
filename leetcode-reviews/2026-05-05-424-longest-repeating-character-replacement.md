## 用户思路概述

1. 用 `cnt` 统计当前窗口中每个大写字母出现次数。
2. 用 `maxCnt` 记录窗口扩张过程中出现过的最高字符频次。
3. 右指针每加入一个字符，就更新对应频次和 `maxCnt`。
4. 如果当前窗口长度减去 `maxCnt` 大于 `k`，说明要替换的字符数量超限，移动左边界。
5. 每一轮用当前窗口长度更新答案。

## 用户解法复杂度

- 时间复杂度：`O(n)`
- 空间复杂度：`O(1)`，只使用 26 个大写字母的频次数组。
- 复杂度来源：每个字符最多被右指针加入一次、被左指针移出一次；频次数组大小固定。

## 用户代码注释版

> 只在点评文档中展示加注释版本；不要把这些注释写回 `src/*.cpp` 的用户原代码。

```cpp
class Solution {
public:
    int characterReplacement(string s, int k) {
        int n=s.length();
        vector<int> cnt(26, 0);
        int maxCnt = 0; // 当前扫描过程中窗口内某个字符的历史最高频次。

        int ans=0;
        for(int l=0, r=0; r<n; r++) {
            cnt[s[r]-'A']++;
            maxCnt = max(maxCnt, cnt[s[r]-'A']);
            if(r-l+1-maxCnt > k) {
                // 非主字符数量超过 k，窗口需要右移左边界。
                cnt[s[l]-'A']--;
                l++;
            }
            ans = max(ans, r-l+1);
        }
        return ans;
    }
};
```

## 关键理解点

| 理解点 | 用户当前表现 | 影响 | 建议 |
| --- | --- | --- | --- |
| 替换次数判断 | 用 `窗口长度 - 最高频字符数` 判断需要替换多少字符。 | 建模准确，是本题最关键的一步。 | 复盘时先解释“保留窗口中最多的那个字符，其余都替换”。 |
| `maxCnt` 不回退 | 左边界右移时没有重新计算 `maxCnt`。 | 这是可接受且常见的最优写法，答案长度不会被低估。 | 要能说明 `maxCnt` 作为历史最大值只影响窗口收缩节奏，不会制造更大的错误答案。 |
| 收缩方式 | 超限时用 `if` 只移动一次左边界。 | 在这类写法下正确，因为每轮右边界只增加 1，窗口最多需要同步右移 1。 | 若改成实时重算最高频，可以用 `while`，但当前写法无需改。 |

## 最优解法

1. 维护窗口内每个大写字母的出现次数。
2. `maxCount` 保存扫描过程中窗口内单字符最高频次。
3. 当前窗口想变成全相同字符，至少需要替换 `窗口长度 - maxCount` 个字符。
4. 如果替换次数超过 `k`，就移出左端字符并右移左边界。
5. 每轮窗口调整后，用窗口长度更新答案。

- 最优时间复杂度：`O(n)`
- 最优空间复杂度：`O(1)`

### 最优解代码

```cpp
class Solution {
public:
    int characterReplacement(string s, int k) {
        vector<int> count(26, 0);
        int left = 0;
        int maxCount = 0;
        int ans = 0;

        for (int right = 0; right < (int)s.size(); ++right) {
            int idx = s[right] - 'A';
            ++count[idx];
            maxCount = max(maxCount, count[idx]);

            if (right - left + 1 - maxCount > k) {
                // 替换次数超限时右移左边界；maxCount 保持历史最大值即可。
                --count[s[left] - 'A'];
                ++left;
            }

            ans = max(ans, right - left + 1);
        }

        return ans;
    }
};
```
