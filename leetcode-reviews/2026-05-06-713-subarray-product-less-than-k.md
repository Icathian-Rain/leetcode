## 用户思路概述

1. 用 `mul` 维护当前窗口 `[l, r]` 内所有元素的乘积。
2. 右指针逐个扩张，把 `nums[r]` 乘入窗口。
3. 当窗口乘积 `mul >= k` 时，持续移出左端元素，直到窗口重新满足乘积小于 `k`。
4. 窗口恢复合法后，以 `r` 作为右端点的所有后缀子数组都合法，因此累加 `r - l + 1`。

## 用户解法复杂度

- 时间复杂度：`O(n)`
- 空间复杂度：`O(1)`
- 复杂度来源：每个元素最多被右指针乘入一次、被左指针除出一次，只维护常数个变量。

## 用户代码注释版

> 只在点评文档中展示加注释版本；不要把这些注释写回 `src/*.cpp` 的用户原代码。

```cpp
class Solution {
public:
    int numSubarrayProductLessThanK(vector<int>& nums, int k) {
        int n=nums.size();
        int mul=1; // 当前窗口内元素乘积。
        int ans=0;
        for(int l=0, r=0; r<n; r++) {
            mul *= nums[r]; // 右端元素进入窗口。
            while(l <= r && mul >= k) {
                // 乘积不再小于 k，窗口非法；持续移出左端直到恢复合法。
                mul /= nums[l];
                l++;
            }

            // 合法窗口内以 r 结尾的后缀子数组数量为 r-l+1。
            ans += (r-l+1);
        }
        return ans;
    }
};
```

## 关键理解点

| 理解点 | 用户当前表现 | 影响 | 建议 |
| --- | --- | --- | --- |
| 窗口合法性 | 用乘积是否小于 `k` 判断窗口是否合法。 | 建模准确，能支撑线性滑动。 | 复盘时先说明本题数组元素为正，因此左端右移会让乘积单调不增。 |
| 计数时机 | 收缩到合法后累加 `r - l + 1`。 | 正确抓住“以右端点结尾”的批量计数方式。 | 遇到统计子数组数量时，优先想清楚固定一端后能一次贡献多少答案。 |
| 边界处理 | `k <= 1` 时通过 `while (l <= r && mul >= k)` 最终贡献 0。 | 在正数约束下结果正确，但依赖循环把窗口清空，表达不够直接。 | 推荐开头显式 `if (k <= 1) return 0;`，避免读者误解和不必要的除法。 |

## 最优解法

1. 如果 `k <= 1`，由于 `nums[i]` 都是正整数，不可能存在乘积严格小于 `k` 的非空子数组，直接返回 `0`。
2. 维护一个乘积严格小于 `k` 的连续窗口。
3. 右端扩张后，如果乘积超限，就移动左端并把移出的元素从乘积中除掉。
4. 当窗口重新合法时，所有以 `right` 结尾、起点在 `[left, right]` 内的子数组都合法，一次性累加数量。

- 最优时间复杂度：`O(n)`
- 最优空间复杂度：`O(1)`

### 最优解代码

```cpp
class Solution {
public:
    int numSubarrayProductLessThanK(vector<int>& nums, int k) {
        if (k <= 1) {
            return 0;
        }

        int left = 0;
        int product = 1;
        int ans = 0;

        for (int right = 0; right < (int)nums.size(); ++right) {
            product *= nums[right];
            while (product >= k) {
                // 保持窗口乘积严格小于 k，之后以 right 结尾的子数组都合法。
                product /= nums[left];
                ++left;
            }

            ans += right - left + 1;
        }

        return ans;
    }
};
```
