## 用户思路概述

1. 用一个队列 `q` 保存全部元素，但通过 `push` 时旋转队列，让最新压入的元素移动到队首。
2. `pop()` 和 `top()` 都直接访问队首，因此对外表现为后进先出。
3. `empty()` 直接检查底层队列是否为空，接口语义清晰。

## 用户解法复杂度

- 时间复杂度：`push` 为 `O(n)`，`pop`、`top`、`empty` 为 `O(1)`。
- 空间复杂度：`O(n)`。
- 复杂度来源：每次 `push` 需要把旧元素轮转一遍，队列本身保存全部元素。

## 用户代码注释版

```cpp
class MyStack {
    queue<int> q; // 队首始终维护为当前栈顶
public:
    void push(int x) {
        int n = q.size();
        q.push(x); // 新元素先进入队尾
        for (int i = 0; i < n; i++) {
            q.push(q.front()); // 把旧元素依次移到新元素后面
            q.pop();
        }
    }

    int pop() {
        int ret = q.front(); // 因为 push 已旋转，队首就是栈顶
        q.pop();
        return ret;
    }

    int top() {
        return q.front();
    }

    bool empty() {
        return q.empty();
    }
};
```

## 最优解法

1. 每次插入新元素后，把插入前的所有旧元素依次移到队尾。
2. 这样队首始终是最近插入且尚未弹出的元素。
3. `pop`、`top` 只需要操作队首即可。

- 最优时间复杂度：`push` 为 `O(n)`，其余接口为 `O(1)`
- 最优空间复杂度：`O(n)`

### 最优解代码

```cpp
class MyStack {
    queue<int> q;

public:
    MyStack() = default;

    void push(int x) {
        int oldSize = q.size();
        q.push(x);
        // 旋转旧元素，使队首始终等价于栈顶。
        while (oldSize--) {
            q.push(q.front());
            q.pop();
        }
    }

    int pop() {
        int value = q.front();
        q.pop();
        return value;
    }

    int top() {
        return q.front();
    }

    bool empty() {
        return q.empty();
    }
};
```
