## 用户思路概述

1. 把环形数组展开成长度 `2*n` 的扫描过程，用 `i % n` 映射回原数组下标。
2. 从右向左扫描，栈中保存右侧可能成为下一个更大值的候选值。
3. 对当前值，弹出所有小于等于它的候选值，保证剩下的栈顶严格更大。
4. 如果栈为空，当前下标答案为 `-1`；否则答案为栈顶值。
5. 每次处理后把当前值入栈。

## 用户解法复杂度

- 时间复杂度：`O(n)`
- 空间复杂度：`O(n)`
- 复杂度来源：虽然循环跑 `2n` 次，但每轮栈操作摊还为常数，栈规模最多线性。

## 用户代码注释版

```cpp
class Solution {
public:
    vector<int> nextGreaterElements(vector<int>& nums) {
        int n=nums.size();
        vector<int> ans(n, 0);
        stack<int> st; // 保存环形右侧候选更大值。
        for(int i=2*n-1; i>=0; i--) {
            int num=nums[i%n];
            while(!st.empty() && num >= st.top()) {
                st.pop(); // 小于等于当前值的候选不可能成为当前值答案。
            }
            if(st.empty()) {
                ans[i%n] = -1;
            } else {
                ans[i%n] = st.top();
            }
            st.push(num);
        }
        return ans;
    }
};
```

## 关键理解点

| 理解点 | 用户当前表现 | 影响 | 建议 |
| --- | --- | --- | --- |
| 环形处理 | 用 `2*n` 次扫描模拟环形右侧。 | 思路正确，能覆盖跨尾到头的答案。 | 复盘时区分“扫描两轮”和“每个元素是否应该入栈两次”。 |
| 严格更大 | 使用 `num >= st.top()` 弹出小于等于当前值。 | 正确处理相等元素不算更大。 | 这点比 `496` 更重要，因为本题允许重复值。 |
| 答案回填 | 每轮都写 `ans[i % n]`。 | 最终正确，但同一下标会在两轮中被写两次。 | 推荐只让每个下标入栈一次，第二轮只用于结算等待下标。 |

## 算法优缺点

| 方案 | 优点 | 缺点 | 适用情况 |
| --- | --- | --- | --- |
| 用户解法 | 简洁，右向左候选值写法正确。 | 同一下标两轮都会写答案，状态解释稍绕。 | 可通过本题，适合快速实现。 |
| 推荐最优解 | 保存下标，每个下标只入栈一次，第二轮只负责帮助结算。 | 代码比保存值略长。 | 更适合迁移到需要回填答案的位置题。 |

## 最优解法

1. 初始化答案为全 `-1`。
2. 用栈保存还没有找到下一个更大值的下标。
3. 从左到右扫描 `2*n` 次，用 `i % n` 得到环形下标。
4. 当前值如果大于栈顶下标对应的值，就回填栈顶答案并弹出。
5. 只有第一轮把下标入栈，第二轮只是帮助这些下标找到跨环答案。

- 最优时间复杂度：`O(n)`
- 最优空间复杂度：`O(n)`

### 最优解代码

```cpp
class Solution {
public:
    vector<int> nextGreaterElements(vector<int>& nums) {
        int n = nums.size();
        vector<int> ans(n, -1);
        vector<int> indexes;

        for (int i = 0; i < 2 * n; ++i) {
            int index = i % n;
            while (!indexes.empty() && nums[indexes.back()] < nums[index]) {
                ans[indexes.back()] = nums[index];
                indexes.pop_back();
            }
            if (i < n) {
                // 每个下标只入栈一次，第二轮只用于帮助它们找到环形右侧答案。
                indexes.push_back(index);
            }
        }

        return ans;
    }
};
```
