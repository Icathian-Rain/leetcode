## 用户思路概述

1. 从右向左扫描温度数组，用栈保存右侧可能成为“下一个更高温度”的下标。
2. 对当前温度 `temperatures[i]`，弹出所有温度小于等于它的下标，因为这些天不会成为当前天的答案。
3. 弹出结束后，如果栈不为空，栈顶就是右侧最近的更高温度下标，答案为 `st.top() - i`。
4. 把当前下标入栈，供左侧更早的天使用。

## 用户解法复杂度

- 时间复杂度：`O(n)`
- 空间复杂度：`O(n)`
- 复杂度来源：每个下标最多入栈和出栈一次；答案数组和栈都为线性规模。

## 用户代码注释版

```cpp
class Solution {
public:
    vector<int> dailyTemperatures(vector<int>& temperatures) {
        int n=temperatures.size();
        stack<int> st; // 保存右侧候选更高温度的下标。
        vector<int> ans(n, 0);
        for(int i=n-1; i>=0; i--) {
            int tem = temperatures[i];
            while(!st.empty() && tem>=temperatures[st.top()]) {
                st.pop(); // 温度不高于当前天，不能作为当前天答案。
            }
            if(!st.empty()) {
                ans[i] = st.top() - i; // 保存下标才能计算等待天数。
            }
            st.push(i);
        }
        return ans;
    }
};
```

## 关键理解点

| 理解点 | 用户当前表现 | 影响 | 建议 |
| --- | --- | --- | --- |
| 保存下标 | 栈中保存下标而不是温度值。 | 正确，因为答案要求天数差。 | 这是本题和 `496/503` 的关键迁移点。 |
| 严格更高 | 弹出小于等于当前温度的候选。 | 正确处理相等温度不算更暖。 | 遇到“更大/更高”题，要检查是否严格。 |
| 扫描方向 | 右向左直接寻找右侧最近更高温度。 | 逻辑正确且简洁。 | 也可以练左向右回填版本，和第 5 天模板更统一。 |

## 算法优缺点

| 方案 | 优点 | 缺点 | 适用情况 |
| --- | --- | --- | --- |
| 用户解法 | 经典右向左单调栈，复杂度最优。 | 复盘时要解释为什么栈顶就是最近更高温度。 | 适合直接提交。 |
| 推荐最优解 | 左向右回填等待下标，和“等待被更大值解决”的模板一致。 | 本质复杂度相同。 | 更适合迁移到答案回填类题。 |

## 最优解法

1. 用栈保存还没有遇到更高温度的日期下标。
2. 从左到右扫描温度，当前温度如果高于栈顶日期温度，就能解决栈顶日期的答案。
3. 持续弹出所有被当前温度解决的日期，并回填等待天数。
4. 当前日期入栈，等待未来更高温度。
5. 扫描结束后，仍未解决的日期答案保持 `0`。

- 最优时间复杂度：`O(n)`
- 最优空间复杂度：`O(n)`

### 最优解代码

```cpp
class Solution {
public:
    vector<int> dailyTemperatures(vector<int>& temperatures) {
        int n = temperatures.size();
        vector<int> ans(n, 0);
        vector<int> indexes;

        for (int i = 0; i < n; ++i) {
            while (!indexes.empty() && temperatures[indexes.back()] < temperatures[i]) {
                int previous = indexes.back();
                indexes.pop_back();
                // 保存下标才能回填等待天数，而不只是知道更高温度是多少。
                ans[previous] = i - previous;
            }
            indexes.push_back(i);
        }

        return ans;
    }
};
```
