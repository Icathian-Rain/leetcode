## 用户思路概述

1. 把每辆车整理成 `{position, speed}`，并按位置从小到大排序。
2. 从离起点更远到更近的顺序计算每辆车到达终点的时间 `t`。
3. 用栈保存若干到达时间。
4. 当当前时间 `t >= st.top()` 时弹出栈顶，否则保留。
5. 最后用栈大小作为车队数量。

## 用户解法复杂度

- 时间复杂度：`O(n log n)`
- 空间复杂度：`O(n)`
- 复杂度来源：排序占主导；栈最多保存所有车辆到达时间。

## 用户代码注释版

```cpp
using pii=pair<int, int>;
class Solution {
public:
    int carFleet(int target, vector<int>& position, vector<int>& speed) {
        int n=position.size();
        vector<pii> car;
        for(int i=0; i<n; i++) {
            car.push_back({position[i], speed[i]});
        }
        sort(car.begin(), car.end()); // 按位置从小到大：离终点远的车在前。

        stack<double> st;
        for(int i=0; i<n; i++) {
            double t = (double)(target - car[i].first) / car[i].second;
            while(!st.empty() && t >= st.top()) {
                // 这里会把前面较远车辆的时间弹掉，合并方向容易反。
                st.pop();
            }
            st.push(t);
        }
        return st.size();
    }
};
```

## 关键理解点

| 理解点 | 用户当前表现 | 影响 | 建议 |
| --- | --- | --- | --- |
| 扫描方向 | 从位置小到大扫描。 | 会先处理离终点更远的车，无法可靠判断它会追上前车形成的车队。 | 推荐从离终点最近的车往后扫描。 |
| 合并条件 | 使用 `t >= st.top()` 弹出已有时间。 | 对标准样例 `target=12` 会得到 `3`，正确答案是 `2`。 | 到达时间小于等于前方车队时间时，后车会并入前方车队。 |
| 状态含义 | 栈里保存到达时间，但栈顶含义不稳定。 | 正确性证明困难。 | 用一个 `slowestTime` 表示前方车队的到达时间上界即可。 |

## 算法优缺点

| 方案 | 优点 | 缺点 | 适用情况 |
| --- | --- | --- | --- |
| 用户解法 | 已经想到排序和到达时间，这是本题关键入口。 | 扫描方向和弹栈条件导致车队合并错误。 | 需要重写当前题。 |
| 推荐最优解 | 从离终点最近的车往后扫描，状态含义简单。 | 仍需排序。 | 适合本题直接提交和面试解释。 |

## 最优解法

1. 对每辆车计算到达终点所需时间。
2. 按位置从大到小排序，也就是先看离终点最近的车。
3. 维护当前最慢的前方车队到达时间 `slowestTime`。
4. 如果后面的车到达时间 `<= slowestTime`，说明它会追上前方车队，车队数不变。
5. 如果后面的车到达时间更大，说明它追不上前方车队，形成新车队。

- 最优时间复杂度：`O(n log n)`
- 最优空间复杂度：`O(n)`

### 最优解代码

```cpp
class Solution {
public:
    int carFleet(int target, vector<int>& position, vector<int>& speed) {
        int n = position.size();
        vector<pair<int, double>> cars;
        cars.reserve(n);

        for (int i = 0; i < n; ++i) {
            double time = (double)(target - position[i]) / speed[i];
            cars.push_back({position[i], time});
        }
        sort(cars.begin(), cars.end(), greater<pair<int, double>>());

        int fleets = 0;
        double slowestTime = 0.0;
        for (auto [pos, time] : cars) {
            if (time > slowestTime) {
                // 从离终点最近的车往后看，只有到达时间更晚才会形成新车队。
                ++fleets;
                slowestTime = time;
            }
        }

        return fleets;
    }
};
```

## 对比与改进方向

| 对比项 | 用户代码 | 最优解代码 | 改进方向 |
| --- | --- | --- | --- |
| 状态定义 | 栈保存已扫描车辆到达时间。 | `slowestTime` 保存前方车队到达时间。 | 状态要能代表“前方车队”，不是单辆车历史。 |
| 更新逻辑 | 从远到近扫描并弹出时间。 | 从近到远扫描，慢车队时间单调更新。 | 改变扫描方向，合并逻辑会自然很多。 |
| 边界处理 | 单车样例可过，标准多车样例有风险。 | 单车、多车、追不上和追得上都统一处理。 | 用标准样例手推到达时间验证。 |
| 复杂度 | `O(n log n)` / `O(n)` | `O(n log n)` / `O(n)` | 复杂度相同，关键是正确性。 |
