## 用户思路概述

1. 用队列 `q` 保存仍可能落在最近 3000 毫秒窗口内的请求时间。
2. 每次 `ping(t)` 先把当前请求时间 `t` 入队。
3. 队首是最早的请求时间，如果它小于 `t - 3000`，就已经过期，需要出队。
4. 持续清理过期请求后，队列中剩余元素数量就是最近请求次数。

## 用户解法复杂度

- 单次 `ping` 摊还时间复杂度：`O(1)`
- 空间复杂度：`O(W)`，其中 `W` 是当前时间窗口内请求数量
- 复杂度来源：每个请求时间最多入队一次、出队一次；队列只保留未过期请求。

## 用户代码注释版

```cpp
class RecentCounter {
public:
    queue<int> q; // 保存当前仍在 [t - 3000, t] 窗口内的请求。
    RecentCounter() {
    }

    int ping(int t) {
        q.push(t);
        while(!q.empty() && q.front() < t-3000) {
            q.pop(); // 队首最早，过期请求只会从队首离开。
        }
        return q.size();
    }
};
```

## 最优解法

1. 请求按时间递增到来，用队列保存仍在窗口内的请求。
2. 每次加入当前请求。
3. 清理所有早于 `t - 3000` 的请求。
4. 返回队列长度。

- 最优摊还时间复杂度：`O(1)`
- 最优空间复杂度：`O(W)`

### 最优解代码

```cpp
class RecentCounter {
    queue<int> requests;

public:
    RecentCounter() {
    }

    int ping(int t) {
        requests.push(t);
        while (!requests.empty() && requests.front() < t - 3000) {
            // 队首永远是最早请求，过期请求只会从队首删除。
            requests.pop();
        }
        return requests.size();
    }
};
```
