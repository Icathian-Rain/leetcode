## 用户思路概述

1. `middleList` 用快慢指针找到前半段尾部。
2. `reverse` 原地反转后半段链表。
3. `reorderList` 中先把链表拆成前后两段，并用 `mid->next = nullptr` 切断前半段尾部。
4. 反转后半段后，调用 `mergeList` 交替拼接两个链表。
5. `mergeList` 每轮保存两个后继入口，再把后半段当前节点插到前半段当前节点之后。

## 用户解法复杂度

- 时间复杂度：`O(n)`
- 空间复杂度：`O(1)`
- 复杂度来源：找中点、反转后半段、交替合并都各自线性完成，只额外维护常数个指针。

## 用户代码注释版

```cpp
class Solution {
public:
    ListNode* middleList(ListNode *head) {
        ListNode *slow = head;
        ListNode *fast = head;
        while(fast->next != nullptr && fast->next->next != nullptr) {
            slow = slow->next;
            fast = fast->next->next;
        }
        return slow; // 返回前半段尾部。
    }

    ListNode* reverse(ListNode *head) {
        ListNode* pre =nullptr;
        ListNode* cur = head;
        while(cur != nullptr) {
            ListNode* nxt = cur->next; // 保存后继入口。
            cur->next = pre;
            pre = cur;
            cur = nxt;
        }
        return pre;
    }

    void mergeList(ListNode* h1, ListNode* h2) {
        ListNode* p1=h1, *p2 = h2;

        while(p1 != nullptr && p2!= nullptr) {
            ListNode* nxt1 = p1->next;
            ListNode* nxt2 = p2->next;
            
            p1->next = p2;  // 后半段节点插到前半段节点后面。
            p1 = nxt1;

            p2->next = nxt1; // 插入节点接回前半段后续入口。
            p2 = nxt2;
        }
    }

    void reorderList(ListNode* head) {
        if(head == nullptr) return ;
        ListNode* mid = middleList(head);
        ListNode* h1 = head;
        ListNode* h2 = mid->next;
        mid->next = nullptr; // 切断前后两段，避免合并后形成环。
        h2 = reverse(h2);
        mergeList(h1, h2);
        return ;
    }
};
```

## 最优解法

1. 用快慢指针找到前半段尾部。
2. 从前半段尾部之后切开链表。
3. 原地反转后半段。
4. 将前半段和反转后的后半段交替合并。
5. 合并前切断、合并中保存两个后继入口，防止丢节点或成环。

- 最优时间复杂度：`O(n)`
- 最优空间复杂度：`O(1)`

### 最优解代码

```cpp
class Solution {
    ListNode* firstHalfTail(ListNode* head) {
        ListNode* slow = head;
        ListNode* fast = head;

        while (fast->next != nullptr && fast->next->next != nullptr) {
            slow = slow->next;
            fast = fast->next->next;
        }

        return slow;
    }

    ListNode* reverseList(ListNode* head) {
        ListNode* previous = nullptr;
        ListNode* current = head;

        while (current != nullptr) {
            ListNode* nextNode = current->next;
            current->next = previous;
            previous = current;
            current = nextNode;
        }

        return previous;
    }

    void mergeAlternating(ListNode* first, ListNode* second) {
        while (second != nullptr) {
            ListNode* nextFirst = first->next;
            ListNode* nextSecond = second->next;

            // second 已是反转后的后半段头部，交替插入到 first 后面。
            first->next = second;
            second->next = nextFirst;
            first = nextFirst;
            second = nextSecond;
        }
    }

public:
    void reorderList(ListNode* head) {
        if (head == nullptr || head->next == nullptr) {
            return;
        }

        ListNode* firstTail = firstHalfTail(head);
        ListNode* secondHead = reverseList(firstTail->next);
        firstTail->next = nullptr; // 先切断两段，避免合并时尾部残留形成环。
        mergeAlternating(head, secondHead);
    }
};
```
