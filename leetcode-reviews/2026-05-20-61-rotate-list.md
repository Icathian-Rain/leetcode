## 用户思路概述

1. 先处理空链表，避免后续访问空指针。
2. 遍历链表统计长度 `len`，同时记录原尾节点 `tail`。
3. 将 `k` 对长度取模，消除完整轮旋转。
4. 如果取模后为 0，直接返回原头。
5. 把尾节点接回头节点形成环，再找到新的尾节点并断开，返回新的头节点。

## 用户解法复杂度

- 时间复杂度：`O(n)`
- 空间复杂度：`O(1)`
- 复杂度来源：一次遍历求长度和尾节点，再移动到新尾节点位置。

## 用户代码注释版

```cpp
class Solution {
public:
    ListNode* rotateRight(ListNode* head, int k) {
        if(head == nullptr) return nullptr;
        ListNode*p = head;
        ListNode*tail;
        int len=0;

        while(p!=nullptr) {
            len++;
            if(p->next == nullptr) {
                tail = p; // 记录原链表尾部。
            }
            p=p->next;
        }

        k = k%len;        // 多余的整圈旋转可以消掉。
        if(k == 0) return head;

        tail->next = head; // 形成环，方便从新尾部切开。
        int t = len-k;
        p = head;
        for(int i=0; i<t-1; i++) {
            p = p->next;  // p 最终停在新尾节点。
        }
        ListNode*ans = p->next;
        p->next = nullptr;
        return ans;
    }
};
```

| 理解点 | 用户当前表现 | 影响 | 建议 |

## 最优解法

1. 若链表为空、只有一个节点或 `k == 0`，直接返回。
2. 遍历到尾节点，同时统计链表长度。
3. 用 `k % length` 得到真正需要移动的步数。
4. 找到新尾节点：它距离原头有 `length - shift - 1` 步。
5. 保存新头，旧尾接原头，新尾断开。

- 最优时间复杂度：`O(n)`
- 最优空间复杂度：`O(1)`

### 最优解代码

```cpp
class Solution {
public:
    ListNode* rotateRight(ListNode* head, int k) {
        if (head == nullptr || head->next == nullptr || k == 0) {
            return head;
        }

        int length = 1;
        ListNode* tail = head;
        while (tail->next != nullptr) {
            tail = tail->next;
            ++length;
        }

        int shift = k % length;
        if (shift == 0) {
            return head;
        }

        int stepsToNewTail = length - shift - 1;
        ListNode* newTail = head;
        for (int i = 0; i < stepsToNewTail; ++i) {
            newTail = newTail->next;
        }

        ListNode* newHead = newTail->next;
        tail->next = head;       // 先把首尾接成环，再从新尾部切开。
        newTail->next = nullptr;
        return newHead;
    }
};
```
