## 用户思路概述

1. 用 `unordered_map<int, DLinkedNode*>` 根据 key 快速定位缓存节点。
2. 用带头尾哨兵的双向链表维护使用顺序，头部表示最近使用，尾部表示最久未使用。
3. `get` 命中后把节点移动到头部，并返回值；未命中返回 `-1`。
4. `put` 插入新 key 时，新建节点并放到头部；容量超出时删除尾部真实节点。
5. `put` 更新旧 key 时，改值并移动到头部。

## 用户解法复杂度

- 时间复杂度：`get` 为 `O(1)`，`put` 为 `O(1)`
- 空间复杂度：`O(capacity)`
- 复杂度来源：哈希表保存 key 到节点的映射，双向链表保存最多 `capacity` 个真实节点。

## 用户代码注释版

```cpp
struct DLinkedNode {
    int key, value;
    DLinkedNode* prev;
    DLinkedNode* next;
    DLinkedNode(): key(0), value(0), prev(nullptr), next(nullptr) {}
    DLinkedNode(int _key, int _value): key(_key), value(_value), prev(nullptr), next(nullptr) {}
};

class LRUCache {
    unordered_map<int, DLinkedNode*> mp; // key -> 链表节点。
    DLinkedNode* head;                   // 头哨兵，不存真实数据。
    DLinkedNode* tail;                   // 尾哨兵，不存真实数据。
    int cap;
    int size;
public:
    LRUCache(int capacity) {
        cap=capacity;
        size=0;
        head = new DLinkedNode();
        tail = new DLinkedNode();
        head->next = tail;
        tail->prev = head;
    }

    int get(int key) {
        if(mp.find(key) == mp.end()) return -1;
        auto p=mp[key];
        moveTohead(p);                   // 访问后变成最近使用。
        return p->value;
    }

    void put(int key, int value) {
        if(mp.find(key) == mp.end()) {
            DLinkedNode*p = new DLinkedNode(key, value);
            mp[key]=p;
            addTohead(p);
            size++;
            if(size > cap) {
                DLinkedNode* toremove = removeTail();
                mp.erase(toremove->key);
                delete toremove;
                size--;
            }
        } else {
            auto p=mp[key];
            p->value = value;
            moveTohead(p);
        }
    }
};
```

## 最优解法

1. 哈希表负责 `key -> node` 的 `O(1)` 定位。
2. 双向链表负责维护从最近使用到最久未使用的顺序。
3. 每次访问或更新节点，都先从原位置摘下，再插到头部。
4. 插入新节点后若超出容量，就删除尾部前一个真实节点，并同步从哈希表移除。
5. 头尾哨兵固定存在，所有真实节点都在它们之间。

- 最优时间复杂度：`get O(1)`，`put O(1)`
- 最优空间复杂度：`O(capacity)`

### 最优解代码

```cpp
struct DLinkedNode {
    int key;
    int value;
    DLinkedNode* prev;
    DLinkedNode* next;
    DLinkedNode() : key(0), value(0), prev(nullptr), next(nullptr) {}
    DLinkedNode(int key, int value) : key(key), value(value), prev(nullptr), next(nullptr) {}
};

class LRUCache {
    unordered_map<int, DLinkedNode*> nodes;
    DLinkedNode* head;
    DLinkedNode* tail;
    int capacity;
    int size;

    void detach(DLinkedNode* node) {
        node->prev->next = node->next;
        node->next->prev = node->prev;
    }

    void pushFront(DLinkedNode* node) {
        // head 和 tail 是哨兵节点，真实最近使用节点始终放在 head 后。
        node->next = head->next;
        node->prev = head;
        head->next->prev = node;
        head->next = node;
    }

    DLinkedNode* popBack() {
        DLinkedNode* node = tail->prev;
        detach(node);
        return node;
    }

public:
    LRUCache(int capacity) : capacity(capacity), size(0) {
        head = new DLinkedNode();
        tail = new DLinkedNode();
        head->next = tail;
        tail->prev = head;
    }

    int get(int key) {
        auto it = nodes.find(key);
        if (it == nodes.end()) {
            return -1;
        }

        DLinkedNode* node = it->second;
        detach(node);
        pushFront(node);
        return node->value;
    }

    void put(int key, int value) {
        auto it = nodes.find(key);
        if (it != nodes.end()) {
            DLinkedNode* node = it->second;
            node->value = value;
            detach(node);
            pushFront(node);
            return;
        }

        DLinkedNode* node = new DLinkedNode(key, value);
        nodes[key] = node;
        pushFront(node);
        ++size;

        if (size > capacity) {
            DLinkedNode* removed = popBack();
            nodes.erase(removed->key);
            delete removed;
            --size;
        }
    }
};
```
