## 用户思路概述

1. 遍历链表，把所有节点值存入 `vector<int> arr`。
2. 对数组排序。
3. 再次遍历原链表，把排序后的值依次写回节点。
4. 返回原链表头。

## 用户解法复杂度

- 时间复杂度：`O(n log n)`
- 空间复杂度：`O(n)`
- 复杂度来源：数组排序需要 `O(n log n)`，额外数组保存所有节点值需要 `O(n)` 空间。

## 用户代码注释版

```cpp
class Solution {
public:
    ListNode* sortList(ListNode* head) {
        vector<int> arr;
        ListNode* p=head;
        while(p != nullptr) {
            arr.push_back(p->val); // 把链表问题转成数组排序。
            p=p->next;
        }
        sort(arr.begin(), arr.end());
        int n=arr.size();
        p = head;
        for(int i=0; i<n; i++, p=p->next) {
            p->val = arr[i];       // 改写节点值，而不是重排节点连接。
        }
        return head;
    }
};
```

| 理解点 | 用户当前表现 | 影响 | 建议 |
| --- | --- | --- | --- |
| 正确性 | 输出值序列能变成有序。 | 普通判题通常可以通过。 | 这是可工作的简化方案。 |

## 算法优缺点

| 方案 | 优点 | 缺点 | 适用情况 |
| --- | --- | --- | --- |
| 用户解法 | 简洁、容易写，时间复杂度达标。 | 空间复杂度为 `O(n)`，且没有练到链表连接排序。 | 可以作为保底思路，不适合作为本题最终模板。 |
| 推荐最优解 | 直接在链表上分段合并，满足 `O(n log n)` 时间和 `O(1)` 额外空间。 | 实现更长，需要清楚切段和合并边界。 | 适合本周链表综合收束。 |

## 最优解法

1. 先统计链表长度。
2. 从长度为 `1` 的有序段开始，两两合并；每轮段长翻倍。
3. 每次用 `split` 把当前链表切成 `left/right/next` 三部分。
4. 合并 `left` 和 `right` 两段，并接到结果链表尾部。
5. 所有轮次完成后返回 `dummy.next`。

- 最优时间复杂度：`O(n log n)`
- 最优空间复杂度：`O(1)`

### 最优解代码

```cpp
class Solution {
    ListNode* split(ListNode* head, int size) {
        for (int i = 1; head != nullptr && i < size; ++i) {
            head = head->next;
        }

        if (head == nullptr) {
            return nullptr;
        }

        ListNode* second = head->next;
        head->next = nullptr; // 切断前一段，避免合并时串回旧链表。
        return second;
    }

    ListNode* mergeSortedLists(ListNode* first, ListNode* second) {
        ListNode dummy(0);
        ListNode* tail = &dummy;

        while (first != nullptr && second != nullptr) {
            if (first->val <= second->val) {
                tail->next = first;
                first = first->next;
            } else {
                tail->next = second;
                second = second->next;
            }
            tail = tail->next;
        }

        tail->next = (first != nullptr) ? first : second;
        return dummy.next;
    }

public:
    ListNode* sortList(ListNode* head) {
        if (head == nullptr || head->next == nullptr) {
            return head;
        }

        int length = 0;
        for (ListNode* node = head; node != nullptr; node = node->next) {
            ++length;
        }

        ListNode dummy(0, head);
        for (int step = 1; step < length; step <<= 1) {
            ListNode* current = dummy.next;
            ListNode* tail = &dummy;

            while (current != nullptr) {
                ListNode* left = current;
                ListNode* right = split(left, step);
                current = split(right, step);

                // 每轮合并两个长度最多为 step 的有序段。
                tail->next = mergeSortedLists(left, right);
                while (tail->next != nullptr) {
                    tail = tail->next;
                }
            }
        }

        return dummy.next;
    }
};
```

## 对比与改进方向

| 对比项 | 用户代码 | 最优解代码 | 改进方向 |

| 状态定义 | 数组保存所有值。 | 链表段长、当前段、结果尾指针。 | 从“排序值”转向“重排节点”。 |
