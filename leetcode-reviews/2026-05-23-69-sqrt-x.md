## 用户思路概述

1. 把答案转成整数区间中的边界问题：找第一个平方大于 `x` 的位置。
2. 使用左闭右开区间 `[0, x + 1)`，其中 `x + 1` 作为哨兵上界。
3. 中点 `m` 的平方大于 `x` 时，收缩右边界；否则左边界移动到 `m + 1`。
4. 循环结束时 `l` 是第一个平方大于 `x` 的数，因此返回 `l - 1`。

## 用户解法复杂度

- 时间复杂度：`O(log x)`
- 空间复杂度：`O(1)`
- 复杂度来源：每轮根据 `m * m > x` 排除一半整数范围，只维护常数变量。

## 用户代码注释版

> 只在点评文档中展示加注释版本；不要把这些注释写回 `src/*.cpp` 的用户原代码。

```cpp
using ll = long long;
class Solution {
public:
    int mySqrt(int x) {
        ll l=0, r=1LL*x+1; // 搜索 [0, x + 1)，保证一定存在第一个平方大于 x 的位置。
        while(l<r) {
            ll m=l+(r-l)/2;
            if(1LL*m*m > 1LL*x) {
                r=m; // m 已经过大，保留 m，继续找第一个过大的位置。
            } else {
                l=m+1; // m 平方不超过 x，答案至少是 m，继续向右找过界点。
            }
        }
        return l-1; // 第一个过大位置左侧，就是整数平方根。
    }
};
```

## 关键理解点

| 理解点 | 用户当前表现 | 影响 | 建议 |
| --- | --- | --- | --- |
| 近似答案建模 | 能转成“第一个不可行位置 - 1” | 很适合迁移到最大可行值问题 | 同时掌握“记录 ans 找最后可行”的写法 |
| 溢出处理 | 用 `long long` 计算 `m * m` 和上界 | 能覆盖 `2147483647` 这类极值 | 保持这个习惯，二分答案题常见乘法/累加溢出 |
| 返回语义 | 返回 `l - 1` | 正确但需要清楚 `l` 已经不是答案 | 复盘时说清 `l` 是第一个平方大于 `x` 的数 |

## 算法优缺点

| 方案 | 优点 | 缺点 | 适用情况 |
| --- | --- | --- | --- |
| 用户解法 | 边界建模正确，`x = 0` 也能自然返回，溢出处理稳 | 返回 `l - 1` 需要依赖哨兵区间理解 | 适合“最大满足条件值 = 第一个不满足值 - 1”的题 |
| 推荐最优解 | 显式维护 `ans`，更直接表达“最后一个可行值” | 代码多一个变量 | 适合答案范围题和面试口述 |

## 最优解法

1. 在闭区间 `[0, x]` 中二分候选整数。
2. 若 `middle * middle <= x`，说明 `middle` 可行，记录答案并尝试更大的数。
3. 若 `middle * middle > x`，说明候选过大，收缩右边界。
4. 循环结束后返回最后记录的可行值。

- 最优时间复杂度：`O(log x)`
- 最优空间复杂度：`O(1)`

### 最优解代码

```cpp
class Solution {
public:
    int mySqrt(int x) {
        int left = 0;
        int right = x;
        int ans = 0;

        while (left <= right) {
            int middle = left + (right - left) / 2;
            if (1LL * middle * middle <= x) {
                ans = middle; // middle 可行，继续尝试更大的整数平方根。
                left = middle + 1;
            } else {
                right = middle - 1;
            }
        }

        return ans;
    }
};
```

## 对比与改进方向

| 对比项 | 用户代码 | 最优解代码 | 改进方向 |
| --- | --- | --- | --- |
| 状态定义 | 找第一个平方大于 `x` 的位置 | 找最后一个平方不超过 `x` 的位置 | 两种都要会，关键是返回语义一致 |
| 更新逻辑 | 过大保留，未过大右移 | 可行记录答案，不可行左移右界 | 面试中 `ans` 写法更容易解释 |
| 边界处理 | `r = x + 1` 哨兵覆盖 `x = 0` | 闭区间覆盖 `x = 0` | 两种都安全 |
| 复杂度 | `O(log x)` / `O(1)` | `O(log x)` / `O(1)` | 已达最优 |
