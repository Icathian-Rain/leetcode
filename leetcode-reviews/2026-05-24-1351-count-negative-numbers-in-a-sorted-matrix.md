## 用户思路概述

1. 观察矩阵每行、每列都按非递增顺序排列。
2. 从每一行的最右侧开始，用 `j` 指向当前还没有确认的列。
3. 如果 `grid[i][j] < 0`，说明当前行从 `j` 到右侧都是负数，于是继续左移。
4. 每行扫描结束后，`n - 1 - j` 就是该行负数数量。
5. 因为下一行的同一列不会更大，`j` 不需要重置，整体只会向左移动。

## 用户解法复杂度

- 时间复杂度：`O(m + n)`
- 空间复杂度：`O(1)`
- 复杂度来源：行指针向下走 `m` 次，列指针最多向左走 `n` 次。

## 用户代码注释版

> 只在点评文档中展示加注释版本；不要把这些注释写回 `src/*.cpp` 的用户原代码。

```cpp
class Solution {
public:
    int countNegatives(vector<vector<int>>& grid) {
        int m=grid.size(), n=grid[0].size();
        int j=n-1; // 从右上角开始，j 表示当前行最后一个可能非负的位置。
        int ans=0;
        for(int i=0; i<m; i++) {
            while(j>=0 && grid[i][j] < 0) {
                j--; // 当前列为负，且下一行只会更小，所以这一列之后也无需回退到右侧。
            }
            ans += n-1-j; // j 右侧全部是当前行的负数。
        }
        return ans;
    }
};
```

## 关键理解点

| 理解点 | 用户当前表现 | 影响 | 建议 |
| --- | --- | --- | --- |
| 行列单调性 | 能利用列指针只左移不重置 | 正确把复杂度降到 `O(m+n)` | 复盘时说清为什么下一行不需要重新从最右侧开始 |
| 计数边界 | 使用 `n - 1 - j` 统计右侧负数 | 能覆盖整行无负数和整行全负数 | 手推 `j == n - 1` 与 `j == -1` 两个边界 |
| 模式迁移 | 写法接近右上角阶梯搜索 | 可迁移到 `240` 类行列有序查找 | 总结为“每步排除一行或一列” |

## 算法优缺点

| 方案 | 优点 | 缺点 | 适用情况 |
| --- | --- | --- | --- |
| 用户解法 | 复杂度最优，状态很少，边界自然 | 变量名略短，复盘时要补充语义 | 适合行列都单调的矩阵计数 |
| 推荐最优解 | 本质相同，命名更清楚，注释强调排除依据 | 没有复杂度提升空间 | 作为阶梯式矩阵搜索模板 |

## 最优解法

1. 从右上角开始，当前位置左侧不一定为负，右侧已经更小。
2. 当前值为负时，当前行右侧都是负数，列指针左移。
3. 当前行处理结束后，累加右侧负数数量。
4. 由于下一行元素不会更大，列指针不重置，整体线性推进。

- 最优时间复杂度：`O(m + n)`
- 最优空间复杂度：`O(1)`

### 最优解代码

```cpp
class Solution {
public:
    int countNegatives(vector<vector<int>>& grid) {
        int rows = static_cast<int>(grid.size());
        int cols = static_cast<int>(grid[0].size());
        int col = cols - 1;
        int ans = 0;

        for (int row = 0; row < rows; ++row) {
            while (col >= 0 && grid[row][col] < 0) {
                --col; // 当前列在这一行已为负，下一行只会更小，可以继续左移。
            }
            ans += cols - 1 - col;
        }

        return ans;
    }
};
```
