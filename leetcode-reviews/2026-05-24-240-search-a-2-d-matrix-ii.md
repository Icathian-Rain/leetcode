## 用户思路概述

1. 从矩阵右上角开始搜索。
2. 如果当前值等于 `target`，直接返回 `true`。
3. 如果当前值大于 `target`，说明当前列从当前位置往下只会更大，因此左移一列。
4. 如果当前值小于 `target`，说明当前行从左到当前位置都不可能命中，因此下移一行。
5. 当行或列越界仍未命中时，返回 `false`。

## 用户解法复杂度

- 时间复杂度：`O(m + n)`
- 空间复杂度：`O(1)`
- 复杂度来源：每一步排除一整行或一整列，行指针最多下移 `m` 次，列指针最多左移 `n` 次。

## 用户代码注释版

> 只在点评文档中展示加注释版本；不要把这些注释写回 `src/*.cpp` 的用户原代码。

```cpp
class Solution {
public:
    bool searchMatrix(vector<vector<int>>& matrix, int target) {
        int m=matrix.size(), n=matrix[0].size();
        int i=0, j=n-1; // 从右上角开始：左侧更小，下方更大。
        while(i<m && j>=0) {
            if(matrix[i][j] == target) {
                return true;
            } else if(matrix[i][j] > target) {
                j--; // 当前列当前位置及下方都偏大，排除这一列。
            } else {
                i++; // 当前行当前位置及左侧都偏小，排除这一行。
            }
        }
        return false;
    }
};
```

## 最优解法

1. 从右上角出发，当前位置左侧都不大于它，下方都不小于它。
2. 当前值过大时，当前列可以排除，列指针左移。
3. 当前值过小时，当前行可以排除，行指针下移。
4. 每一步都减少一行或一列，直到命中或越界。

- 最优时间复杂度：`O(m + n)`
- 最优空间复杂度：`O(1)`

### 最优解代码

```cpp
class Solution {
public:
    bool searchMatrix(vector<vector<int>>& matrix, int target) {
        int rows = static_cast<int>(matrix.size());
        int cols = static_cast<int>(matrix[0].size());
        int row = 0;
        int col = cols - 1;

        while (row < rows && col >= 0) {
            if (matrix[row][col] == target) {
                return true;
            }
            if (matrix[row][col] > target) {
                --col; // 当前列下方更大，整列当前候选可排除。
            } else {
                ++row; // 当前行左侧更小，整行当前候选可排除。
            }
        }

        return false;
    }
};
```

## 对比与改进方向

| --- | --- | --- | --- |
