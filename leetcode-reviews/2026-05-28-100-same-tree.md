## 用户思路概述

1. 两个节点都为空时返回 `true`。
2. 只有一个为空时返回 `false`，结构已经不同。
3. 两个节点值不同返回 `false`。
4. 同步递归比较左右子树，只有两侧都相同才返回 `true`。

## 用户解法复杂度

- 时间复杂度：`O(min(n, m))`，最坏为 `O(n)`
- 空间复杂度：`O(h)`，最坏为 `O(n)`
- 复杂度来源：同步访问两棵树对应位置，递归栈取决于树高。

## 用户代码注释版

```cpp
class Solution {
public:
    bool isSameTree(TreeNode* p, TreeNode* q) {
        if(p==nullptr && q==nullptr) return true; // 两边都空，结构相同。
        if((p==nullptr && q!= nullptr)||(p!=nullptr && q==nullptr)) return false;
        if(p->val != q->val) return false; // 值不同直接失败。
        return isSameTree(p->left, q->left) &&
               isSameTree(p->right, q->right);
    }
};
```

## 关键理解点

| 理解点 | 用户当前表现 | 影响 | 建议 |
| --- | --- | --- | --- |
| 双树同步 | 对应节点同步比较 | 正确性稳定 | 后续子树、镜像题都能复用 |
| 空节点组合 | 分开处理双空和单空 | 覆盖结构不同 | 可简化成 `if (!p || !q) return p == q` |
| 递归返回值 | 当前两棵子树是否相同 | 清晰可迁移 | 继续保持布尔语义明确 |

| 方案 | 优点 | 缺点 | 适用情况 |

## 最优解法

1. 如果任一节点为空，只有两个都为空才相同。
2. 非空时先比较节点值。
3. 同步递归比较左右子树。

- 最优时间复杂度：`O(n)`
- 最优空间复杂度：`O(h)`

### 最优解代码

```cpp
class Solution {
public:
    bool isSameTree(TreeNode* p, TreeNode* q) {
        if (p == nullptr || q == nullptr) {
            return p == q; // 只有两个空节点才算结构相同。
        }
        if (p->val != q->val) {
            return false;
        }
        return isSameTree(p->left, q->left) &&
               isSameTree(p->right, q->right);
    }
};
```
