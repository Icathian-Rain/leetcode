## 用户思路概述

1. 空树直接返回 false。
2. 每到一个节点，就从 `targetSum` 中减去当前节点值。
3. 只有到叶子节点时，才判断剩余值是否为 0。
4. 非叶子节点继续递归左右子树，只要任意一侧存在合法路径就返回 true。

## 用户解法复杂度

- 时间复杂度：`O(n)`
- 空间复杂度：`O(h)`
- 复杂度来源：每个节点最多访问一次；递归栈深度为树高 `h`。

## 用户代码注释版

```cpp
class Solution {
public:
    bool hasPathSum(TreeNode* root, int targetSum) {
        // 空节点不能构成根到叶路径。
        if(root == nullptr) return false;
        targetSum -= root->val;
        if(root->left == nullptr && root->right == nullptr) {
            // 只有叶子节点才结算完整路径。
            if(targetSum == 0) return true;
            else return false;
        }
        return hasPathSum(root->left, targetSum) || hasPathSum(root->right, targetSum);
    }
};
```

## 关键理解点

| 理解点 | 用户当前表现 | 影响 | 建议 |
| --- | --- | --- | --- |
| 路径定义 | 只在叶子节点判断 | 正确覆盖根到叶路径要求 | 保持这个边界 |
| 状态推进 | 用剩余目标值向下传递 | 简洁稳定 | 复盘时说清剩余值语义 |
| 代码清晰度 | 叶子判断可简化 | 不影响正确性 | 可直接 `return targetSum == root->val` |

## 算法优缺点

| 方案 | 优点 | 缺点 | 适用情况 |
| --- | --- | --- | --- |
| 用户解法 | 正确、直接，状态定义清楚 | 叶子分支略啰嗦 | 根到叶路径存在性判断 |
| 推荐最优解 | 同一思路，叶子处直接比较当前值 | 本质复杂度相同 | 可作为路径剩余和模板 |

## 最优解法

1. 空节点返回 false。
2. 如果当前节点是叶子，直接判断 `targetSum == root->val`。
3. 否则把剩余目标值传给左右子树。
4. 左右任意一侧存在合法路径即可。

- 最优时间复杂度：`O(n)`
- 最优空间复杂度：`O(h)`

### 最优解代码

```cpp
class Solution {
public:
    bool hasPathSum(TreeNode* root, int targetSum) {
        if (root == nullptr) {
            return false;
        }

        // 只有叶子节点能完成一条根到叶路径。
        if (root->left == nullptr && root->right == nullptr) {
            return targetSum == root->val;
        }

        int rest = targetSum - root->val;
        return hasPathSum(root->left, rest) ||
               hasPathSum(root->right, rest);
    }
};
```

## 对比与改进方向

| 对比项 | 用户代码 | 最优解代码 | 改进方向 |
| --- | --- | --- | --- |
| 状态定义 | 修改剩余 `targetSum` | 显式 `rest` | 语义更清楚 |
| 更新逻辑 | 先减当前节点再递归 | 叶子直接判断，非叶子传剩余值 | 减少分支 |
| 边界处理 | 空树、叶子都覆盖 | 相同 | 正确 |
| 复杂度 | `O(n)` / `O(h)` | `O(n)` / `O(h)` | 已是最优 |
