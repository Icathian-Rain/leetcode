## 用户思路概述

1. 使用 `path` 保存当前根到当前节点的路径。
2. 使用 `ans` 保存所有满足条件的完整路径。
3. DFS 进入节点时，把当前值加入 `path`，并从目标值中扣除当前值。
4. 到叶子节点时，如果剩余目标值为 0，就把当前路径加入答案。
5. 返回上一层前 `path.pop_back()`，恢复现场。

## 用户解法复杂度

- 时间复杂度：`O(n * h)`，若把复制答案路径的成本计入；遍历本身为 `O(n)`。
- 空间复杂度：`O(h)`，不含返回答案；其中 `h` 是树高。
- 复杂度来源：每个节点访问一次，命中答案时复制当前路径。

## 用户代码注释版

```cpp
class Solution {
    vector<vector<int>> ans;
    vector<int> path;
    void dfs(TreeNode* root, int target) {
        if(root == nullptr) return;
        // 选择当前节点。
        path.push_back(root->val);
        target -= root->val;
        if(root->left == nullptr && root->right == nullptr) {
            if(target == 0) {
                ans.push_back(path);
            }
        } else {
            dfs(root->left, target);
            dfs(root->right, target);
        }
        // 撤销当前节点，保证兄弟分支看到的是自己的路径。
        target += root->val;
        path.pop_back();
    }
public:
    vector<vector<int>> pathSum(TreeNode* root, int targetSum) {
        dfs(root, targetSum);
        return ans;
    }
};
```

## 关键理解点

| 理解点 | 用户当前表现 | 影响 | 建议 |
| --- | --- | --- | --- |
| 回溯动作 | `push` 后在返回前 `pop` | 正确隔离不同路径 | 很好，继续保持 |
| 叶子结算 | 只在叶子加入答案 | 符合根到叶路径定义 | 正确 |
| 成员状态 | `ans/path` 是成员变量 | LeetCode 单次调用可过，多次调用可能残留 | 推荐入口使用局部变量传引用 |

## 算法优缺点

| 方案 | 优点 | 缺点 | 适用情况 |
| --- | --- | --- | --- |
| 用户解法 | 回溯结构完整，正确性稳定 | 成员变量有复用风险，`target += root->val` 对值传参其实不必要 | 路径收集类题 |
| 推荐最优解 | 局部 `ans/path`，状态生命周期更安全 | 参数略多 | 可复用的回溯模板 |

## 最优解法

1. DFS 参数携带当前节点、剩余目标值、当前路径和答案。
2. 进入节点时压入路径并扣除节点值。
3. 到叶子且剩余值为 0 时复制路径到答案。
4. 离开节点前弹出当前值。

- 最优时间复杂度：`O(n * h)`，遍历为 `O(n)`，复制答案路径有额外成本。
- 最优空间复杂度：`O(h)`，不含返回答案。

### 最优解代码

```cpp
class Solution {
    void dfs(TreeNode* root, int target, vector<int>& path, vector<vector<int>>& ans) {
        if (root == nullptr) {
            return;
        }

        path.push_back(root->val);
        target -= root->val;
        // 叶子节点才代表一条完整根到叶路径。
        if (root->left == nullptr && root->right == nullptr && target == 0) {
            ans.push_back(path);
        } else {
            dfs(root->left, target, path, ans);
            dfs(root->right, target, path, ans);
        }
        path.pop_back();
    }

public:
    vector<vector<int>> pathSum(TreeNode* root, int targetSum) {
        vector<vector<int>> ans;
        vector<int> path;
        dfs(root, targetSum, path, ans);
        return ans;
    }
};
```
