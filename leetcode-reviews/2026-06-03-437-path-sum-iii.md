## 用户思路概述

1. DFS 过程中维护从根到当前节点的前缀和 `sum`。
2. 用 `cnt` 记录当前递归路径上每个前缀和出现次数。
3. 到达当前节点时查找 `sum - targetSum` 出现过几次，从而统计以当前节点结尾的合法路径数量。
4. 进入左右子树前加入当前前缀和，返回上一层前撤销当前前缀和。

## 用户解法复杂度

- 时间复杂度：`O(n)`
- 空间复杂度：`O(h)`，最坏 `O(n)`
- 复杂度来源：每个节点访问一次；哈希表只保存当前路径上的前缀和计数，递归栈深度为树高。

## 用户代码注释版

```cpp
class Solution {
    unordered_map<ll, int> cnt;
    int ans = 0;
    void dfs(TreeNode* root, int targetSum, ll sum) {
        if(root == nullptr) return ;
        sum += root->val;
        cout << sum << endl; // 调试输出会导致 LeetCode 提交输出污染。
        // 查找之前路径中是否存在一个前缀，使两段前缀差等于 targetSum。
        if(cnt.find(sum - targetSum) != cnt.end()) {
            ans += cnt[sum-targetSum];
        }
        cnt[sum] += 1;
        dfs(root->left, targetSum, sum);
        dfs(root->right, targetSum, sum);
        cnt[sum] -= 1; // 回溯，避免兄弟子树共享当前路径状态。
    }

public:
    int pathSum(TreeNode* root, int targetSum) {
        cnt[0] = 1; // 空前缀用于统计从根开始的路径。
        dfs(root, targetSum, 0);
        return ans;
    }
};
```

## 最优解法

1. 用哈希表记录当前根到节点路径上的前缀和次数，初始 `prefixCount[0] = 1`。
2. 访问节点后更新当前前缀和，答案增加 `prefixCount[prefix - targetSum]`。
3. 递归左右子树前加入当前前缀和，返回后撤销，保证哈希表只代表当前路径。

- 最优时间复杂度：`O(n)`
- 最优空间复杂度：`O(h)`，最坏 `O(n)`

### 最优解代码

```cpp
class Solution {
public:
    int pathSum(TreeNode* root, int targetSum) {
        unordered_map<long long, int> prefixCount;
        prefixCount[0] = 1;

        function<int(TreeNode*, long long)> dfs = [&](TreeNode* node, long long prefix) {
            if (node == nullptr) return 0;
            prefix += node->val;
            int paths = prefixCount[prefix - targetSum];
            ++prefixCount[prefix];
            paths += dfs(node->left, prefix);
            paths += dfs(node->right, prefix);
            --prefixCount[prefix];
            return paths;
        };

        return dfs(root, 0);
    }
};
```
