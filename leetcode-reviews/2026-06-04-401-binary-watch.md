## 用户思路概述

1. 把总亮灯数拆成小时灯数量和分钟灯数量。
2. 分别用 `hdfs` 和 `mdfs` 枚举小时 4 位、分钟 6 位中哪些位置亮。
3. 把枚举出的合法小时和分钟两两组合，拼成题目要求的时间字符串。

## 用户解法复杂度

- 时间复杂度：`O(C(4,h) + C(6,m) + H*M)`，由于手表范围固定，也可视为 `O(1)`
- 空间复杂度：`O(H + M)`，固定范围下为 `O(1)`
- 复杂度来源：小时和分钟分别枚举亮灯组合，再组合两个结果列表。

## 用户代码注释版

```cpp
class Solution {
    void hdfs(int idx, int left, vector<int>& hvis, vector<int>& hresult) {
        if(left == 0) {
            int h = 0;
            for(int i=0; i<4; i++) {
                if(hvis[i] == true) {
                    h |= 1 << i; // 根据亮灯位置还原小时数值。
                }
            }
            if(h <  12) {
                hresult.push_back(h);
            }
            return;
        }
        if(idx == 4) {
            return;
        }

        hvis[idx] = true;
        hdfs(idx+1, left-1, hvis, hresult);
        hvis[idx] = false;
        hdfs(idx+1, left, hvis, hresult);
    }

public:
    vector<string> readBinaryWatch(int turnedOn) {
        vector<string> ans;
        for(int hour = 0; hour<=turnedOn; hour++) {
            int min = turnedOn - hour;
            if(hour > 4 || min > 6) continue;
            // 小时和分钟分别枚举，再做笛卡尔组合。
        }
        return ans;
    }
};
```

## 最优解法

1. 枚举所有小时 `0..11` 和分钟 `0..59`。
2. 统计小时二进制中 `1` 的数量和分钟二进制中 `1` 的数量。
3. 如果总数等于 `turnedOn`，按要求格式化时间。

- 最优时间复杂度：`O(1)`
- 最优空间复杂度：`O(1)`，不计输出结果

### 最优解代码

```cpp
class Solution {
public:
    vector<string> readBinaryWatch(int turnedOn) {
        vector<string> ans;
        for (int hour = 0; hour < 12; ++hour) {
            for (int minute = 0; minute < 60; ++minute) {
                // 小时和分钟的亮灯数量之和必须等于 turnedOn。
                if (__builtin_popcount(hour) + __builtin_popcount(minute) != turnedOn) {
                    continue;
                }
                string time = to_string(hour) + ":";
                if (minute < 10) time.push_back('0');
                time += to_string(minute);
                ans.push_back(time);
            }
        }
        return ans;
    }
};
```
