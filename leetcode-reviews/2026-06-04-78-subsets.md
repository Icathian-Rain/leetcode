## 用户思路概述

1. 用 `comp` 维护当前已经选择的元素。
2. 对每个下标 `idx` 做两种决策：选择当前元素，或不选择当前元素。
3. 当 `idx == nums.size()` 时，当前路径就是一个完整子集，加入答案。

## 用户解法复杂度

- 时间复杂度：`O(n * 2^n)`
- 空间复杂度：`O(n)`，不计输出结果
- 复杂度来源：共有 `2^n` 个子集，每个子集复制进答案时最多包含 `n` 个元素；递归深度为 `n`。

## 用户代码注释版

```cpp
class Solution {
public:
    vector<vector<int>> ans;
    vector<int> comp;

    void backtrace(vector<int>& nums, int idx) {
        if(idx == nums.size()) {
            ans.push_back(comp); // 所有元素都决策完后收集一个完整子集。
            return ;
        }
        comp.push_back(nums[idx]); // 选择当前元素。
        backtrace(nums, idx+1);
        comp.pop_back(); // 撤销选择，进入“不选当前元素”的分支。
        backtrace(nums, idx+1);
    }

    vector<vector<int>> subsets(vector<int>& nums) {
        backtrace(nums, 0);
        return ans;
    }
};
```

## 关键理解点

| 理解点 | 用户当前表现 | 影响 | 建议 |
| --- | --- | --- | --- |
| 决策树 | 明确每个元素有选和不选两种分支 | 正确覆盖所有子集 | 这是本题最重要的基础 |
| 回溯恢复 | `push` 后递归，`pop` 后走另一分支 | 路径不会串分支 | 保持这个动作顺序 |
| 成员状态 | `ans/comp` 是成员变量 | 多次调用可能残留结果 | 入口处清空或改局部变量 |

## 算法优缺点

| 方案 | 优点 | 缺点 | 适用情况 |
| --- | --- | --- | --- |
| 用户解法 | 选/不选模型清楚，容易证明完整性 | 只在叶子收集，递归节点数量略多；成员状态有复用风险 | 很适合入门理解子集枚举 |
| 推荐最优解 | 每个递归节点都收集当前路径，写法更贴近组合模板 | 需要理解 `start` 表示下一次选择起点 | 后续组合题迁移更顺 |

## 最优解法

1. 用局部 `path` 保存当前子集，用 `start` 表示下一次可选择的起点。
2. 每进入一个递归节点，当前 `path` 就是合法子集，先加入答案。
3. 从 `start` 开始枚举下一个元素，选择后递归到 `i + 1`，返回后撤销。

- 最优时间复杂度：`O(n * 2^n)`
- 最优空间复杂度：`O(n)`，不计输出结果

### 最优解代码

```cpp
class Solution {
public:
    vector<vector<int>> subsets(vector<int>& nums) {
        vector<vector<int>> result;
        vector<int> path;

        function<void(int)> dfs = [&](int start) {
            // 当前路径本身就是一个合法子集。
            result.push_back(path);
            for (int i = start; i < nums.size(); ++i) {
                path.push_back(nums[i]);
                dfs(i + 1);
                path.pop_back();
            }
        };

        dfs(0);
        return result;
    }
};
```

## 对比与改进方向

| 对比项 | 用户代码 | 最优解代码 | 改进方向 |
| --- | --- | --- | --- |
| 状态定义 | 当前下标 `idx` 和路径 | 下一次选择起点 `start` 和路径 | 为组合类题提前铺路 |
| 更新逻辑 | 每个元素选或不选 | 从候选范围里选择下一个元素 | 两种都正确，后者更可迁移 |
| 边界处理 | 叶子节点收集 | 每个节点收集 | 明确“什么时候已经是答案” |
| 复杂度 | `O(n*2^n)` | `O(n*2^n)` | 主要优化复用风险和模板迁移 |
