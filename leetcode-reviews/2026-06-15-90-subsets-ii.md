## 用户思路概述

1. 先对 `nums` 排序，让重复值相邻。
2. 用 `path` 表示当前子集，每进入一个递归节点就把当前路径加入 `ans`。
3. 每一层从 `idx` 开始向后选择元素，递归时传入 `i + 1`。
4. 当 `i > idx && nums[i] == nums[i - 1]` 时跳过，避免同一层重复选择相同值。

## 用户解法复杂度

- 时间复杂度：`O(n * 2^n)`
- 空间复杂度：`O(n)`，不计返回结果
- 复杂度来源：最多生成 `2^n` 个子集，每次复制路径最坏 `O(n)`；递归深度为 `n`。

## 用户代码注释版

```cpp
class Solution {
    vector<vector<int>> ans;
    vector<int> path;

    void backtrace(vector<int>& nums, int idx) {
        ans.push_back(path); // 子集题中，当前路径本身就是合法结果。
        for (int i = idx; i < nums.size(); i++) {
            if (i > idx && nums[i] == nums[i - 1]) continue; // 同一层去重。
            path.push_back(nums[i]);
            backtrace(nums, i + 1);
            path.pop_back();
        }
    }

public:
    vector<vector<int>> subsetsWithDup(vector<int>& nums) {
        sort(nums.begin(), nums.end());
        backtrace(nums, 0);
        return ans;
    }
};
```

## 最优解法

1. 排序，让相同值相邻。
2. 每个递归节点先收集当前路径。
3. 同一层遇到与前一个相同的值时跳过。
4. 选择后递归到 `i + 1`，返回后撤销路径。

- 最优时间复杂度：`O(n * 2^n)`
- 最优空间复杂度：`O(n)`，不计返回结果

### 最优解代码

```cpp
class Solution {
public:
    vector<vector<int>> subsetsWithDup(vector<int>& nums) {
        sort(nums.begin(), nums.end());

        vector<vector<int>> result;
        vector<int> current;

        function<void(int)> dfs = [&](int start) {
            result.push_back(current);

            for (int i = start; i < static_cast<int>(nums.size()); ++i) {
                if (i > start && nums[i] == nums[i - 1]) {
                    continue; // 同一层跳过重复值，避免生成重复子集。
                }
                current.push_back(nums[i]);
                dfs(i + 1);
                current.pop_back();
            }
        };

        dfs(0);
        return result;
    }
};
```
