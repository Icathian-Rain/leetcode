## 用户思路概述

1. 按行递归放置皇后，`row` 表示当前要处理的行。
2. `path` 保存当前棋盘布局。
3. `cols` 记录哪些列已有皇后。
4. `rect[row - col + n - 1]` 和 `rect2[row + col]` 记录两条对角线是否被占用。
5. 每次放置后递归下一行，返回时恢复棋盘和三个约束数组。

## 用户解法复杂度

- 时间复杂度：约 `O(n!)`
- 空间复杂度：`O(n^2 + n)`
- 复杂度来源：每行选择一个列位置，列和对角线约束会剪掉大量分支；棋盘保存为 `n*n`。

## 用户代码注释版

```cpp
class Solution {
public:
    vector<vector<string>> solveNQueens(int n) {
        vector<vector<string>> ans;
        vector<string> path(n, string(n, '.'));
        vector<bool> cols(n, false);
        vector<bool> rect(2 * n - 1, false);
        vector<bool> rect2(2 * n - 1, false);

        function<void(int)> dfs = [&](int row) {
            if (row == n) {
                ans.push_back(path); // 每一行都放好一个皇后。
                return;
            }

            for (int col = 0; col < n; col++) {
                if (!cols[col] && !rect[row - col + n - 1] && !rect2[row + col]) {
                    cols[col] = rect[row - col + n - 1] = rect2[row + col] = true;
                    path[row][col] = 'Q';
                    dfs(row + 1);
                    path[row][col] = '.';
                    cols[col] = rect[row - col + n - 1] = rect2[row + col] = false;
                }
            }
        };

        dfs(0);
        return ans;
    }
};
```

## 关键理解点

| 理解点 | 用户当前表现 | 影响 | 建议 |
| --- | --- | --- | --- |
| 行递归 | 每层只处理一行 | 正确把二维棋盘降成逐行选择 | 这是 N 皇后最稳的建模 |
| 约束表 | 列、主副对角线都独立维护 | 能 `O(1)` 判断当前位置是否合法 | 继续记住两个对角线编号公式 |
| 恢复现场 | 棋盘和约束数组都成对恢复 | 回溯动作完整 | 很扎实，可以迁移到数独 |

## 最优解法

1. 按行递归。
2. 对每个候选列检查列和两条对角线。
3. 放置皇后并标记约束。
4. 递归下一行，返回后恢复棋盘和约束。

- 最优时间复杂度：约 `O(n!)`
- 最优空间复杂度：`O(n^2 + n)`

### 最优解代码

```cpp
class Solution {
public:
    vector<vector<string>> solveNQueens(int n) {
        vector<vector<string>> result;
        vector<string> board(n, string(n, '.'));
        vector<bool> cols(n, false);
        vector<bool> diag1(2 * n - 1, false);
        vector<bool> diag2(2 * n - 1, false);

        function<void(int)> dfs = [&](int row) {
            if (row == n) {
                result.push_back(board);
                return;
            }

            for (int col = 0; col < n; ++col) {
                int leftDiag = row - col + n - 1;
                int rightDiag = row + col;
                if (cols[col] || diag1[leftDiag] || diag2[rightDiag]) continue;
                cols[col] = diag1[leftDiag] = diag2[rightDiag] = true;
                board[row][col] = 'Q';
                dfs(row + 1);
                board[row][col] = '.';
                cols[col] = diag1[leftDiag] = diag2[rightDiag] = false; // 恢复列和两条对角线状态。
            }
        };

        dfs(0);
        return result;
    }
};
```
