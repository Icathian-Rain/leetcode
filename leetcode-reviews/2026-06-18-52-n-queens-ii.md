## 用户思路概述

1. 沿用 `51. N-Queens` 的逐行放置模型。
2. 用 `cols`、`rect`、`rect2` 分别记录列和两条对角线是否被占用。
3. 每一行尝试所有列，合法时放置皇后并递归下一行。
4. 回溯时恢复棋盘和约束状态。
5. 当 `row == n` 时，不保存棋盘，而是 `ans++`。

## 用户解法复杂度

- 时间复杂度：约 `O(n!)`
- 空间复杂度：`O(n^2 + n)`
- 复杂度来源：逐行选择列并用对角线剪枝；当前代码仍维护完整棋盘。

## 用户代码注释版

```cpp
class Solution {
public:
    int totalNQueens(int n) {
        int ans = 0;
        vector<string> path(n, string(n, '.'));
        vector<bool> cols(n, false);
        vector<bool> rect(2 * n - 1, false);
        vector<bool> rect2(2 * n - 1, false);

        function<void(int)> dfs = [&](int row) {
            if (row == n) {
                ans++; // 只统计数量，不需要保存棋盘。
                return;
            }

            for (int col = 0; col < n; col++) {
                if (!cols[col] && !rect[row - col + n - 1] && !rect2[row + col]) {
                    cols[col] = rect[row - col + n - 1] = rect2[row + col] = true;
                    path[row][col] = 'Q';
                    dfs(row + 1);
                    path[row][col] = '.';
                    cols[col] = rect[row - col + n - 1] = rect2[row + col] = false;
                }
            }
        };

        dfs(0);
        return ans;
    }
};
```

## 最优解法

1. 逐行递归。
2. 用列和两条对角线约束判断能否放置。
3. 合法则标记约束并递归下一行。
4. 到达第 `n` 行时计数加一。
5. 回溯时恢复约束。

- 最优时间复杂度：约 `O(n!)`
- 最优空间复杂度：`O(n)`

### 最优解代码

```cpp
class Solution {
public:
    int totalNQueens(int n) {
        int count = 0;
        vector<bool> cols(n, false);
        vector<bool> diag1(2 * n - 1, false);
        vector<bool> diag2(2 * n - 1, false);

        function<void(int)> dfs = [&](int row) {
            if (row == n) {
                ++count;
                return;
            }

            for (int col = 0; col < n; ++col) {
                int leftDiag = row - col + n - 1;
                int rightDiag = row + col;
                if (cols[col] || diag1[leftDiag] || diag2[rightDiag]) continue;
                cols[col] = diag1[leftDiag] = diag2[rightDiag] = true;
                dfs(row + 1);
                cols[col] = diag1[leftDiag] = diag2[rightDiag] = false; // 只计数，不需要维护完整棋盘。
            }
        };

        dfs(0);
        return count;
    }
};
```
