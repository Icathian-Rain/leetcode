## 用户思路概述

1. 从每个网格位置尝试作为单词起点。
2. `dfs(board, word, x, y, idx)` 判断当前位置是否匹配 `word[idx]`。
3. 匹配成功后标记 `vis[x][y] = true`，再向四个方向搜索下一个字符。
4. 如果 `idx` 到达单词末尾，返回 `true`。
5. 当前分支失败时恢复访问标记，允许其他路径使用该位置。

## 用户解法复杂度

- 时间复杂度：`O(m*n*3^L)`，其中 `L` 是单词长度
- 空间复杂度：`O(m*n + L)`
- 复杂度来源：每个起点都可能展开搜索；除第一步外每步通常最多向 3 个未访问方向扩展。

## 用户代码注释版

```cpp
class Solution {
public:
    vector<vector<int>> DIRCET = {{1, 0}, {-1, 0}, {0, 1}, {0, -1}};
    vector<vector<bool>> vis;

    bool dfs(vector<vector<char>>& board, string& word, int x, int y, int idx) {
        if (board[x][y] != word[idx]) return false; // 当前格子字符不匹配。
        if (idx == word.size() - 1) return true;    // 已匹配最后一个字符。

        vis[x][y] = true;
        for (int k = 0; k < 4; k++) {
            int dx = x + DIRCET[k][0], dy = y + DIRCET[k][1];
            if (dx >= 0 && dx < board.size() && dy >= 0 && dy < board[0].size() && !vis[dx][dy]) {
                if (dfs(board, word, dx, dy, idx + 1)) {
                    return true; // 风险：成功返回前没有恢复当前格访问状态。
                }
            }
        }
        vis[x][y] = false;
        return false;
    }
};
```

## 关键理解点

| 理解点 | 用户当前表现 | 影响 | 建议 |
| --- | --- | --- | --- |
| 路径访问状态 | 使用 `vis` 防止重复使用同一格 | 正确命中网格回溯核心 | 成功返回前也恢复现场，让函数副作用更干净 |
| 起点枚举 | 每个格子都尝试起点 | 正确覆盖所有可能路径 | 可先检查首字符再进入 DFS |
| 调试输出 | `exist` 中有 `cout` | LeetCode 提交通常不应输出调试信息 | 删除调试输出 |
| 状态初始化 | 每个起点重新分配 `vis` | 正确但成本略高 | 可以全局初始化一次，DFS 负责成对恢复 |

## 算法优缺点

| 方案 | 优点 | 缺点 | 适用情况 |
| --- | --- | --- | --- |
| 用户解法 | 匹配、方向搜索、访问标记主干完整 | 成功返回前未恢复；有调试输出 | 思路适合本题，需要修实现细节 |
| 推荐最优解 | 所有返回路径都恢复现场，无调试输出 | 复杂度本质仍为指数搜索 | 标准网格路径搜索 |

## 最优解法

1. 对每个格子作为起点尝试 DFS。
2. 当前格字符不匹配立即返回。
3. 匹配后标记访问，搜索四邻格。
4. 无论成功或失败返回，都恢复当前格访问状态。

- 最优时间复杂度：`O(m*n*3^L)`
- 最优空间复杂度：`O(m*n + L)`

### 最优解代码

```cpp
class Solution {
public:
    bool exist(vector<vector<char>>& board, string word) {
        int rows = static_cast<int>(board.size());
        int cols = static_cast<int>(board[0].size());
        vector<vector<bool>> visited(rows, vector<bool>(cols, false));
        vector<pair<int, int>> directions = {{1, 0}, {-1, 0}, {0, 1}, {0, -1}};

        function<bool(int, int, int)> dfs = [&](int x, int y, int index) {
            if (board[x][y] != word[index]) return false;
            if (index == static_cast<int>(word.size()) - 1) return true;

            visited[x][y] = true;
            for (auto [dx, dy] : directions) {
                int nx = x + dx, ny = y + dy;
                if (nx < 0 || nx >= rows || ny < 0 || ny >= cols || visited[nx][ny]) continue;
                if (dfs(nx, ny, index + 1)) {
                    visited[x][y] = false; // 成功返回前也恢复现场。
                    return true;
                }
            }
            visited[x][y] = false;
            return false;
        };

        for (int x = 0; x < rows; ++x) {
            for (int y = 0; y < cols; ++y) {
                if (dfs(x, y, 0)) return true;
            }
        }
        return false;
    }
};
```
