## 用户思路概述

1. `s1` 用一维状态表示前 `i` 间房屋能取得的最大金额。
2. 当前房屋要么不偷，沿用前一间的结果；要么偷，就接上前两间之前的结果。
3. `s2` 把每个位置拆成两个状态：当前不偷和当前偷。
4. 最终 `rob` 选择调用 `s2`，返回最后一天两个状态中的最大值。

## 用户解法复杂度

- 时间复杂度：`O(n)`
- 空间复杂度：`O(n)`
- 复杂度来源：两种写法都只线性扫描一次数组；`s2` 使用 `n * 2` 的状态表。

## 用户代码注释版

```cpp
class Solution {
public:
    int s2(vector<int>& nums) {
        int n=nums.size();
        if(n == 1) return nums[0];
        if(n == 2) return max(nums[0], nums[1]);
        vector<vector<int>> dp(n+1, vector<int>(2, 0));
        for(int i=1; i<=n; i++) {
            dp[i][0] = max(dp[i-1][0], dp[i-1][1]); // 第 i 间不偷，继承前 i-1 间最优。
            dp[i][1] = dp[i-1][0] + nums[i-1];      // 第 i 间偷，前一间必须不偷。
        }
        return max(dp[n][0], dp[n][1]);
    }

    int rob(vector<int>& nums) {
        return s2(nums);
    }
};
```

## 关键理解点

| 理解点 | 用户当前表现 | 影响 | 建议 |
| --- | --- | --- | --- |
| 状态定义 | 同时写出一维和二维状态 | 对相邻限制理解比较扎实 | 后续优先选更简洁的一维表达 |
| 转移约束 | 偷当前时接 `dp[i-1][0]` | 正确表达相邻不能同时选 | 这是本题最核心的约束 |
| 初始化 | 手动处理 `n == 1`、`n == 2` | 正确，但可以更统一 | 用滚动变量从空前缀开始可减少特判 |
| 代码组织 | 保留 `s1`、`s2` 两版 | 方便对比学习 | 提交时可以只保留最终方案 |

## 算法优缺点

| 方案 | 优点 | 缺点 | 适用情况 |
| --- | --- | --- | --- |
| 用户解法 | 两种状态写法都正确，二维状态解释性强 | 空间还可压缩，提交代码略冗余 | 学习阶段很好，复盘价值高 |
| 推荐最优解 | 用两个变量滚动保存前两项，边界自然 | 对变量语义要求更高 | 熟悉转移后更适合提交 |

## 最优解法

1. 用 `bestOneBack` 表示处理到前一间房屋的最优结果。
2. 用 `bestTwoBack` 表示处理到前两间房屋的最优结果。
3. 当前房屋只有两种选择：不偷则保持 `bestOneBack`，偷则得到 `bestTwoBack + money`。
4. 取二者最大值并滚动更新。

- 最优时间复杂度：`O(n)`
- 最优空间复杂度：`O(1)`

### 最优解代码

```cpp
class Solution {
public:
    int rob(vector<int>& nums) {
        int bestTwoBack = 0;
        int bestOneBack = 0;
        for (int money : nums) {
            // 偷当前房屋只能接在前两间之前的最优结果后面。
            int current = max(bestOneBack, bestTwoBack + money);
            bestTwoBack = bestOneBack;
            bestOneBack = current;
        }
        return bestOneBack;
    }
};
```

## 对比与改进方向

| 对比项 | 用户代码 | 最优解代码 | 改进方向 |
| --- | --- | --- | --- |
| 状态定义 | `dp[i][0/1]` 或 `dp[i]` | 前一项和前两项最优值 | 确认只依赖两项后再压缩 |
| 更新逻辑 | 显式区分偷与不偷 | 直接取两种选择最大值 | 本质相同 |
| 边界处理 | 对 `n == 1/2` 特判 | 空前缀初始化自然覆盖 | 减少特殊分支 |
| 复杂度 | `O(n)` / `O(n)` | `O(n)` / `O(1)` | 空间优化 |
