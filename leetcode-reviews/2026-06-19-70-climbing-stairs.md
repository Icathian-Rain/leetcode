## 用户思路概述

1. 用 `dp[i]` 表示到达第 `i` 阶的方法数。
2. 初始化 `dp[0] = 1`、`dp[1] = 1`，分别表示站在起点和到达第 1 阶的方案。
3. 从第 2 阶开始，当前阶只能由前一阶或前两阶到达。
4. 最后返回 `dp[n]`。

## 用户解法复杂度

- 时间复杂度：`O(n)`
- 空间复杂度：`O(n)`
- 复杂度来源：需要顺序填充 `n + 1` 个状态。

## 用户代码注释版

```cpp
class Solution {
public:
    int climbStairs(int n) {
        vector<int> dp(n+1, 0); // dp[i] 表示到达第 i 阶的方法数。
        dp[0] = 1;              // 起点算一种“什么都不走”的方式。
        dp[1] = 1;              // 到第 1 阶只有一步。
        for(int i=2; i<=n; i++) {
            dp[i] = dp[i-1] + dp[i-2]; // 从前一阶走 1 步，或从前两阶走 2 步。
        }
        return dp[n];
    }
};
```

## 关键理解点

| 理解点 | 用户当前表现 | 影响 | 建议 |
| --- | --- | --- | --- |
| 状态定义 | `dp[i]` 含义稳定 | 能自然推出转移 | 继续保持先写状态含义再写循环 |
| 初始化 | `dp[0]` 和 `dp[1]` 都设为 1 | 边界覆盖完整 | 记住 `dp[0]` 常用于表示空前缀或起点方案 |
| 空间优化 | 使用完整数组 | 正确且易懂，但空间可降 | 熟悉后可滚动保存前两项 |

## 算法优缺点

| 方案 | 优点 | 缺点 | 适用情况 |
| --- | --- | --- | --- |
| 用户解法 | 状态直观，适合入门和复盘 | 只用到前两项，数组空间不是必须 | 初学递推时非常合适 |
| 推荐最优解 | 保留同样转移，空间降到常数 | 变量名要写清楚，否则不如数组直观 | 面试和提交时更轻量 |

## 最优解法

1. 只保存前两阶的方法数。
2. 从第 2 阶开始滚动计算当前阶。
3. 每算完一阶，就把两个历史变量向前移动。

- 最优时间复杂度：`O(n)`
- 最优空间复杂度：`O(1)`

### 最优解代码

```cpp
class Solution {
public:
    int climbStairs(int n) {
        int twoStepsBefore = 1;
        int oneStepBefore = 1;
        for (int step = 2; step <= n; step++) {
            // 到达当前阶只能来自前一阶或前两阶。
            int current = oneStepBefore + twoStepsBefore;
            twoStepsBefore = oneStepBefore;
            oneStepBefore = current;
        }
        return oneStepBefore;
    }
};
```

## 对比与改进方向

| 对比项 | 用户代码 | 最优解代码 | 改进方向 |
| --- | --- | --- | --- |
| 状态定义 | `dp[i]` 表示到达第 `i` 阶 | 两个变量表示前两项 | 先用数组理解，再压缩空间 |
| 更新逻辑 | 顺序填表 | 顺序滚动 | 转移本质相同 |
| 边界处理 | 覆盖 `n = 1` | 同样覆盖 | 初始化决定边界是否自然成立 |
| 复杂度 | `O(n)` / `O(n)` | `O(n)` / `O(1)` | 空间可优化 |
