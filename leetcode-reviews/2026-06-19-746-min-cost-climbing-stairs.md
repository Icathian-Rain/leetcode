## 用户思路概述

1. 用 `dp[i]` 记录站到某一级台阶时的最小花费。
2. `dp[1] = cost[0]`，表示踩到第 0 级台阶需要付出 `cost[0]`。
3. 后续每一级从前一级或前两级转移过来，并加上当前台阶花费。
4. 楼顶可以从最后一级或倒数第二级跨上去，所以返回二者较小值。

## 用户解法复杂度

- 时间复杂度：`O(n)`
- 空间复杂度：`O(n)`
- 复杂度来源：顺序计算每一级台阶的最小花费，并保存完整数组。

## 用户代码注释版

```cpp
class Solution {
public:
    int minCostClimbingStairs(vector<int>& cost) {
        int n=cost.size();
        vector<int> dp(n+1, 0);
        dp[0] = 0;
        dp[1] = cost[0]; // dp[1] 实际表示踩到 cost[0] 这一级的花费。
        for(int i=2; i<=n; i++) {
            dp[i] = min(dp[i-1], dp[i-2]) + cost[i-1]; // 计算踩到第 i-1 级的最小花费。
        }
        return min(dp[n], dp[n-1]); // 从最后一级或倒数第二级跨到楼顶。
    }
};
```

## 关键理解点

| 理解点 | 用户当前表现 | 影响 | 建议 |
| --- | --- | --- | --- |
| 状态语义 | 代码实际把 `dp[i]` 当作踩到 `i-1` 级的花费 | 能通过，但下标解释容易绕 | 更推荐定义为“到达第 i 级的最低花费” |
| 楼顶处理 | 用 `min(dp[n], dp[n-1])` 处理最后一步 | 符合当前状态定义 | 换状态定义后可以直接返回 `dp[n]` |
| 空间优化 | 使用完整数组 | 正确且方便检查 | 转移只依赖前两级，可压缩 |

## 算法优缺点

| 方案 | 优点 | 缺点 | 适用情况 |
| --- | --- | --- | --- |
| 用户解法 | 能正确处理典型样例，转移方向清楚 | `dp` 下标和台阶编号错开一位，复盘成本较高 | 能提交，但建议重写状态定义 |
| 推荐最优解 | `dp[i]` 表示到达第 `i` 级，返回值自然 | 需要理解“离开台阶时付费”的语义 | 更适合迁移到其他最小代价题 |

## 最优解法

1. 定义 `dp[i]` 为到达第 `i` 级台阶的最低花费，楼顶记作第 `n` 级。
2. 到达第 `i` 级可以从 `i - 1` 或 `i - 2` 级跨来，并支付离开的那一级费用。
3. 只保存前两级的结果，最后返回到达楼顶的最小花费。

- 最优时间复杂度：`O(n)`
- 最优空间复杂度：`O(1)`

### 最优解代码

```cpp
class Solution {
public:
    int minCostClimbingStairs(vector<int>& cost) {
        int n = static_cast<int>(cost.size());
        int costToPrev2 = 0;
        int costToPrev1 = 0;
        for (int step = 2; step <= n; step++) {
            // 到达 step 可以从 step-1 或 step-2 跨来，离开那一级时才付费。
            int current = min(costToPrev1 + cost[step - 1],
                              costToPrev2 + cost[step - 2]);
            costToPrev2 = costToPrev1;
            costToPrev1 = current;
        }
        return costToPrev1;
    }
};
```

## 对比与改进方向

| 对比项 | 用户代码 | 最优解代码 | 改进方向 |
| --- | --- | --- | --- |
| 状态定义 | 踩到第 `i-1` 级的花费 | 到达第 `i` 级的花费 | 让返回值和楼顶编号一致 |
| 更新逻辑 | 先算踩台阶，再额外取最后两项 | 直接算到楼顶 | 减少末尾特殊解释 |
| 边界处理 | 依赖题目 `n >= 2` | 同样自然覆盖 | 注意起点可选第 0 或第 1 级 |
| 复杂度 | `O(n)` / `O(n)` | `O(n)` / `O(1)` | 压缩空间 |

## 下一步建议

建议用“到达第 `i` 级”的定义重写一次，这会让楼顶、起点和付费时机都更顺。
