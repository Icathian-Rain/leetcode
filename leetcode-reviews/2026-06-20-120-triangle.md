## 用户思路概述

1. `s1` 用二维表记录到达三角形每个位置的最小路径和。
2. 对每一层分别处理左边界、右边界和中间位置。
3. 最后一层中取最小值作为答案。
4. `s2` 把二维表压成上一层的一维数组，每层生成 `nxt`。
5. `minimumTotal` 当前调用 `s2`。

## 用户解法复杂度

- 时间复杂度：`O(n^2)`，其中 `n` 是三角形层数
- 空间复杂度：`O(n)`
- 复杂度来源：`s2` 逐层遍历三角形所有元素，并保留上一层结果。

## 用户代码注释版

```cpp
class Solution {
public:
    int s2(vector<vector<int>>& triangle) {
        int n=triangle.size();
        vector<int> dp(n, 0);
        dp[0] = triangle[0][0]; // dp[j] 表示上一层到达 j 位置的最小路径和。
        for(int i=1; i<n; i++) {
            vector<int> nxt(n, 0);
            for(int j=0; j<=i; j++) {
                if(j == 0) {
                    nxt[j] = dp[j] + triangle[i][j]; // 左边界只能从正上方来。
                } else if(j == i) {
                    nxt[j] = dp[j-1] + triangle[i][j]; // 右边界只能从左上方来。
                } else {
                    nxt[j] = min(dp[j], dp[j-1]) + triangle[i][j]; // 中间位置取两个来源较小值。
                }
            }
            dp = nxt;
        }
        int ans=INT_MAX;
        for(int j=0; j<n; j++) {
            ans = min(ans, dp[j]);
        }
        return ans;
    }
};
```

| 理解点 | 用户当前表现 | 影响 | 建议 |

| 不规则边界 | 单独处理 `j == 0` 和 `j == i` | 正确覆盖三角形两侧 | 这是本题最容易漏的地方 |
| 空间优化 | 已从二维表写到一维滚动 | 说明转移来源理解到位 | 还可以自底向上原地压到一个数组 |

| 代码组织 | 保留 `s1`、`s2` 两版 | 复盘很清楚 | 提交时保留一版即可 |

## 算法优缺点

| 方案 | 优点 | 缺点 | 适用情况 |
| --- | --- | --- | --- |
| 用户解法 | 状态转移完整，边界清晰，空间已优化到 `O(n)` | 每层新建 `nxt`，最后还要扫描一遍 | 学习阶段非常稳 |
| 推荐最优解 | 自底向上，直接得到顶部答案，代码更短 | 思维方向和从上往下不同 | 标准最优空间写法 |

## 最优解法

1. 从最后一层开始，把 `dp[col]` 初始化为底层每个位置的值。
2. 从倒数第二层往上推。
3. 对当前位置，下一步只能走到下一层 `col` 或 `col + 1`，取较小后加当前值。
4. 推到顶层后，`dp[0]` 就是答案。

- 最优时间复杂度：`O(n^2)`
- 最优空间复杂度：`O(n)`

### 最优解代码

```cpp
class Solution {
public:
    int minimumTotal(vector<vector<int>>& triangle) {
        vector<int> dp = triangle.back();
        for (int row = static_cast<int>(triangle.size()) - 2; row >= 0; row--) {
            for (int col = 0; col <= row; col++) {
                // 从下一层相邻两个位置中选择更小的后续路径。
                dp[col] = min(dp[col], dp[col + 1]) + triangle[row][col];
            }
        }
        return dp[0];
    }
};
```

## 对比与改进方向

| 对比项 | 用户代码 | 最优解代码 | 改进方向 |
| --- | --- | --- | --- |
| 状态定义 | 到达当前层某位置的最小路径和 | 从当前层某位置到底部的最小路径和 | 体会“自顶向下”和“自底向上”的返回值差异 |
| 更新逻辑 | 从上一层两个来源来 | 从下一层两个去向选 | 都是相邻来源选择 |
| 边界处理 | 左右边界单独判断 | 自底向上天然只遍历有效列 | 可减少分支 |
| 复杂度 | `O(n^2)` / `O(n)` | `O(n^2)` / `O(n)` | 数量级相同，代码更短 |
