## 用户思路概述

1. 用 `dp[i]` 表示凑成金额 `i` 需要的最少硬币数。
2. 用 `amount + 1` 作为不可达哨兵，因为答案不可能超过 `amount`。
3. 初始化 `dp[0] = 0`，表示金额 0 不需要硬币。
4. 从小金额到大金额枚举，再尝试每一种硬币。
5. 如果硬币面额不超过当前金额，就用 `dp[i - coin] + 1` 更新当前最小值。

## 用户解法复杂度

- 时间复杂度：`O(amount * n)`，其中 `n` 是硬币种类数
- 空间复杂度：`O(amount)`
- 复杂度来源：每个金额都会遍历所有硬币。

## 用户代码注释版

```cpp
class Solution {
public:
    int coinChange(vector<int>& coins, int amount) {
        int MAX = amount + 1; // 不可达哨兵。
        vector<int> dp(amount+1, MAX);
        dp[0] = 0;
        for(int i=0; i<=amount; i++) {
            for(int j=0; j<coins.size(); j++) {
                if(coins[j] <= i) {
                    dp[i] = min(dp[i], dp[i-coins[j]] + 1);
                }
            }
        }
        return dp[amount] > amount ? -1 : dp[amount];
    }
};
```

## 最优解法

1. `dp[value]` 表示凑成 `value` 的最少硬币数。
2. 对每个硬币，从该面额开始正序更新容量。
3. 正序更新表示当前硬币可以在同一轮中被重复使用。
4. 最后如果仍是哨兵值，返回 `-1`。

- 最优时间复杂度：`O(amount * n)`
- 最优空间复杂度：`O(amount)`

### 最优解代码

```cpp
class Solution {
public:
    int coinChange(vector<int>& coins, int amount) {
        const int impossible = amount + 1;
        vector<int> dp(amount + 1, impossible);
        dp[0] = 0;
        for (int coin : coins) {
            for (int value = coin; value <= amount; value++) {
                // coin 可以重复使用，所以容量从小到大更新。
                dp[value] = min(dp[value], dp[value - coin] + 1);
            }
        }
        return dp[amount] == impossible ? -1 : dp[amount];
    }
};
```
