## 用户思路概述

1. 设正号数字之和为 `x`，负号部分之和为 `sum - x`。
2. 根据 `x - (sum - x) = target` 推出 `x = (sum + target) / 2`。
3. 如果 `sum + target` 不是偶数，或者 `target` 的绝对值超过总和，返回 0。
4. 用 `dp[j]` 统计凑出和 `j` 的方案数。
5. 每个数字只能使用一次，所以容量倒序更新。

## 用户解法复杂度

- 时间复杂度：`O(n * x)`
- 空间复杂度：`O(x)`
- 复杂度来源：每个数字都更新目标容量范围内的方案数。

## 用户代码注释版

```cpp
class Solution {
public:
    int findTargetSumWays(vector<int>& nums, int target) {
        int sum=0;
        for(auto num: nums) {
            sum += num;
        }
        // x - (sum-x) = target
        // x = (sum+target)/2
        if((sum+target)%2 != 0) return 0;
        if(abs(target) > sum) return 0;

        int x=(sum+target)/2;
        vector<int> dp(x+1, 0);
        dp[0] = 1; // 凑出 0 有一种方式：什么都不选。
        for(int i=0; i<nums.size(); i++) {
            int num=nums[i];
            for(int j=x; j>=num; j--) {
                dp[j] += dp[j-num]; // 倒序保证当前数只被分配一次符号。
            }
        }
        return dp[x];
    }
};
```

## 最优解法

1. 先判断 `abs(target) > sum`，目标超出总和则无解。
2. 再判断 `sum + target` 是否为偶数。
3. 把问题转成从数组中选若干数凑成 `positive` 的方案数。
4. 用一维数组倒序更新方案数。

- 最优时间复杂度：`O(n * positive)`
- 最优空间复杂度：`O(positive)`

### 最优解代码

```cpp
class Solution {
public:
    int findTargetSumWays(vector<int>& nums, int target) {
        int sum = accumulate(nums.begin(), nums.end(), 0);
        if (abs(target) > sum || (sum + target) % 2 != 0) return 0;

        int positive = (sum + target) / 2;
        vector<int> dp(positive + 1, 0);
        dp[0] = 1;
        for (int num : nums) {
            // 每个数只能分配一次符号，所以倒序统计方案数。
            for (int value = positive; value >= num; value--) {
                dp[value] += dp[value - num];
            }
        }
        return dp[positive];
    }
};
```
