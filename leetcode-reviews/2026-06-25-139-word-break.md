## 用户思路概述

1. 把 `wordDict` 放入哈希集合，方便判断片段是否存在。
2. `dp[i]` 表示 `s[0..i-1]` 能否被拆分。
3. 初始化 `dp[0] = true`，表示空前缀可拆分。
4. 枚举结束位置 `i` 和切分点 `j`。
5. 如果 `dp[j]` 可达且 `s[j..i-1]` 在词典中，则 `dp[i] = true`。

## 用户解法复杂度

- 时间复杂度：`O(n^3)` 量级，主要来自枚举切分点并构造子串
- 空间复杂度：`O(n + D)`，`D` 是词典存储

## 用户代码注释版

```cpp
class Solution {
public:
    bool wordBreak(string s, vector<string>& wordDict) {
        unordered_set<string> st(wordDict.begin(), wordDict.end());
        int n=s.length();
        vector<bool> dp(n+1, 0);
        dp[0] = true;
        for(int i=1; i<=n; i++) {
            for(int j=0; j<i; j++) {
                if(dp[j] && st.find(s.substr(j, i-j)) != st.end()) {
                    dp[i] = true;
                    break;
                }
            }
        }
        return dp[n];
    }
};
```

## 最优解法

在普通 DP 基础上记录词典最大长度，只枚举可能长度，减少无效子串检查。

- 最优时间复杂度：约 `O(n * L^2)`，`L` 是最大词长
- 最优空间复杂度：`O(n + D)`

### 最优解代码

```cpp
class Solution {
public:
    bool wordBreak(string s, vector<string>& wordDict) {
        unordered_set<string> words(wordDict.begin(), wordDict.end());
        int maxLen = 0;
        for (const string& word : wordDict) maxLen = max(maxLen, static_cast<int>(word.size()));

        vector<bool> dp(s.size() + 1, false);
        dp[0] = true;
        for (int end = 1; end <= static_cast<int>(s.size()); end++) {
            for (int len = 1; len <= maxLen && len <= end; len++) {
                int start = end - len;
                if (dp[start] && words.count(s.substr(start, len))) {
                    dp[end] = true;
                    break;
                }
            }
        }
        return dp[s.size()];
    }
};
```
