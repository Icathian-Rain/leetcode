## 用户思路概述

1. `dp[i]` 表示前 `i` 个字符的解码方案数。
2. `dp[0] = 1` 表示空前缀有一种基础方案。
3. 用 `test(idx, len)` 判断单字符或双字符片段是否合法。
4. 如果单字符合法，则从 `dp[i-1]` 转移。
5. 如果双字符合法，则从 `dp[i-2]` 转移。

## 用户解法复杂度

- 时间复杂度：`O(n)`
- 空间复杂度：`O(n)`

## 用户代码注释版

```cpp
class Solution {
public:
    int numDecodings(string s) {
        int n=s.length();
        vector<int> dp(n+1, 0);
        dp[0] = 1;
        auto test = [&](int idx, int len) -> bool {
            if(idx < 0) return false;
            if(len == 1) return s[idx] != '0';
            return s[idx] == '1' || (s[idx] == '2' && s[idx+1] <= '6');
        };
        for(int i=1; i<=n; i++) {
            if(test(i-1, 1)) dp[i] += dp[i-1];
            if(test(i-2, 2)) dp[i] += dp[i-2];
        }
        return dp[n];
    }
};
```

## 最优解法

本题只依赖前一项和前两项，可以压缩成两个变量。

- 最优时间复杂度：`O(n)`
- 最优空间复杂度：`O(1)`

### 最优解代码

```cpp
class Solution {
public:
    int numDecodings(string s) {
        int n = static_cast<int>(s.size());
        int twoBack = 1;
        int oneBack = s[0] == '0' ? 0 : 1;
        for (int i = 2; i <= n; i++) {
            int current = 0;
            if (s[i - 1] != '0') current += oneBack;
            int twoDigits = (s[i - 2] - '0') * 10 + (s[i - 1] - '0');
            if (twoDigits >= 10 && twoDigits <= 26) current += twoBack;
            twoBack = oneBack;
            oneBack = current;
        }
        return oneBack;
    }
};
```

| 对比项 | 用户代码 | 最优解代码 | 改进方向 |

| 状态定义 | 前缀方案数 | 滚动前缀方案数 | 本质相同 |
| 更新逻辑 | 单字符 + 双字符 | 相同 | 主干正确 |

| 复杂度 | `O(n)` / `O(n)` | `O(n)` / `O(1)` | 空间可优化 |
