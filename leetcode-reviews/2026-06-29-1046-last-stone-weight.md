## 用户思路概述

1. 把所有石头重量放入大根堆，使当前最大石头可以快速取出。
2. 每轮取出两个最大重量 `y` 和 `x`。
3. 如果两块石头相等，二者同时消失；否则把差值 `y - x` 放回堆中。
4. 堆中不足两块石头时结束，返回剩余重量或 `0`。

## 用户解法复杂度

- 时间复杂度：`O(n log n)`
- 空间复杂度：`O(n)`
- 复杂度来源：每块石头入堆一次，后续每轮最多弹出两次并插入一次，每次堆操作为 `O(log n)`。

## 用户代码注释版

```cpp
class Solution {
public:
    int lastStoneWeight(vector<int>& stones) {
        priority_queue<int, vector<int>, less<int>> pq; // 大根堆，每次取当前最重石头。
        for(auto stone: stones) {
            pq.push(stone);
        }

        while(pq.size() >= 2) { // 至少有两块石头才需要继续碰撞。
            int y = pq.top(); pq.pop();
            int x = pq.top(); pq.pop();
            if(x == y) {
                continue; // 相等时两块都消失。
            } else {
                pq.push(y-x); // 不相等时新石头继续参与后续比较。
            }
        }
        return pq.size() == 0 ? 0 : pq.top();
    }
};
```

| 理解点 | 用户当前表现 | 影响 | 建议 |

## 最优解法

1. 用大根堆保存所有仍然存在的石头。
2. 当堆中至少有两块石头时，弹出最重和次重。
3. 如果二者不同，把差值重新放回堆。
4. 最后堆为空返回 `0`，否则返回唯一剩余石头。

- 最优时间复杂度：`O(n log n)`
- 最优空间复杂度：`O(n)`

### 最优解代码

```cpp
class Solution {
public:
    int lastStoneWeight(vector<int>& stones) {
        priority_queue<int> heap(stones.begin(), stones.end());

        while (heap.size() > 1) {
            int first = heap.top();
            heap.pop();
            int second = heap.top();
            heap.pop();
            // 两块重量不同才会产生新的候选石头。
            if (first != second) {
                heap.push(first - second);
            }
        }

        return heap.empty() ? 0 : heap.top();
    }
};
```
