- 题意前提：字符按出现频次降序，同一种字符连续输出；同频字符之间顺序不限。当前 128 项计数依赖题目限定的英文字母与数字字符范围。

## 用户思路概述

1. 创建 128 个 `{频次, 字符编码}` 记录，字符编码直接作为计数下标。
2. 扫描字符串，累计每个字符的频次。
3. 使用 `greater<pii>()` 按 pair 的字典序降序排列，先比较频次，再比较字符编码。
4. 跳过零频字符，按频次一次性构造整段字符并追加到答案。

## 用户解法复杂度

- 设字符串长度为 `n`，计数表大小为 `C=128`。
- 时间复杂度：`O(n + C log C)`，固定字符集下为 `O(n)`。输出字符总数为 `n`，不能把分段构造字符串的开销遗漏。
- 空间复杂度：计数表为 `O(C)`；当前 `string(count, ch)` 还会产生最长 `O(n)` 的临时字符串，因此原实现最坏辅助空间为 `O(C+n)`，即使不计最终答案。含答案总空间仍为 `O(n+C)`。
- 参数 `string s` 按值传递；若调用时发生输入复制，也需 `O(n)` 空间，通常与题目接口和工作区空间分开说明。

## 用户代码注释版

> 只在文档中加入解释，源码中的原公开实现保持不变。

```cpp
using pii = pair<int, int>;
class Solution {
public:
    string frequencySort(string s) {
        vector<pii> cnt;
        for(int i=0; i<128; i++) {
            cnt.push_back({0, i}); // 字符编码就是计数位置。
        }
        for(auto ch: s) {
            cnt[ch].first++; // 依赖本题 ASCII 范围内的字符约束。
        }
        // 先按频次降序；同频时按字符编码降序，也是合法答案。
        sort(cnt.begin(), cnt.end(), greater<pii>());
        string ans = "";
        for(auto [count, ch]: cnt) {
            if(count != 0)
            ans += string(count, ch); // 每个字符整体输出；这里会创建临时字符串。
        }
        return ans;

    }
};
```

## 关键理解点

| 理解点 | 用户当前表现 | 影响 | 复盘重点 |
| --- | --- | --- | --- |
| 排序对象 | 排序固定大小的字符计数表 | 避免对 n 个字符直接比较排序 | 复杂度中的排序规模是 C，不是 n |
| 并列规则 | pair 次关键字采用字符编码降序 | 题目允许同频任意顺序，符合要求 | 不需要额外稳定排序或恢复原顺序 |
| 字符分组 | 每种字符一次性连续输出 | 同时满足频次顺序与同字符连续 | 只保证相同频次相邻还不够 |
| 字符范围 | 使用长度 128 的表 | 对本题字符范围足够 | 若输入改为任意字节，需改用 256 项并使用 unsigned char 下标；Unicode 需另建模型 |
| 内存构造 | 先建临时字符串，再追加 | 不改变线性时间，但增加临时空间 | 使用 append(count, ch) 直接构造到答案 |

## 算法优缺点

| 方案 | 优点 | 取舍 | 适用情况 |
| --- | --- | --- | --- |
| 用户固定字符集排序 | 直接、简洁，已达线性时间 | 分段临时字符串可能占 O(n) 空间 | 字符集小且已知 |
| 推荐固定字符集排序 | 保留原算法，预留答案容量，直接 append | 时间复杂度不再下降 | 本题最合适的日常实现 |
| 按频次建桶 | 时间 O(n+C)，容易迁移到频次分层 | 通常需 O(n+C) 桶空间，本题未必划算 | 候选种类多、希望避免比较排序时 |

## 可能的最优解法

1. 沿用固定字符集计数和计数项排序；本题无需为了使用堆而替换当前方案。
2. 排序后始终保持：已输出字符的频次不小于后续字符频次，每种字符只输出一次完整分组。
3. 用 `reserve(s.size())` 预留结果容量，以 `append(count, ch)` 直接追加，省去显式临时字符串。
4. 推荐方案与原方案均为时间最优级：必须读取输入并写出长度为 n 的答案，因此需要 `Ω(n)` 时间。

- 时间：`O(n+C log C)`，固定 C 下为 `O(n)`。
- 辅助空间：`O(C)`，不计输入按值复制和返回字符串；含返回字符串为 `O(n+C)`。
- 桶排序也是线性方案，但本题固定字符集很小，选择空间更紧凑、与原实现一致的方案。

### 推荐 C++20 提交代码

```cpp
class Solution {
public:
    string frequencySort(string s) {
        vector<pair<int, int>> counts;
        counts.reserve(128);
        for (int ch = 0; ch < 128; ++ch) {
            counts.push_back({0, ch});
        }
        for (unsigned char ch : s) {
            ++counts[ch].first;
        }
        // 固定字符集只需排序 128 项，同频字符顺序不限。
        sort(counts.begin(), counts.end(), greater<pair<int, int>>());
        string result;
        result.reserve(s.size());
        for (const auto& [count, ch] : counts) {
            if (count > 0) {
                result.append(count, static_cast<char>(ch));
            }
        }
        return result;
    }
};
```
