## 用户思路概述

1. 对区间按默认字典序排序，先比较左端点，同左端点时比较右端点。
2. 以第一个区间初始化尚未输出的当前段 `[l,r]`。
3. 如果下一区间左端点不大于 `r`，扩张当前右边界；否则输出当前段，重新开始一段。
4. 循环结束后补入最后一段。

## 用户解法复杂度

- 时间复杂度：`O(n log n)`，排序主导，后续扫描 `O(n)`。
- 辅助空间：常见 `std::sort` 实现的调用栈为 `O(log n)`，扫描状态为 `O(1)`，不计返回结果。
- 含返回结果的总空间：最坏 `O(n)`。排序会改变输入区间顺序，没有复制整份输入。

## 用户代码注释版

> 以下仅在文档中解释原实现，源码中的公开函数保持不变。

```cpp
class Solution {
public:
    vector<vector<int>> merge(vector<vector<int>>& intervals) {
        int n=intervals.size();
        sort(intervals.begin(), intervals.end()); // 后续左端点单调不减。

        vector<vector<int>> ans;
        // 当前段尚未放入 ans；这里依赖题目保证输入非空。
        int l=intervals[0][0], r=intervals[0][1];
        for(int i=1; i<n; i++) {
            if(intervals[i][0] <= r) {
                // 闭区间端点相等也相交；包含关系下右端点不能缩小。
                r = max(r, intervals[i][1]);
            } else {
                // 后续左端点只会更大，当前段可安全定稿。
                ans.push_back({l, r});
                l = intervals[i][0], r = intervals[i][1];
            }
        }
        ans.push_back({l, r}); // 最后一段尚未输出，必须收尾。
        return ans;

    }
};
```

## 关键理解点

| 理解点 | 用户当前表现 | 影响 | 建议 |
| --- | --- | --- | --- |
| 算法选择 | 先排序再扫描 | 达到常用比较排序方案的最优级别 | 无需更换算法 |
| 当前段含义 | `[l,r]` 是尚未定稿的一段 | 状态清楚，断开时才能输出 | 口述说明后续为何不可能再连接已输出段 |
| 闭区间边界 | 使用 `<= r` | 正确合并 `[1,4]` 与 `[4,5]` | 与严格分离条件 `r < nextLeft` 配对记忆 |
| 包含关系 | 使用 `max` 更新右端点 | `[1,10],[2,3]` 不会错误缩短覆盖范围 | 保留这个写法 |
| 初始化与收尾 | 直接读取首项，循环后补最后一段 | 在本题约束内正确 | 泛化为空输入时先判空，或改成结果末段写法 |

## 算法优缺点

| 方案 | 优点 | 取舍 | 适用情况 |
| --- | --- | --- | --- |
| 用户解法 | 当前段显式独立，控制流直接，复杂度达标 | 需非空初始化和末尾补入；会重排输入 | 无序、非空的区间集合 |
| 推荐最优解 | 用结果最后一段维护当前范围，统一初始化与收尾 | 同样会重排输入，复杂度不变 | 本题及需要支持空集合的复用场景 |

## 可能的最优解法

1. 沿用左端点排序，不改变原算法方向。
2. 不变量：处理完一个前缀后，`result` 是这个前缀合并后的有序结果，只有最后一段可能继续扩张。
3. 结果为空或末段严格位于当前区间左侧时，新增一段；否则扩张末段右边界。
4. 排序保证更早的结果段不会与当前及后续区间重新连接，因此只检查末段即可。

- 时间复杂度：`O(n log n)`，采用常用比较排序模型；这里不声称限定整数域下不存在其他算法。
- 辅助空间：常见排序实现为 `O(log n)`，不计结果；含结果最坏 `O(n)`。
- 原解已经满足训练目标，推荐写法只减少初始化与收尾分支。

### 最优解代码

```cpp
class Solution {
public:
    vector<vector<int>> merge(vector<vector<int>>& intervals) {
        sort(intervals.begin(), intervals.end());
        vector<vector<int>> result;
        for (const auto& interval : intervals) {
            // 闭区间端点相等时也重叠；只有严格分离才新增一段。
            if (result.empty() || result.back()[1] < interval[0]) {
                result.push_back(interval);
            } else {
                // 已排序，当前区间只能扩展最后一段的右边界。
                result.back()[1] = max(result.back()[1], interval[1]);
            }
        }
        return result;
    }
};
```
