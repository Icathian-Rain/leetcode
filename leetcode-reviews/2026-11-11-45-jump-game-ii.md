- 约束要点：`1 <= nums.length <= 10^4`，`0 <= nums[i] <= 1000`；题目保证可以到达 `n-1`；`n == 1` 时答案为 0

## 用户思路概述

1. 维护 `l`（当前位置）、`r`（目前能到达的最远下标）、`end`（当前这一步的跳跃边界）、`ans`（跳跃次数）。
2. 扫描 `l` 从 0 到 `n-2`（最后一个下标不需要再起跳），每轮用 `r = max(r, l + nums[l])` 扩张最远可达。
3. 当 `l == end` 时，说明当前这一步的所有候选起点已检查完，`ans` 加一，并把 `end` 推进到 `r`，开始统计下一步。
4. 返回 `ans`。

## 用户解法复杂度

- 时间复杂度：`O(n)`（每个下标最多访问一次）
- 空间复杂度：`O(1)`
- 复杂度来源：单趟扫描，常数个整型变量。

## 用户代码注释版

> 只在点评文档中展示加注释版本；不把这些注释写回 `src/*.cpp` 的用户原代码。

```cpp
class Solution {
public:
    int jump(vector<int>& nums) {
        int n=nums.size();
        int l=0, r=0;
        int end = 0;
        int ans = 0;
        // l 扫到 n-2 即可：站在最后一个下标时不需要再跳
        // l<=r 在本题保证可达的前提下是冗余保护，提前退出不影响答案
        for(l=0; l<n-1 && l<=r; l++) {
            r = max(r, l+nums[l]);   // r：从 [0, l] 出发能到达的最远下标
            if(l == end) {          // 走完当前这一步的可达范围：结算一次跳跃
                end = r;
                ans++;
            }
        }
        return ans;
    }
};
```

## 关键理解点

| 理解点 | 用户当前表现 | 影响 | 建议 |
| --- | --- | --- | --- |
| 分层推进结构 | `end` 是"当前跳跃的边界"，`l == end` 时结算 | 这是本题的核心不变量：`ans` 次跳跃能覆盖的下标区间是 `(prevEnd, end]`，与分层 BFS 等价，理解到位 | 复盘时能说出"每个 `ans` 对应一段连续下标区间" |
| `n-1` 处不再起跳 | 循环上界 `l < n-1` | 正确避免"到达终点后多算一步"，`n==1` 时循环不执行返回 0，正确 | 已达标；这是本题最容易多算一步的地方 |
| 冗余条件 | `l <= r` 在保证可达的前提下永不触发 | 无害，但会掩盖"本题依赖可达性保证"这一前提 | 若去掉该条件，答案不变；保留时应在心里注明它依赖题设 |
| 命名 | `l`/`r`/`end` 三变量语义各异 | 次要级问题：`l` 是扫描下标，`r` 是最远可达，`end` 是层边界，命名未体现差异 | 推荐用 `i`/`farthest`/`boundary` 一类命名 |

## 算法优缺点

| 方案 | 优点 | 缺点 | 适用情况 |
| --- | --- | --- | --- |
| 用户解法（分层推进计数） | `O(n)`/`O(1)`，一遍扫描；与 55 的状态自然衔接 | 冗余的 `l<=r` 条件依赖题设才无害 | 求"最少几步推进到底"的问题 |
| 推荐最优解 | 与用户解法同构，多一个"提前结算"出口（`boundary >= n-1` 时 break） | 无实质缺点 | 同上；提前出口在大数组上略省，主要是让"到达即停"的语义显式化 |

## 最优解法

1. 维护 `farthest`（当前层内能到达的最远下标）与 `boundary`（当前层的右端点），跳跃次数 `ans` 初始为 0。
2. 扫描 `i` 从 0 到 `n-2`：先用 `farthest = max(farthest, i + nums[i])` 收集本层所有候选。
3. 当 `i == boundary` 时，本层检查完毕，`ans` 加一并把 `boundary` 推进到 `farthest`；若 `farthest` 已越过 `n-1`，可提前结束。
- 关键不变量：`boundary` 是"已用 `ans` 步恰好能覆盖的最远下标"；每跨过一次 `boundary`，步数加一。等价于对隐式分层图做 BFS，每层就是一段连续下标区间。
- 最优时间复杂度：`O(n)`
- 最优空间复杂度：`O(1)`

### 最优解代码

```cpp
class Solution {
public:
    int jump(vector<int>& nums) {
        int n = static_cast<int>(nums.size());
        int ans = 0;
        int farthest = 0; // 本层内能到达的最远下标
        int boundary = 0; // 当前层右端点：已用 ans 步恰好覆盖到这里
        for (int i = 0; i < n - 1; i++) {
            farthest = max(farthest, i + nums[i]);
            if (i == boundary) {        // 本层候选收集完，结算一步
                ans++;
                boundary = farthest;
                if (boundary >= n - 1) break; // 已能到达终点，无需继续
            }
        }
        return ans;
    }
};
```
