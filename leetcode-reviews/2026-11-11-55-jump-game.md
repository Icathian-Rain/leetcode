## 基本信息

- 日期：2026-11-11
- 主题：第 10 周区间与贪心 - 可达性与跳跃
- 难度：中等
- 本次结果：通过（用户确认已测试通过）
- 对应源码：[src/55.jump-game.cpp](../src/55.jump-game.cpp)
- 资料来源：[LeetCode 中国版官方题目页](https://leetcode.cn/problems/jump-game/)，2026-11-11 查询
- 约束要点：`1 <= nums.length <= 10^4`，`0 <= nums[i] <= 10^5`；数组长度为 1 时起点即终点，直接返回 `true`

## 用户思路概述

1. 维护区间变量 `l`（当前位置）和 `r`（目前能到达的最远下标），均初始化为 0。
2. 循环条件为 `l < n && l <= r`：位置未越界且当前仍在可达范围内时，用 `r = max(r, l + nums[l])` 扩张最远可达边界。
3. 循环自然退出后返回 `l == n`：若 `l` 走到了 `n`，说明全程可达；若中途 `l > r`，说明卡在某个不可再前进的位置。

## 用户解法复杂度

- 时间复杂度：`O(n)`（每个下标最多访问一次）
- 空间复杂度：`O(1)`
- 复杂度来源：单趟扫描，只维护两个整型变量。

## 用户代码注释版

> 只在点评文档中展示加注释版本；不把这些注释写回 `src/*.cpp` 的用户原代码。

```cpp
class Solution {
public:
    bool canJump(vector<int>& nums) {
        int n=nums.size();
        int l=0, r=0;
        // l：当前检查的位置；r：目前能到达的最远下标
        // l > r 表示当前位置已不可达，提前终止
        for(l=0; l<n && l<=r; l++) {
            r = max(r, l+nums[l]);   // 从 l 出发最远到 l+nums[l]，扩张可达边界
        }
        return l == n;               // l 走到 n 即全程可达；卡住时 l < n
    }
};
```

## 关键理解点

| 理解点 | 用户当前表现 | 影响 | 建议 |
| --- | --- | --- | --- |
| 可达边界的单调性 | `r` 只增不减，且从不回退检查 | 这是贪心正确性的核心：一个位置可达，则它之前的所有位置都可达，无需回头 | 复盘时能说出"为什么不需要记忆化或 DP" |
| 终止条件的编码方式 | 用 `l == n` 同时编码成功与卡死两种出口 | 正确且紧凑，是亮点；但成功/失败路径都藏在循环退出原因里，初读需要推理 | 口头复盘时练习把两种出口分开陈述：`l == n`（走完）与 `l > r`（卡住） |
| 边界情况 | `n == 1` 时循环至少执行一次后退出，返回 `true` | 正确覆盖"起点即终点" | 已达标 |
| 命名 | `l`、`r` 像区间端点，实际语义是"当前位置"和"最远可达" | 次要级问题：命名与昨日区间题的 `l`/`r` 撞车，容易误读 | 建议用 `i`/`farthest` 一类名字表达真实语义 |

## 算法优缺点

| 方案 | 优点 | 缺点 | 适用情况 |
| --- | --- | --- | --- |
| 用户解法（单变量维护最远可达） | `O(n)`/`O(1)`，一遍扫描；边界扩张逻辑极简 | 出口编码较隐晦；命名偏区间风格 | 判定"能否全程推进"的可达性问题 |
| 推荐最优解 | 与用户解法同构，仅命名与返回值更直白（`farthest >= n-1`） | 无实质缺点 | 同上，且迁移到 45、1326 时状态语义更连贯 |

## 最优解法

1. 维护"目前能到达的最远下标" `farthest`，初始为 0。
2. 从下标 0 开始扫描：若 `i > farthest`，说明位置 `i` 不可达，直接返回 `false`；否则用 `farthest = max(farthest, i + nums[i])` 扩张。
3. 扫描中一旦 `farthest >= n - 1` 可提前返回 `true`；扫描结束也可统一判断。
- 关键不变量：`farthest` 是前 `i+1` 个位置能覆盖的最远下标；位置可达性单调（可达位置之前全部可达），故无需回退。
- 最优时间复杂度：`O(n)`
- 最优空间复杂度：`O(1)`

### 最优解代码

```cpp
class Solution {
public:
    bool canJump(vector<int>& nums) {
        int n = static_cast<int>(nums.size());
        int farthest = 0; // 目前能到达的最远下标
        for (int i = 0; i < n; i++) {
            // i 超出可达边界：从这里开始全部不可达
            if (i > farthest) return false;
            farthest = max(farthest, i + nums[i]);
        }
        return true;
    }
};
```
