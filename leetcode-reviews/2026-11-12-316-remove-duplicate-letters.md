- 约束要点：`1 <= s.length <= 10^4`，仅小写字母；输出每个字母恰好一次、保持相对顺序、字典序最小；与 1081. Smallest Subsequence of Distinct Characters 为同一题

## 用户思路概述

1. 预处理 `cnt[c]`：每个字母在剩余未扫描部分中的出现次数（先统计总数，扫描中每见一次就减一）。
2. 用 `ans` 字符串当栈：对每个字符先 `cnt[x]--`；若已在栈中（`vis[x]`）则跳过。
3. 否则做单调栈弹出：当栈顶字符比当前字符大、且栈顶字符在剩余部分还会出现（`cnt[栈顶] > 0`）时，弹出栈顶并清除其 `vis` 标记——当前栈顶可被后面更小的安排替代。
4. 当前字符入栈并标记 `vis`；扫描结束后 `ans` 即字典序最小的去重结果。

## 用户解法复杂度

- 时间复杂度：`O(n)`（每个字符至多入栈一次、出栈一次）
- 空间复杂度：`O(|Σ|)`（26 大小的 `cnt`、`vis` 与栈内字符数不超过 26）
- 复杂度来源：单趟扫描，栈操作总量摊还后每个元素 O(1)；辅助空间由字符集大小决定，与 `n` 无关时可视为 `O(1)`。

## 用户代码注释版

> 只在点评文档中展示加注释版本；不把这些注释写回 `src/*.cpp` 的用户原代码。

```cpp
using pii = pair<int, int>; // 未使用的类型别名，可删除
class Solution {
public:
    string removeDuplicateLetters(string s) {
        int n=s.size();
        vector<int> cnt(26, 0), vis(26, 0);
        for(auto ch: s) cnt[ch-'a']++;  // cnt：每个字母的总出现次数
        string ans;                     // 同时充当栈和结果
        for(auto ch: s) {
            int x = ch - 'a';
            cnt[x]--;                   // 先扣减：cnt[栈顶] 表示"当前扫描位置之后还剩几次"
            if(vis[x]) continue;        // 已在栈中，跳过避免重复
            // 弹出条件：栈顶更大（当前字符放前面更优）且栈顶之后还会出现（弹出安全）
            while(!ans.empty() && ans.back() > ch && cnt[ans.back()-'a'] > 0) {
                vis[ans.back() - 'a'] = 0;
                ans.pop_back();
            }
            ans.push_back(ch);
            vis[x] = 1;
        }
        return ans;
    }
};
```

| --- | --- | --- | --- |
| 弹出条件的三要素 | `栈顶更大` + `之后还会出现` + `不在栈中才入栈` 全部正确 | 这是本题正确性的全部核心，三要素缺一不可，掌握扎实 | 复盘时逐条反问：去掉"之后还会出现"会怎样（丢字母）；去掉"已入栈跳过"会怎样（重复） |

## 算法优缺点

| 方案 | 优点 | 缺点 | 适用情况 |
| --- | --- | --- | --- |
| 用户解法（计数 + 单调栈） | `O(n)` 线性最优；`ans` 一物两用（栈即结果），结构紧凑 | 弹出条件依赖三要素同时成立，写错任何一个都导致错误答案 | "保序 + 字典序最小/最大"的选择性保留问题 |
| 递归贪心变体（每轮选可行最小字符） | 思路直观 | 每层要重新计数，复杂度更高；不利于迁移 | 仅作理解参考，本次不展开 |

## 最优解法

1. 统计每个字母出现次数 `cnt`，维护"是否已在栈中"的 `inStack`。
2. 顺序扫描：`cnt[c]--`；已在栈中则跳过。
3. 否则弹出栈顶中"比当前字符大且之后还会出现"的字符（弹出时清除 `inStack`），再把当前字符入栈。
4. 栈底到栈顶即为答案。
- 关键不变量：栈内字符严格递增地保持当前可见的最优前缀；每个字符只有在"后面还有备份"时才允许被弹出，保证每字母最终恰好保留一次。
- 最优时间复杂度：`O(n)`
- 最优空间复杂度：`O(|Σ|)`，即 `O(1)`（26 个字母）

### 最优解代码

```cpp
class Solution {
public:
    string removeDuplicateLetters(string s) {
        vector<int> cnt(26, 0), inStack(26, 0);
        for (char ch : s) cnt[ch - 'a']++;
        string stk; // 栈内即当前最优前缀，结束时就是答案
        for (char ch : s) {
            int x = ch - 'a';
            cnt[x]--; // cnt[x] 从此表示"x 在当前位置之后还出现几次"
            if (inStack[x]) continue; // 已保留过，跳过保证每字母恰好一次
            // 弹出条件三要素：栈非空、栈顶更大、栈顶之后还有备份
            while (!stk.empty() && stk.back() > ch && cnt[stk.back() - 'a'] > 0) {
                inStack[stk.back() - 'a'] = 0;
                stk.pop_back();
            }
            stk.push_back(ch);
            inStack[x] = 1;
        }
        return stk;
    }
};
```
