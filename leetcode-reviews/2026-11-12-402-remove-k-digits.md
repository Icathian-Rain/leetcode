## 基本信息

- 日期：2026-11-12
- 主题：第 10 周区间与贪心 - 字符串边界与分段
- 难度：中等
- 本次结果：通过（用户确认已测试通过）
- 对应源码：[src/402.remove-k-digits.cpp](../src/402.remove-k-digits.cpp)
- 资料来源：[LeetCode 中国版官方题目页](https://leetcode.cn/problems/remove-k-digits/)，2026-11-12 查询
- 约束要点：`1 <= k <= num.length <= 10^5`，`num` 仅含数字且除 0 外无前导零；输出不能有前导零，删空返回 `"0"`

## 用户思路概述

1. 用字符串 `ans` 当栈，顺序扫描 `num`：当栈顶数字比当前数字大且删除配额 `k > 0` 时，弹出栈顶并 `k--`——高位换小值优先。
2. 当前数字入栈。
3. 扫描后若配额未用完（说明剩余数字非降），从尾部继续弹出直到 `k == 0`。
4. 去除前导零；结果为空返回 `"0"`。

## 用户解法复杂度

- 时间复杂度：`O(n)`（每个数字至多入栈、出栈各一次）
- 空间复杂度：`O(n)`（栈字符串，也是返回结果本身）
- 复杂度来源：单趟扫描加摊还的栈操作；前导零清理最多再扫一趟。

## 用户代码注释版

> 只在点评文档中展示加注释版本；不把这些注释写回 `src/*.cpp` 的用户原代码。

```cpp
class Solution {
public:
    string removeKdigits(string num, int k) {
        string ans;  // 同时充当栈和结果
        for(auto c: num) {
            // 弹出条件：栈顶更大（高位换小值更优）且还有删除配额
            while(!ans.empty() && ans.back() > c && k>0) {
                ans.pop_back();
                k--;
            }
            ans.push_back(c);
        }
        // 扫描完配额没用尽：剩余数字非降，从尾部删最大的若干位
        while(k > 0) {
            ans.pop_back();
            k--;
        }
        int i=0;
        while(i < ans.size() && ans[i] == '0') i++;  // 去前导零
        ans = ans.substr(i);
        return ans.empty() ? "0": ans;   // 全删或只剩零时返回 "0"
    }
};
```

## 关键理解点

| 理解点 | 用户当前表现 | 影响 | 建议 |
| --- | --- | --- | --- |
| 贪心方向 | 高位优先换小值（`ans.back() > c` 时弹出） | 正确：数的大小由高位决定，越靠前的位置换小值收益越大 | 口头证明"删除一个逆序对中的较大者不劣" |
| 尾部补删 | 扫描后配额未用完时从尾部弹出 | 正确：走到这一步说明剩余数字非降，尾部是最大的若干位；漏掉这一步是本题最常见错误 | 复盘时先构造一个触发尾部补删的输入（如 `"112", k=1`）并走一遍 |
| 前导零与空结果 | 去零后判空返回 `"0"` | 正确覆盖 `"10", k=2` → `"0"` 和 `"10200", k=1` → `"200"` | 已达标 |
| 比较符方向 | 栈顶 `>` 当前才弹，相等不弹 | 正确：弹相等位不改变数值且浪费配额 | 想清"为什么 `=` 不弹"——留下更长的相同前缀无损失 |

## 最优解法

1. 用栈维护保留的数字前缀：扫描中，只要栈顶大于当前数字且 `k > 0`，弹出栈顶并 `k--`。
2. 扫描结束后若 `k > 0`，从尾部截断 `k` 位（此时栈内非降）。
3. 去除前导零，空串返回 `"0"`。
- 关键不变量：栈内始终是"当前已见前缀在配额约束下能形成的最小数"；配额用尽后栈只追加不弹出。
- 最优时间复杂度：`O(n)`
- 最优空间复杂度：`O(n)`（结果栈）

### 最优解代码

```cpp
class Solution {
public:
    string removeKdigits(string num, int k) {
        string stk; // 栈内是当前前缀在配额内能成的最小数
        for (char c : num) {
            // 高位换小值优先：栈顶更大且还有配额才弹
            while (!stk.empty() && stk.back() > c && k > 0) {
                stk.pop_back();
                k--;
            }
            stk.push_back(c);
        }
        // 配额没用尽：剩余数字非降，从尾部删最大的若干位
        while (k > 0) {
            stk.pop_back();
            k--;
        }
        // 去前导零
        size_t firstNonZero = stk.find_first_not_of('0');
        if (firstNonZero == string::npos) return "0"; // 全零或删空
        return stk.substr(firstNonZero);
    }
};
```
