# 题解点评 - 763. Partition Labels（划分字母区间）

## 基本信息

- 日期：2026-11-12
- 主题：第 10 周区间与贪心 - 字符串边界与分段
- 难度：中等
- 本次结果：通过（用户确认已测试通过）
- 对应源码：[src/763.partition-labels.cpp](../src/763.partition-labels.cpp)
- 资料来源：[LeetCode 中国版官方题目页](https://leetcode.cn/problems/partition-labels/)，2026-11-12 查询
- 约束要点：`1 <= s.length <= 500`，仅小写字母；要求同一字母最多出现在一个片段，且片段数尽可能多

## 用户思路概述

1. 预处理 `rightMost[c]`：记录每个字母最后出现的下标（倒序覆盖式赋值即可，最后一轮留下的就是最大下标）。
2. 扫描阶段复用昨日的层边界骨架：维护 `far`（当前片段必须延伸到的最远下标）与 `pre`（上一片段结束位置）。
3. 每轮用 `far = max(far, rightMost[s[i]-'a'])` 扩张；当 `i == far` 时当前位置是本片段的必然终点，输出长度 `far - pre + 1`，并把 `pre` 推进到 `far + 1`。
4. 返回所有片段长度。

## 用户解法复杂度

- 时间复杂度：`O(n)`（预处理一趟 + 扫描一趟）
- 空间复杂度：`O(1)`（26 大小的 `rightMost` 数组，与 `n` 无关）
- 复杂度来源：两趟线性扫描；辅助数组大小只由字符集决定。

## 用户代码注释版

> 只在点评文档中展示加注释版本；不把这些注释写回 `src/*.cpp` 的用户原代码。

```cpp
class Solution {
public:
    vector<int> partitionLabels(string s) {
        int n=s.length();
        vector<int> rightMost(26, -1);
        // 顺序覆盖：每轮赋值留下的最终是每个字母最后出现的下标
        for(int i=0; i<n; i++) {
            rightMost[s[i]-'a'] = i;
        }
        int pre = 0;  // 上一片段结束位置（开区间起点）
        int far = 0;  // 当前片段必须延伸到的最远下标
        vector<int> ans;
        for(int i=0; i<n; i++) {
            far = max(far, rightMost[s[i]-'a']);
            if(i == far) {              // 本片段所有字母的最后一处都已扫过，可以切分
                ans.push_back(far-pre+1);
                pre = far+1;
            }
        }
        return ans;
    }
};
```

## 算法优缺点

| 方案 | 优点 | 缺点 | 适用情况 |
| --- | --- | --- | --- |
| 用户解法（最后出现位置 + 边界推进） | `O(n)`/`O(1)`，两趟扫描；完整复用本周已掌握的骨架，迁移成本最低 | 无实质缺点 | "每个对象必须完整落进一段"的分段问题 |
| 倒序预处理变体 | 一次倒序循环即可填好最后出现位置 | 与正序覆盖相比只是写法差异，无复杂度区别 | 纯写法偏好，本次不展开 |

## 最优解法

1. 第一趟记录每个字母的最后出现下标 `last[c]`。
2. 第二趟扫描，维护 `segEnd`（当前片段必须延伸到的最远下标）与 `segStart`（当前片段起点）。
3. 每见一个字符就把 `segEnd` 扩张到 `max(segEnd, last[c])`；当 `i == segEnd` 时片段自洽，记录长度 `segEnd - segStart + 1`，下一片段从 `segEnd + 1` 开始。
- 关键不变量：`segEnd` 是"当前片段内所有已见字母的最后出现位置的最大值"；片段数尽可能多等价于在每个自洽位置立即切分。
- 最优时间复杂度：`O(n)`
- 最优空间复杂度：`O(1)`（26 大小数组）

### 最优解代码

```cpp
class Solution {
public:
    vector<int> partitionLabels(string s) {
        int n = static_cast<int>(s.size());
        int last[26];
        for (int i = 0; i < 26; i++) last[i] = -1;
        for (int i = 0; i < n; i++) last[s[i] - 'a'] = i; // 每个字母最后出现位置
        vector<int> ans;
        int segStart = 0, segEnd = 0;
        for (int i = 0; i < n; i++) {
            // 片段必须延伸到本片段内所有字母的最后出现处
            segEnd = max(segEnd, last[s[i] - 'a']);
            if (i == segEnd) {          // 扫到必然终点，立即切分保证片段数最多
                ans.push_back(segEnd - segStart + 1);
                segStart = segEnd + 1;
            }
        }
        return ans;
    }
};
```
