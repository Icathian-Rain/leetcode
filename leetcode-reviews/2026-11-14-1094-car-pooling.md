- 约束要点：`1 <= trips.length <= 1000`，`1 <= numPassengers <= 100`，`0 <= from < to <= 1000`，`1 <= capacity <= 10^5`；同一位置先下后上，下车座位可立即被新乘客占用

## 用户思路概述

1. 把每个行程拆成两个事件：`{from, +num}`（上车）与 `{to, -num}`（下车）。
2. 按字典序排序事件——同一位置时负数事件（下车）天然排在正数事件（上车）之前，符合"先下后上"语义。
3. 扫描事件，维护 `total`（当前车内人数）；累计后若 `total > capacity` 立即返回 `false`。
4. 全部事件处理完返回 `true`。

## 用户解法复杂度

- 时间复杂度：`O(n log n)`（事件排序主导）
- 空间复杂度：`O(n)`（事件数组）
- 复杂度来源：`2n` 个事件的排序；扫描只维护一个整型变量。本题值域仅 1000，若用差分数组可到 `O(n + 1000)`，但量级上无实际差别。

## 用户代码注释版

> 只在点评文档中展示加注释版本；不把这些注释写回 `src/*.cpp` 的用户原代码。

```cpp
class Solution {
public:
    bool carPooling(vector<vector<int>>& trips, int capacity) {
        int n=trips.size();
        vector<vector<int>> events;
        for(auto trip: trips) {
            int num = trip[0], from = trip[1], to = trip[2];
            events.push_back({from, num});    // 上车事件：人数 +num
            events.push_back({to, -num});     // 下车事件：人数 -num
        }
        // 字典序排序：同一位置负数在前，先下后上，座位可立即复用
        sort(events.begin(), events.end());
        int total = 0;  // 当前车内人数
        for(auto e: events) {
            total += e[1];
            if(total > capacity) {   // 任意时刻超载即失败
                return false;
            }
        }
        return true;
    }
};
```

## 算法优缺点

| 方案 | 优点 | 缺点 | 适用情况 |
| --- | --- | --- | --- |
| 用户解法（事件排序扫描） | `O(n log n)` 不受值域限制；与 253 模板统一 | 值域小时不如差分数组简洁 |
| 差分数组 | `O(n + 1000)` 线性；无排序、无事件容器 | 依赖值域上界，值域大时空间爆炸 | 值域已知且小时的首选 |

## 最优解法

1. 用长度 1001 的差分数组：每个行程令 `diff[from] += num`、`diff[to] -= num`。
2. 从位置 0 到 1000 做前缀和，得到每个位置的瞬时乘客数。
3. 任何位置超过 `capacity` 返回 `false`；否则返回 `true`。
- 关键不变量：前缀和恰好是每个位置的"上车人数减下车人数"累计，即瞬时载客量；`to` 处先减保证下车座位立即释放。
- 最优时间复杂度：`O(n + T)`，`T = 1000`
- 最优空间复杂度：`O(T)`

### 最优解代码

```cpp
class Solution {
public:
    bool carPooling(vector<vector<int>>& trips, int capacity) {
        // 值域 0..1000，用差分数组记录每站上下车的人数变化
        int diff[1001] = {0};
        for (const auto& trip : trips) {
            diff[trip[1]] += trip[0];  // from 处上车
            diff[trip[2]] -= trip[0]; // to 处下车，座位立即释放
        }
        int total = 0;
        for (int pos = 0; pos <= 1000; pos++) {
            total += diff[pos]; // 前缀和即瞬时载客量
            if (total > capacity) return false;
        }
        return true;
    }
};
```
