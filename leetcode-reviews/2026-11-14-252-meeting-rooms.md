- 约束要点：`0 <= intervals.length <= 10^4`，`0 <= start < end <= 10^6`；端点相接不算冲突（`[1,5]` 与 `[5,10]` 可同时参加）；空输入返回 `true`

## 用户思路概述

1. 按左端点（默认字典序）排序区间。
2. 扫描相邻对：若 `intervals[i][0] < intervals[i-1][1]`，即当前会议开始早于上一场结束，存在冲突，返回 `false`。
3. 全部相邻对检查通过返回 `true`。

## 用户解法复杂度

- 时间复杂度：`O(n log n)`（排序主导，扫描为 `O(n)`）
- 空间复杂度：`O(log n)`（排序栈）
- 复杂度来源：一次排序加一趟相邻比较，无额外存储。

## 用户代码注释版

> 只在点评文档中展示加注释版本；不把这些注释写回 `src/*.cpp` 的用户原代码。

```cpp
class Solution {
public:
    bool canAttendMeetings(vector<vector<int>>& intervals) {
        int n = intervals.size();
        sort(intervals.begin(), intervals.end()); // 按左端点排序
        for(int i=1; i<n; i++) {
            // 严格小于：端点相接（后场开始 == 前场结束）不算冲突
            if(intervals[i][0] < intervals[i-1][1]) {
                return false;
            }
        }
        return true;   // n==0 或 1 时循环不执行，自然返回 true
    }
};
```

| 方案 | 优点 | 缺点 | 适用情况 |

| 事件扫描线 | 与 253/1094 同构，迁移性强 | 本题用不上，杀鸡用牛刀 | 需要计数或容量判定时才值得 |

## 最优解法

1. 按左端点排序。
2. 检查每个相邻对：后一个区间的左端点若严格小于前一个的右端点，即冲突。
3. 无冲突返回 `true`。
- 关键不变量：排序后区间按开始时间单调；任何重叠若存在，排序后必有一对相邻区间直接重叠。
- 最优时间复杂度：`O(n log n)`
- 最优空间复杂度：`O(log n)`（排序栈）

### 最优解代码

```cpp
class Solution {
public:
    bool canAttendMeetings(vector<vector<int>>& intervals) {
        // 按左端点排序后，冲突只可能出现在相邻对之间
        sort(intervals.begin(), intervals.end());
        for (int i = 1; i < static_cast<int>(intervals.size()); i++) {
            // 严格小于：端点相接不算冲突
            if (intervals[i][0] < intervals[i - 1][1]) return false;
        }
        return true;
    }
};
```
