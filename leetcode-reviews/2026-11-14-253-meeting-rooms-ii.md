## 用户思路概述

1. 把每个区间拆成两个事件：开始事件 `{begin, +1}` 与结束事件 `{end, -1}`。
2. 对全部 `2n` 个事件按默认字典序排序——同一时刻时 `-1` 小于 `+1`，结束事件天然排在开始事件之前。
3. 扫描事件，维护 `total`（当前进行中的会议数）与 `ans`（历史峰值）；每个事件后 `total += e[1]`，并更新 `ans = max(ans, total)`。
4. 返回峰值 `ans`。

## 用户解法复杂度

- 时间复杂度：`O(n log n)`（事件排序主导，扫描为 `O(n)`）
- 空间复杂度：`O(n)`（事件数组）
- 复杂度来源：`2n` 个事件的排序；扫描只维护两个整型变量。

## 用户代码注释版

> 只在点评文档中展示加注释版本；不把这些注释写回 `src/*.cpp` 的用户原代码。

```cpp
class Solution {
public:
    int minMeetingRooms(vector<vector<int>>& intervals) {
        int n=intervals.size();
        vector<vector<int>> events;
        for(auto interval: intervals) {
            int begin = interval[0], end = interval[1];
            events.push_back({begin, 1});   // 开始事件：占用 +1
            events.push_back({end, -1});    // 结束事件：释放 -1
        }
        // 字典序排序：同一时刻 -1 < +1，结束事件先处理——端点相接可共用房间
        sort(events.begin(), events.end());
        int total = 0;  // 当前进行中的会议数
        int ans = 0;    // 历史峰值即所需房间数
        for(auto e: events) {
            total += e[1];
            ans = max(ans, total);
        }
        return ans;
    }
};
```

## 最优解法

1. 每个区间拆成 `{start, +1}` 与 `{end, -1}` 两个事件，共 `2n` 个。
2. 按时刻升序排序；同一时刻结束事件先于开始事件（半开区间语义）。
3. 扫描累计当前占用数，记录历史峰值；峰值即最少房间数。
- 关键不变量：`total` 是扫描到当前时刻的净占用数；由于同刻先处理释放，任意两个相接会议不会同时计入。
- 最优时间复杂度：`O(n log n)`
- 最优空间复杂度：`O(n)`

### 最优解代码

```cpp
class Solution {
public:
    int minMeetingRooms(vector<vector<int>>& intervals) {
        vector<pair<int, int>> events; // {时刻, 变化量}
        for (const auto& iv : intervals) {
            events.push_back({iv[0], 1});   // 占用
            events.push_back({iv[1], -1});  // 释放
        }
        // pair 字典序：同一时刻 -1 在 +1 前，先释放后占用，端点相接可共用
        sort(events.begin(), events.end());
        int total = 0, ans = 0;
        for (const auto& [time, delta] : events) {
            total += delta;
            ans = max(ans, total); // 峰值即所需房间数
        }
        return ans;
    }
};
```
