- 约束要点：`1 <= prices.length <= 3*10^4`，`0 <= prices[i] <= 10^4`；可任意多次交易但持仓上限一股，同一天可完成买卖

## 用户思路概述

1. 定义 `dp[i][0]` 为第 `i` 天结束时不持有的最大利润，`dp[i][1]` 为持有时的最大利润。
2. 初始化 `dp[0][0] = 0`、`dp[0][1] = -prices[0]`。
3. 转移：不持有 = max(昨天就不持有, 昨天持有今天卖)；持有 = max(昨天就持有, 昨天不持有今天买)。
4. 返回 `dp[n-1][0]`（最后一天不持有必然最优）。

## 用户解法复杂度

- 时间复杂度：`O(n)`（单趟转移）
- 空间复杂度：`O(n)`（DP 表）
- 复杂度来源：每个状态只依赖前一天，但用户用了完整二维表存储全部历史。

## 用户代码注释版

> 只在点评文档中展示加注释版本；不把这些注释写回 `src/*.cpp` 的用户原代码。

```cpp
class Solution {
public:
    int maxProfit(vector<int>& prices) {
        int n=prices.size();
        // dp[i][0]: 第 i 天结束时不持有的最大利润
        // dp[i][1]: 第 i 天结束时持有的最大利润
        vector<vector<int>> dp(n, vector<int>(2, n)); // 初值 n 无实际作用，dp[0] 已显式设置
        dp[0][0] = 0;
        dp[0][1] = -prices[0];
        for(int i=1; i<n; i++) {
            dp[i][0] = max(dp[i-1][0], dp[i-1][1] + prices[i]); // 卖出或不动作
            dp[i][1] = max(dp[i-1][1], dp[i-1][0] - prices[i]); // 买入或不动作
        } 
        return dp[n-1][0];   // 最后一天不持有必然最优
    }
};
```

## 关键理解点

| 理解点 | 用户当前表现 | 影响 | 建议 |
| --- | --- | --- | --- |
| 状态设计 | 持有/不持有两状态，无限次交易不记次数 | 正确：无限次交易下无需交易维度，抓住了本题与带交易次数限制版本的本质区别 | 复盘时说出"为什么不需要记录交易次数" |
| 空间浪费 | 完整 `n x 2` 表，但转移只依赖 `i-1` | 主要级问题（不影响正确性）：可滚动到 `O(1)`，DP 表是唯一可优化点 | 意识到"依赖只看前一天"即可压缩 |
| 初始值噪音 | `vector<int>(2, n)` 用 `n` 当初值 | 无害（`dp[0]` 显式设置，每轮 `max` 覆盖），但初值语义不明，复盘时容易困惑 | 初始化用 `0` 或直接不依赖初值 |
| 贪心视角缺席 | 用 DP 通过，未触及贪心 | 本周主题是贪心，本题是"局部贡献拆分"的最佳入门案例 | 对照最优解的贪心版本，理解"所有正差值之和"等价于最优交易序列 |

## 算法优缺点

| 方案 | 优点 | 缺点 | 适用情况 |
| --- | --- | --- | --- |
| 用户解法（二维 DP） | 状态清晰、可扩展（加交易次数/冷冻期只需扩状态）；正确性直观 | `O(n)` 空间冗余；代码量偏大 | 带约束的股票题系列（冷冻期、手续费、限次数）的首选框架 |
| 滚动变量 DP | 同上，但 `O(1)` 空间 | 仍不如贪心简短 | 同上 |
| 推荐最优解（贪心收集正差值） | `O(n)`/`O(1)`，两行核心；直接体现"连续收益拆成局部贡献" | 只适用于无限次交易版本，不可扩展到带约束变体 | 本题及"求所有上升段总涨幅"类问题 |

## 最优解法

1. 逐日累加相邻差值 `prices[i] - prices[i-1]`，只收集正数。
2. 答案即所有正差值之和。
- 关键不变量：任意交易序列的利润都能拆成若干相邻日差值的和；最优解等价于把每段上升区间的涨幅全部收入——因为同一天可先卖后买，任何"错过"的涨幅都可以无损补收。反证：若最优解漏掉某正差值，把它单独作为一次一买一卖加入只会增加利润。
- 最优时间复杂度：`O(n)`
- 最优空间复杂度：`O(1)`

### 最优解代码

```cpp
class Solution {
public:
    int maxProfit(vector<int>& prices) {
        int profit = 0;
        for (int i = 1; i < static_cast<int>(prices.size()); i++) {
            // 只收集正差值：每个上升段的涨幅都可通过当天卖当天买无损收入
            profit += max(0, prices[i] - prices[i - 1]);
        }
        return profit;
    }
};
```
