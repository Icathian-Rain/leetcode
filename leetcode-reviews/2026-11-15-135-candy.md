- 约束要点：`1 <= n <= 5*10^4`，`0 <= ratings[i] <= 5*10^4`；每个孩子至少 1 颗；相邻中评分更高者糖果严格更多；评分相同无强制要求

## 用户思路概述

1. 从左到右一遍：`left[i]` 表示只考虑左邻居约束时孩子 `i` 的最少糖果数——评分比左邻高则 `left[i-1]+1`，否则为 1。
2. 从右到左一遍：用滚动变量 `right` 计算只考虑右邻居约束的最少糖果数——评分比右邻高则在上一次基础上 +1，否则重置为 1。
3. 每个孩子取两个方向约束的较大值 `max(left[i], right)` 同时满足两侧要求，累加即答案。

## 用户解法复杂度

- 时间复杂度：`O(n)`（两趟扫描）
- 空间复杂度：`O(n)`（`left` 数组）
- 复杂度来源：左向约束需要随机访问历史（或也滚动），右向用滚动变量已省一份数组。

## 用户代码注释版

> 只在点评文档中展示加注释版本；不把这些注释写回 `src/*.cpp` 的用户原代码。

```cpp
class Solution {
public:
    int candy(vector<int>& ratings) {
        int n=ratings.size();
        vector<int> left(n);
        for(int i=0; i<n; i++) {
            if(i>0 && ratings[i] > ratings[i-1]) {
                left[i] = left[i-1]+1;   // 比左邻高：左向约束下的最少糖果
            } else {
                left[i] = 1;             // 不比左邻高：下限 1 颗
            }
        }
        int right = 0, ans = 0;
        for(int i=n-1; i>=0; i--) {
            if(i<n-1 && ratings[i] > ratings[i+1]) {
                right = right + 1;      // 比右邻高：右向约束递增
            } else {
                right = 1;              // 不比右邻高：重置为下限
            }
            ans += max(left[i], right); // 取两方向较大值同时满足两侧约束
        }
        return ans;
    }
};
```

## 关键理解点

| 理解点 | 用户当前表现 | 影响 | 建议 |
| --- | --- | --- | --- |
| 双向约束的分解 | 左向、右向各扫一遍再取 max | 这是本题正确性的核心：孩子 `i` 的糖果数 = max(左向链长, 右向链长)，两个单调链在该点交汇 | 口头证明"取 max 后两侧相邻约束同时满足且不会超发" |
| 右向用滚动变量 | `right` 只依赖上一轮（即右侧邻居） | 省掉一份数组，说明对状态依赖看得很清 | 已达标；左向同样可滚动，但保留 `left` 数组更易复盘，取舍合理 |
| 相等评分的处理 | 相等时重置为 1 | 正确：评分相同无强制要求，重置最小化总数 | 想清"如果题目改成相等也要更多糖"会怎样（本题会变成另一道题） |
| 最少性论证 | 实现正确 | 每个位置的值已是双向约束下的必要下限，总和自然最少 | 复盘时说出"max 是下限而非估计"这句 |

## 算法优缺点

| 方案 | 优点 | 缺点 | 适用情况 |
| --- | --- | --- | --- |
| 用户解法（双向扫描 + max 合并） | `O(n)`/`O(n)`，本题标准最优解；结构清晰易复盘 | 需要一份数组（可接受） | 相邻双向约束类问题的通用模板 |
| 单遍上坡/下坡计数 | `O(1)` 额外空间 | 技巧化：需同时维护当前上坡长度、下坡长度和下坡起点，边界极易出错 | 追求空间极致时；本题规模下不值得冒出错风险 |

## 最优解法

1. 左向一遍：比左邻评分高则在上一个基础上 +1，否则 1。
2. 右向一遍：比右邻评分高则在上一个基础上 +1，否则 1。
3. 每个位置取两趟结果的较大值并求和。
- 关键不变量：`left[i]` 是仅看左链时的必要糖果数，`right[i]` 是仅看右链时的必要糖果数；`max` 同时满足两侧且是逐位置下限，故总和最少。
- 最优时间复杂度：`O(n)`
- 最优空间复杂度：`O(n)`（`O(1)` 变体存在但技巧化，本题不推荐）

### 最优解代码

```cpp
class Solution {
public:
    int candy(vector<int>& ratings) {
        int n = static_cast<int>(ratings.size());
        vector<int> left(n, 1);
        // 左向约束：比左邻评分高则比左邻多一颗
        for (int i = 1; i < n; i++) {
            if (ratings[i] > ratings[i - 1]) left[i] = left[i - 1] + 1;
        }
        int ans = 0, right = 0;
        // 右向约束滚动计算，逐位取 max 合并双向要求
        for (int i = n - 1; i >= 0; i--) {
            if (i < n - 1 && ratings[i] > ratings[i + 1]) right++;
            else right = 1;
            ans += max(left[i], right); // max 是双向约束下的必要下限
        }
        return ans;
    }
};
```
