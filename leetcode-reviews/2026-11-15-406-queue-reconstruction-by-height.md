- 约束要点：`1 <= people.length <= 2000`，`0 <= h <= 10^6`，`0 <= k < people.length`；`people[i] = [hi, ki]` 表示前面恰好有 `ki` 个身高 `>= hi` 的人；题目保证输入必能重建合法队列

## 用户思路概述

1. 排序：身高升序；同身高时 `k` 降序——让同高但 `k` 更大的人先放置。
2. 维护结果数组 `ans`，空位表示尚未放置。每个人放入"从左到右第 `k+1` 个空位"：`spaces = k + 1`，从头扫描跳过已占位，数到第 `spaces` 个空位时放入。
3. 全部放置完成后 `ans` 即重建队列。

## 用户解法复杂度

- 时间复杂度：`O(n^2)`（排序 `O(n log n)` + 每人一趟空位扫描 `O(n)`）
- 空间复杂度：`O(n)`（结果数组，不计返回本身则 `O(1)`）
- 复杂度来源：`n <= 2000`，`O(n^2)` 约 4*10^6 次操作，通过无压力；理论最优可用树状数组优化到 `O(n log n)`，本题规模下无必要。

## 用户代码注释版

> 只在点评文档中展示加注释版本；不把这些注释写回 `src/*.cpp` 的用户原代码。

```cpp
class Solution {
public:
    vector<vector<int>> reconstructQueue(vector<vector<int>>& people) {
        int n=people.size();
        // 身高升序、同高 k 降序：同高的人中 k 大的先占位
        sort(people.begin(), people.end(), [](const vector<int>& u, const vector<int>& v) {
            return u[0] < v[0] || (u[0] == v[0] && u[1] > v[1]);
        });
        vector<vector<int>> ans(n);
        for(auto person: people) {
            int spaces = person[1] + 1;   // 放入从左到右第 k+1 个空位
            for(int i=0; i<n; i++) {
                if(ans[i].empty()) {     // 空位 = 该位置尚未放人
                    spaces--;
                    if(!spaces) {
                        ans[i] = person;
                        break;
                    }
                }
            }
        }
        return ans;
    }
};
```

## 关键理解点

| 理解点 | 用户当前表现 | 影响 | 建议 |
| --- | --- | --- | --- |
| 排序方向与放置次序的配合 | 矮的先放、同高 k 大的先放 | 正确且是本解法正确性的全部：当前人放入第 `k+1` 个空位后，它左侧的空位将来只放更高的人（恰好 `k` 个，满足条件），左侧已占位全是更矮的人（不数入 `k`） | 口头回答"为什么同高必须 k 降序先放"——若 k 小的先放，k 大的同高者数空位时无法把它算进前置人数 |
| 空位语义 | "第 k+1 个空位"而非"第 k+1 个位置" | 正确：空位留给更高的人，已占位是更矮的人；这个区分是本解法最容易搞混的点 | 复盘时用 `[[5,0],[5,1]]` 走一遍，确认同高两人互不挤占 |
| 正确性论证 | 实现正确 | 论证链较长（排序方向、放置次序、空位计数三处耦合），是本题的真正难点 | 分三句写：谁先放、放哪、为什么后放的人不破坏先放的人 |
| 复杂度意识 | `O(n^2)` 通过 | `n <= 2000` 下足够；树状数组优化到 `O(n log n)` 属于理论兴趣 | 知道优化存在即可，本题不必追求 |

## 算法优缺点

| 方案 | 优点 | 缺点 | 适用情况 |
| --- | --- | --- | --- |
| 用户解法（矮先放 + 数空位） | 正确性可以从"空位留给高个"直观理解；不依赖容器插入操作 | 手工数空位的双循环较长；`O(n^2)` | 喜欢显式模拟放置过程时 |
| 推荐最优解（高先放 + 按下标插入） | 排序后每人的 `k` 就是最终插入位置，逻辑一句话说清；同为 `O(n^2)` 但代码减半 | "高先放为什么 k 即位置"需要一句论证 | 面试标准写法，论证更短 |
| 树状数组优化 | `O(n log n)` 理论最优 | 代码复杂度远超题目需要 | 仅大规模数据或竞赛场景 |

## 最优解法

1. 排序：身高降序；同身高时 `k` 升序。
2. 依次把每个人插入结果列表下标 `k` 处。
- 关键不变量：先放的人全部 `>=` 后放的人，因此当前人插入时，已在列表中的人都算"身高 >= 它"，它要求的 `k` 个前置人数恰好等于"下标 k 处插入后，它前面恰好有 k 个人"；同高 k 升序保证同高内部先放 k 小的，后放的 k 大者插入时不会破坏先放者（先放者算入其前置人数，位置由插入次序保证）。
- 最优时间复杂度：`O(n^2)`（列表插入；`n <= 2000` 足够）
- 最优空间复杂度：`O(n)`（结果列表）

### 最优解代码

```cpp
class Solution {
public:
    vector<vector<int>> reconstructQueue(vector<vector<int>>& people) {
        // 身高降序、同高 k 升序：先放的人对后放的人全部算"更高的前置者"
        sort(people.begin(), people.end(), [](const vector<int>& a, const vector<int>& b) {
            if (a[0] != b[0]) return a[0] > b[0];
            return a[1] < b[1];
        });
        vector<vector<int>> ans;
        for (const auto& person : people) {
            // 已放的人都 >= 当前身高，k 即最终下标，直接插入
            ans.insert(ans.begin() + person[1], person);
        }
        return ans;
    }
};
```
