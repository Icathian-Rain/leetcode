# 题解点评 - 1020. Number of Enclaves（飞地的数量）

## 基本信息

- 日期：2026-11-17

- 难度：中等
- 本次结果：逻辑推演正确（用户未明确确认测试状态，暂记待验证）
- 对应源码：[src/1020.number-of-enclaves.cpp](../src/1020.number-of-enclaves.cpp)
- 资料来源：[LeetCode 中国版官方题目页](https://leetcode.cn/problems/number-of-enclaves/)，2026-11-17 查询
- 约束要点：`1 <= m, n <= 500`；飞地 = 无法移动出网格边界的陆地格；边界上的陆地本身即可离开，不计入

## 用户思路概述

1. 第一阶段：只扫描网格四条边上的陆地格，从每个边界陆格出发 BFS 沉岛——把所有"能离开"的陆地全部清 0。
2. 第二阶段：再次全网格扫描，剩余仍为 1 的格子就是飞地，计数返回。

## 用户解法复杂度

- 时间复杂度：`O(m × n)`（边界扫描 + 两轮全扫，每格至多入队一次）
- 空间复杂度：`O(m × n)`（队列最坏）
- 复杂度来源：边界 BFS 沉岛保证每格至多处理一次；两轮线性扫描。

## 用户代码注释版

> 只在点评文档中展示加注释版本；不把这些注释写回 `src/*.cpp` 的用户原代码。

```cpp
using pii = pair<int, int>;
const int DIRECT[][2] = {{1,0}, {-1,0}, {0, 1}, {0, -1}};
class Solution {
public:
    int numEnclaves(vector<vector<int>>& grid) {
        int m=grid.size(), n=grid[0].size();
        int ans=0;
        // 第一阶段：从边界陆格出发沉岛，清掉所有"能离开"的陆地
        for(int x=0; x<m; x++) {
            for(int y=0; y<n; y++) {
                // 只在四条边上且是陆地时启动
                if((x == 0 || x == m-1 || y == 0 || y == n-1) && (grid[x][y] == 1)) {
                    queue<pii> q;
                    q.push({x, y});
                    grid[x][y] = 0;   // 入队即沉岛
                    while(!q.empty()) {
                        auto [cx, cy] = q.front(); q.pop();
                        for(int i=0; i<4; i++) {
                            int nx=cx+DIRECT[i][0], ny=cy+DIRECT[i][1];
                            if(nx>=0 && nx<m && ny>=0 && ny<n && grid[nx][ny]==1) {
                                q.push({nx, ny});
                                grid[nx][ny]=0;  // 入队同时沉岛，防止重复入队
                            }
                        }
                    }
                }
            }
        }
        // 第二阶段：剩余的 1 全是飞地
        for(int x=0; x<m; x++) {
            for(int y=0; y<n; y++) {
                if(grid[x][y] == 1) {
                    ans++;
                }
            }
        }
        return ans;
    }
};
```

## 关键理解点

| 理解点 | 用户当前表现 | 影响 | 建议 |
| --- | --- | --- | --- |
| 反向思维 | 从边界出发清除可达陆地，而不是对每个内部陆格判断能否到达边界 | 这是本题的核心决策，方向选对了：正向判定每格都要一次搜索（`O((mn)^2)` 级），反向一次清除即 `O(mn)` | 口头回答"为什么反向更优"——乘法变加法 |
| 边界扫描的完备性 | 四条边的所有格子都作为候选起点 | 正确：能离开的陆地必然与某个边界陆格连通 | 想清"为什么可以只从边界出发"——连通关系对称 |
| 两阶段分离 | 先全部清除，再统一计数 | 正确：清除阶段不能同时计数（那时分不清是不是飞地） | 已达标 |
| 扫描范围 | 第一阶段仍是全网格双重循环，只是启动条件限边界 | 正确但稍绕：边界格只有 `O(m+n)` 个，先收集边界格再启动可少一轮全扫；当前写法无害 | 知道优化存在即可，两轮全扫不影响复杂度量级 |

## 算法优缺点

| 方案 | 优点 | 缺点 | 适用情况 |
| --- | --- | --- | --- |
| 用户解法（边界 BFS 清除 + 计数） | `O(mn)` 最优级；反向思维的标准形态 | 第一阶段全网格扫描略绕（可先收集边界起点） | "与边界相关的连通判定"通用解 |
| 正向逐格判定 | 思路直白 | 每个内部陆格一次搜索，最坏 `O((mn)^2)` | 反面教材，用于理解反向的必要性 |
| 并查集 | 可扩展到动态查询 | 本题静态统计，杀鸡用牛刀 | 第 12 周主题前奏 |

## 最优解法

1. 收集四条边上的所有陆地格作为起点。
2. 从这些起点 BFS/DFS，把所有与边界连通的陆地沉没。
3. 全网格扫描，剩余陆格数即飞地数。
- 关键不变量：清除后剩余的 1 恰好是"不与任何边界陆格连通"的陆地，即飞地定义的逆否形式。
- 最优时间复杂度：`O(m × n)`
- 最优空间复杂度：`O(m × n)`（队列最坏）

### 最优解代码

```cpp
class Solution {
public:
    int numEnclaves(vector<vector<int>>& grid) {
        int m = static_cast<int>(grid.size());
        int n = static_cast<int>(grid[0].size());
        const int dx[] = {1, -1, 0, 0}, dy[] = {0, 0, 1, -1};
        queue<pair<int, int>> q;
        // 只收集四条边上的陆格作为起点：能离开的陆地必与它们连通
        for (int x = 0; x < m; x++) {
            for (int y = 0; y < n; y++) {
                if ((x == 0 || x == m - 1 || y == 0 || y == n - 1) && grid[x][y] == 1) {
                    grid[x][y] = 0; // 入队即沉岛
                    q.push({x, y});
                }
            }
        }
        while (!q.empty()) {
            auto [cx, cy] = q.front(); q.pop();
            for (int i = 0; i < 4; i++) {
                int nx = cx + dx[i], ny = cy + dy[i];
                if (nx >= 0 && nx < m && ny >= 0 && ny < n && grid[nx][ny] == 1) {
                    grid[nx][ny] = 0; // 入队同时沉岛
                    q.push({nx, ny});
                }
            }
        }
        int ans = 0;
        // 清除后剩余的 1 全是飞地
        for (const auto& row : grid) {
            for (int cell : row) ans += cell;
        }
        return ans;
    }
};
```

## 对比与改进方向

| 对比项 | 用户代码 | 最优解代码 | 改进方向 |
| --- | --- | --- | --- |
| 状态定义 | 逐起点 BFS + 二次扫描 | 边界起点收集 + 单队列 | 先收集边界起点可少一轮全扫，逻辑也更清晰 |
| 更新逻辑 | 入队即沉岛 | 相同 | 已达标 |
| 边界处理 | 四边判断、清除后计数正确 | 相同 | 已达标 |
| 复杂度 | 时间 `O(mn)`、空间 `O(mn)` | 相同 | 已达最优 |

用户解法正确且达最优复杂度，与推荐最优解的差异只在"逐起点启动"还是"先收集再统一启动"的组织方式。
