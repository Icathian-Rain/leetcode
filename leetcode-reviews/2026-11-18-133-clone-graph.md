- 约束要点：节点数 `0..100`，`1 <= val <= 100`；无自环、无重复边；非空时图连通；输入为 `nullptr` 时返回 `nullptr`

## 用户思路概述

1. 空节点直接返回。
2. 建立"旧指针 → 新指针"哈希映射 `mp`，起点入队并立刻为它创建克隆。
3. BFS 出队一个旧节点，遍历其邻居：邻居未见过则入队并立刻创建克隆（发现即克隆，发现即标记）；无论邻居是否已克隆，都把 `mp[邻居]` 接到 `mp[当前]` 的邻居表里。
4. 返回 `mp[起点]`。

## 用户解法复杂度

- 时间复杂度：`O(n + e)`（每个节点克隆一次，每条边两次引导——每端出队时各接一次）
- 空间复杂度：`O(n)`（映射与队列，不计返回的图本身）
- 复杂度来源：克隆即标记保证每个旧节点至多入队一次；边的接入在两端的出队时各发生一次，总量 `2e`。

## 用户代码注释版

> 只在点评文档中展示加注释版本；不把这些注释写回 `src/*.cpp` 的用户原代码。

```cpp
class Solution {
public:
    Node* cloneGraph(Node* node) {
        if(node == nullptr) return node;
        unordered_map<Node*, Node*> mp;   // 旧指针 -> 新指针，兼作"已发现"标记

        queue<Node*> q;
        q.push(node);
        mp[node] = new Node(node->val);    // 入队即克隆：映射存在即已发现
        while(!q.empty()) {
            Node* p = q.front(); q.pop();
            int n=p->neighbors.size();
            for(int i=0; i<n; i++) {
                if(mp.find(p->neighbors[i]) == mp.end()) {
                    // 邻居未见过：发现即克隆并标记
                    q.push(p->neighbors[i]);
                    mp[p->neighbors[i]] = new Node(p->neighbors[i]->val);
                }
                mp[p]->neighbors.push_back(mp[p->neighbors[i]]);
                // 邻居此刻必已有克隆（刚建或早已建），边可以安全接入
            }
        }

        return mp[node];
    }
};
```

## 关键理解点

| 理解点 | 用户当前表现 | 影响 | 建议 |
| --- | --- | --- | --- |
| 发现即克隆 | 邻居首次被见到时立刻建克隆，映射存在即标记 | 正确且与第 1-2 天"入队即沉岛/改色即标记"一脉相承：这里的"标记"就是"已有克隆" | 把三天的标记写法归成一句话：无独立 visited 时，伴随结构本身就是标记 |
| 边的接入时机 | 无论邻居新旧，出队时统一 `mp[p]->neighbors.push_back(...)` | 正确：邻居克隆要么刚建、要么早已存在，查找不会落空；这一行同时覆盖新邻居和已见邻居，避免了两套分支 | 口头回答"为什么 push_back 不需要分新旧两种情况" |
| 环的处理 | 映射防止环上重复克隆/入队 | 正确：本题官方样例 1 就是二环（1-2-3-4），天然考验环意识 | 已达标 |
| 空节点判断 | 开头 `nullptr` 短路 | 正确覆盖官方样例 3 | 已达标 |

## 算法优缺点

| 方案 | 优点 | 缺点 | 适用情况 |
| --- | --- | --- | --- |
| 用户解法（BFS + 克隆映射） | `O(n+e)`/`O(n)`；无递归栈深问题；克隆即标记与本周标记体系一致 | 无实质缺点 | 图复制类标准写法 |
| 递归 DFS 版 | 代码更短，"克隆后递归邻居"语义直观 | 递归深度受图形态影响 | 备选等价方案，见下方最优解 |

## 最优解法

1. 哈希映射"旧指针 → 新克隆"。
2. DFS：进入函数先建（或取）当前节点的克隆；对每个邻居递归克隆后接入克隆的邻居表。
- 关键不变量：映射中的每个条目 = "该旧节点已发现"；克隆的邻居表填充发生在旧节点的扩展期，天然覆盖全部边两次（每端一次）。
- 最优时间复杂度：`O(n + e)`
- 最优空间复杂度：`O(n)`（映射 + 栈）

### 最优解代码

```cpp
class Solution {
    Node* dfsClone(Node* node, unordered_map<Node*, Node*>& mp) {
        // 已有克隆直接返回：映射存在即"已发现"，天然处理环
        if (mp.count(node)) return mp[node];
        mp[node] = new Node(node->val);   // 先建克隆再递归，防止环上无限递归
        for (Node* nb : node->neighbors) {
            mp[node]->neighbors.push_back(dfsClone(nb, mp)); // 邻居的克隆递归生成
        }
        return mp[node];
    }
public:
    Node* cloneGraph(Node* node) {
        if (node == nullptr) return nullptr;
        unordered_map<Node*, Node*> mp;
        return dfsClone(node, mp);
    }
};
```
