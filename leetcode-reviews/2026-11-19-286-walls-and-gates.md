## 用户思路概述

1. 初始扫描：所有门（值 0）入队（多源起点）。
2. BFS 扩散：出队一格，邻居在界内且值为 `INF`（未填充）时填 `rooms[邻居] = rooms[当前] + 1` 并入队——填值即标记，`INF` 兼作"未访问"。
3. 墙（-1）和已填房间天然不会被扩展条件命中，队列空即完成，原地写回。

## 用户解法复杂度

- 时间复杂度：`O(m × n)`（每格至多入队一次）
- 空间复杂度：`O(m × n)`（队列最坏；不需要额外矩阵，原地修改）
- 复杂度来源：`INF` 兼作 visited，初始已确定的 0/-1 不参与扩展。

## 用户代码注释版

> 只在点评文档中展示加注释版本；不把这些注释写回 `src/*.cpp` 的用户原代码。

```cpp
using pii = pair<int, int>;
const int INF=2147483647;
const int DIRECT[][2]={{1,0}, {-1, 0}, {0, 1}, {0, -1}};
class Solution {
public:
    void wallsAndGates(vector<vector<int>>& rooms) {
        int m=rooms.size(), n=rooms[0].size();
        queue<pii> q;
        for(int i=0; i<m; i++) {
            for(int j=0; j<n; j++) {
                if(rooms[i][j] == 0) {
                    q.push({i, j});   // 全部门同时入队：多源起点
                }
            }
        }

        while(!q.empty()) {
            auto [i, j] = q.front(); q.pop();
            for(int d=0; d<4; d++) {
                int ni=i+DIRECT[d][0], nj=j+DIRECT[d][1];
                if(ni>=0 && ni<m && nj>=0 && nj<n && rooms[ni][nj]==INF) {
                    rooms[ni][nj]=rooms[i][j]+1;  // 填值即标记；INF 兼作未访问
                    q.push({ni, nj});
                }
            }
        }
        return ;
    }
};
```

## 最优解法

1. 全部门（0）作为多源起点一次入队。
2. BFS：邻居为 `INF` 时填 `当前值 + 1` 并入队——首次到达即最近门距离。
3. 队列空返回，不可达房间保持 INF。
- 关键不变量：被 `d` 步首达的房间恰有最小距离 `d`；`INF` 双重身份（答案初值 + 未访问标记）使扩展条件天然完备。
- 最优时间复杂度：`O(m × n)`
- 最优空间复杂度：`O(m × n)`（队列最坏；不计原地目标矩阵）

### 最优解代码

```cpp
class Solution {
public:
    void wallsAndGates(vector<vector<int>>& rooms) {
        int m = static_cast<int>(rooms.size());
        int n = static_cast<int>(rooms[0].size());
        // INF 兼作未访问标记：填充后不再等于 INF，天然防重复入队
        const int INF = 2147483647;
        const int dx[] = {1, -1, 0, 0}, dy[] = {0, 0, 1, -1};
        queue<pair<int, int>> q;
        for (int i = 0; i < m; i++) {
            for (int j = 0; j < n; j++) {
                if (rooms[i][j] == 0) q.push({i, j}); // 多源：全部门同时入队
            }
        }
        while (!q.empty()) {
            auto [x, y] = q.front(); q.pop();
            for (int d = 0; d < 4; d++) {
                int nx = x + dx[d], ny = y + dy[d];
                if (nx >= 0 && nx < m && ny >= 0 && ny < n && rooms[nx][ny] == INF) {
                    rooms[nx][ny] = rooms[x][y] + 1; // 首次到达即最近距离
                    q.push({nx, ny});
                }
            }
        }
    }
};
```
