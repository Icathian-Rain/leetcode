- 难度：中等
- 本次结果：通过（用户确认已通过测试）
- 对应源码：[src/542.01-matrix.cpp](../src/542.01-matrix.cpp)
- 资料来源：[LeetCode 中国版官方题目页](https://leetcode.cn/problems/01-matrix/)，2026-11-19 查询
- 约束要点：`1 <= m, n <= 10^4` 且 `1 <= m*n <= 10^4`；`mat` 只含 0/1 且至少有一个 0；距离为四方向步数（即最小曼哈顿距离）

## 用户思路概述

1. 结果矩阵 `ans` 初始化为 -1（双重含义：未访问标记 + 待填充距离）。
2. 初始扫描：所有 0 格作为多源起点入队，`ans` 置 0。
3. BFS 扩散：出队一格，邻居在界内且 `ans == -1`（未访问）时填 `ans[邻居] = ans[当前] + 1` 并入队——填值即标记，首次到达的距离必为最近 0 的距离。
4. 返回 `ans`。

## 用户解法复杂度

- 时间复杂度：`O(m × n)`（每格至多入队一次）
- 空间复杂度：`O(m × n)`（结果矩阵 + 队列）
- 复杂度来源：`-1` 兼作 visited，邻居扩展只发生在未访问格上；结果矩阵既是输出也是状态的承担者。

## 用户代码注释版

> 只在点评文档中展示加注释版本；不把这些注释写回 `src/*.cpp` 的用户原代码。

```cpp
using pii = pair<int, int>;
const int DIRECT[][2]={{1,0}, {-1, 0}, {0, 1}, {0, -1}};
class Solution {
public:
    vector<vector<int>> updateMatrix(vector<vector<int>>& mat) {
        int m=mat.size(), n=mat[0].size();
        vector<vector<int>> ans(m, vector<int>(n, -1)); // -1 = 未访问
        queue<pii> q;
        for(int i=0; i<m; i++) {
            for(int j=0; j<n; j++) {
                if(mat[i][j] == 0) {
                    ans[i][j] = 0;      // 源头距离 0
                    q.push({i, j});     // 全部 0 同时入队：多源起点
                }
            }
        }

        while(!q.empty()) {
            auto [i, j] = q.front(); q.pop();
            for(int d=0; d<4; d++) {
                int ni=i+DIRECT[d][0], nj=j+DIRECT[d][1];
                if(ni>=0 && ni<m && nj>=0 && nj<n && ans[ni][nj]==-1) {
                    ans[ni][nj]=ans[i][j]+1;   // 填值即标记；首次到达即最近 0 的距离
                    q.push({ni, nj});
                }
            }
        }
        return ans;
    }
};
```

## 关键理解点

| 理解点 | 用户当前表现 | 影响 | 建议 |
| --- | --- | --- | --- |
| 方向反转 | 从 0 出发找 1，而不是从每个 1 找最近 0 | 关键决策正确：正向逐 1 搜索是 `O(mn · 源数)` 级，反向多源一次扫完；与 1020 的"反向思维"呼应——但那题反向是为了资格，这题反向是为了距离 | 口头回答"为什么必须从 0 出发"——每个 1 的答案由所有 0 竞争产生，等价于从 0 集体出发的首达层 |
| -1 兼作标记 | 未访问即未填值，填值即已访问 | 正确：本题不能改写输入（1 格改成什么都不是标记），所以用结果矩阵承担状态——与沉岛/改色的"借用可变图"写法形成对照：**当输入不可借用时，写在输出上** | 归纳本周的第四种标记载体：独立 visited / 改图 / 映射 / 输出矩阵 |
| 无层计数 | 不需要分钟数，只写距离 | 正确：距离由 `ans[当前]+1` 隐式携带，比 994 更简洁——队列里不需要时间戳，父格距离+1 即层保证 | 已达标 |

## 算法优缺点

| 方案 | 优点 | 缺点 | 适用情况 |
| --- | --- | --- | --- |
| 用户解法（多源 BFS 距离填充） | `O(mn)` 最优级；-1 兼作标记省一个 visited | 结果矩阵本身已是 `O(mn)`，不可避免 | 距离场类标准写法 |
| 两遍 DP（左上 + 右下） | 同 `O(mn)`，免队列，常数小 | 边界初始化易错（首遍取 `m+n` 作无穷），直觉弱于 BFS | 不允许队列或追求常数时 |
| 逐 1 BFS | —— | 每次 BFS 从单点出发遍历可达区，总量近 `O(mn · 1的个数)` | 反面教材 |

## 最优解法

1. 所有 0 格作为多源起点，距离 0 入队。
2. BFS：首次到达某格时其距离 = 父格距离 + 1，填入结果矩阵（填值即标记）。
3. 队列空返回结果。
- 关键不变量：BFS 层 `k` 的格子恰好距最近 0 为 `k`；`-1` 时距离未定且未访问，两重身份统一。
- 最优时间复杂度：`O(m × n)`
- 最优空间复杂度：`O(m × n)`（结果矩阵即输出）

### 最优解代码

```cpp
class Solution {
public:
    vector<vector<int>> updateMatrix(vector<vector<int>>& mat) {
        int m = static_cast<int>(mat.size());
        int n = static_cast<int>(mat[0].size());
        vector<vector<int>> dist(m, vector<int>(n, -1)); // -1 = 未访问
        queue<pair<int, int>> q;
        const int dx[] = {1, -1, 0, 0}, dy[] = {0, 0, 1, -1};
        for (int i = 0; i < m; i++) {
            for (int j = 0; j < n; j++) {
                if (mat[i][j] == 0) {
                    dist[i][j] = 0; // 多源起点：全部 0 一次入队
                    q.push({i, j});
                }
            }
        }
        while (!q.empty()) {
            auto [x, y] = q.front(); q.pop();
            for (int d = 0; d < 4; d++) {
                int nx = x + dx[d], ny = y + dy[d];
                if (nx >= 0 && nx < m && ny >= 0 && ny < n && dist[nx][ny] == -1) {
                    dist[nx][ny] = dist[x][y] + 1; // 填值即标记，首次到达即最近距离
                    q.push({nx, ny});
                }
            }
        }
        return dist;
    }
};
```
