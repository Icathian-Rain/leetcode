- 约束要点：`1 <= m, n <= 100`；**0 = 陆地，1 = 水域**（与 200 题相反）；封闭岛屿 = 不接触网格边界的陆地区块

## 用户思路概述

1. DFS 返回布尔值："以 `(x, y)` 所在连通块是否完全不触边界"。
2. 终止语义：越界返回 `false`（块碰到了边界）；非 0（水或已访问标记 -1）返回 `true`（不是陆地，不构成"触界"）。
3. 陆地格改 -1（改值即标记）后递归四个邻居，四方向全部 `true` 才判定该块封闭。
4. 外层扫描遇 0 启动 DFS，返回 true 则计数加一；标记 -1 保证每块只判一次。

## 用户解法复杂度

- 时间复杂度：`O(m × n)`（每格至多进入一次 DFS）
- 空间复杂度：`O(m × n)`（递归栈最坏）
- 复杂度来源：改 -1 即标记保证无重入；单趟外层扫描。

## 用户代码注释版

> 只在点评文档中展示加注释版本；不把这些注释写回 `src/*.cpp` 的用户原代码。

```cpp
class Solution {
    bool dfs(vector<vector<int>>& grid, int x, int y) {
        int m=grid.size(), n=grid[0].size();
        if(x < 0 || x >= m || y < 0 || y >= n) {
            return false;      // 块触到网格边界：该块不封闭
        }

        if(grid[x][y] != 0) return true;  // 水(-1 已访问不算)：不构成触界
        grid[x][y] = -1;                   // 改值即标记，块内只访问一次
        bool res1 = dfs(grid, x+1, y);
        bool res2 = dfs(grid, x-1, y);
        bool res3 = dfs(grid, x, y+1);
        bool res4 = dfs(grid, x, y-1);
        return res1 && res2 && res3 && res4;    // 四方向都不触界才是封闭
    }


public:
    int closedIsland(vector<vector<int>>& grid) {
        int m=grid.size(), n=grid[0].size();
        int ans=0;
        for(int x=0; x<m; x++) {
            for(int y=0; y<n; y++) {
                if(grid[x][y] == 0 && dfs(grid, x, y)) {  // 遇到未访问陆地即整块判定
                    ans++;
                }
            }
        }
        return ans;
    }
};
```

## 关键理解点

| 理解点 | 用户当前表现 | 影响 | 建议 |
| --- | --- | --- | --- |
| 返回值语义设计 | DFS 返回"该块是否封闭"，用 `&&` 聚合四方向 | 一次遍历直接给出整块资格，不必像 1020（先清除再数）那样两阶段——风格与前者互为对照，两种都对 | 把 1020 的"两阶段版"与本题的"返回值版"并排总结：它们是同一判定的两种实现组织 |
| 越界返回 false | 触界语义与返回值绑定 | 正确且是本写法的灵魂：**越界（离开网格）在 1020 里是"能逃离"的必要条件，在这里是"不封闭"的必要条件——同一种语义，两副面具** | 复盘时说清：`false` 顺着 `&&` 传播但 DFS 不会提前返回——四方向继续走是为了把整块标完 -1，避免下轮重复计数 |
| `&&` 的求值顺序 | `res1 && res2 && ...` 全部求值后才组合 | 关键细节：这里没有短路（先算完四个递归存入变量再组合），**这是本写法正确且必须的**——若写成"链条短路的 `dfs(...) && dfs(...)`"会在第一个 false 后跳过后续递归，导致块没标完 | 这是本次三题里最值得写笔记的一处；想清楚"为什么提取到变量再 `&&` 是必须的" |
| 0/1 语义反转 | 本题 0 是陆地（与 200 相反） | 条件 `grid[x][y] != 0` 与 200 题 `== '1'` 对照，用户没有被惯性带偏 | 遇到网格题先确认 0/1 或 '0'/'1' 语义再动手——本周收尾时应形成这个检查习惯 |

## 最优解法

1. 外层扫描遇陆地启动 DFS。
2. DFS 以"四方向都不触界"为整块资格判据，途中把陆地标记（-1 或独立矩阵）。
3. 全部聚合 `&&` 后返回，真值即计数。
- 关键不变量：一个连通块的封闭性与从其中任一点出发的判定结果一致——一旦四扩展途中出现越界，整块即不封闭，且块已被完全标记不会重判。
- 最优时间复杂度：`O(m × n)`
- 最优空间复杂度：`O(m × n)`（递归栈）

### 最优解代码

```cpp
class Solution {
    // 返回 (x, y) 所在块是否完全不触边界；块内所有格子本趟全部标记为 -1
    bool dfs(vector<vector<int>>& grid, int x, int y) {
        int m = static_cast<int>(grid.size());
        int n = static_cast<int>(grid[0].size());
        if (x < 0 || x >= m || y < 0 || y >= n) return false; // 触界即不封闭
        if (grid[x][y] != 0) return true;   // 水或已访问：不构成触界
        grid[x][y] = -1;                    // 改值即标记
        // 必须先全部求值再聚合：短路 && 会跳过后续递归导致块标记不完整
        bool d = dfs(grid, x + 1, y);
        bool u = dfs(grid, x - 1, y);
        bool r = dfs(grid, x, y + 1);
        bool l = dfs(grid, x, y - 1);
        return d && u && r && l;
    }
public:
    int closedIsland(vector<vector<int>>& grid) {
        int m = static_cast<int>(grid.size());
        int n = static_cast<int>(grid[0].size());
        int ans = 0;
        for (int x = 0; x < m; x++) {
            for (int y = 0; y < n; y++) {
                if (grid[x][y] == 0 && dfs(grid, x, y)) ans++; // 遇未访问陆地块判定一次
            }
        }
        return ans;
    }
};
```
