- 难度：中等

- 约束要点：`1 <= deadends.length <= 500`；`target` 不在 deadends 中；`"0000"` 在 deadends 中直接返回 -1；一次只拨一位、转一格

## 用户思路概述

1. 死锁串入哈希集合；`dist` 用 `unordered_map<string, int>`——状态空间是 10⁴ 个四字符串，天然以字符串为键。
2. 前置检查：`0000` 死锁返回 -1；`target == "0000"` 返回 0（起点即终点）。
3. BFS：出队当前串，对每一位 `i` 做 `+1` 与 `-1` 两种拨动（`j = -1; j <= 1; j += 2`），字符回绕手工处理（`< '0'` → `'9'`，`> '9'` → `'0'`）。
4. 拨出的新串等于 target 立即返回 `dist[cur] + 1`（扩展中判终点，比出队判少算一层）；非死锁且未访问时记录距离并入队。

## 用户解法复杂度

- 时间复杂度：`O(10⁴ × 8)` 状态 × 邻居数，加上每状态 O(4) 的字符串操作，即 `O(B · D)`（B = 状态界 10⁴，D = 8 邻居）
- 空间复杂度：`O(10⁴ + |deadends|)`（dist 哈希表 + 死锁集合）
- 复杂度来源：状态空间有界（4 位各 10 值），BFS 至多访问每个状态一次；隐式生成邻居，不预建全图。

## 用户代码注释版

> 只在点评文档中展示加注释版本；不把这些注释写回 `src/*.cpp` 的用户原代码。

```cpp
class Solution {
public:
    int openLock(vector<string>& deadends, string target) {
        unordered_set<string> deadset(deadends.begin(), deadends.end());
        unordered_map<string, int> dist;  // 键出现即已访问（dist.count == 0 为未访问）
        queue<string> q;
        if(deadset.count("0000") == 1) return -1;   // 起手即死锁
        if(target == "0000") return 0;               // 起点即终点
        q.push("0000");
        dist["0000"] = 0;
        while(!q.empty()) {
            auto cur=q.front(); q.pop();
            for(int i=0; i<4; i++) {                 // 四个拨轮
                for(int j=-1; j<=1; j+=2) {          // +1 / -1 两种拨动
                    string tmp = cur;
                    tmp[i] += j;
                    if(tmp[i] < '0') tmp[i] = '9';   // 字符回绕
                    if(tmp[i] > '9') tmp[i] = '0';
                    if(tmp == target) return dist[cur]+1;  // 扩展中判终点：早一步返回
                    if(deadset.count(tmp) == 0 && dist.count(tmp) == 0) {
                        dist[tmp] = dist[cur] + 1;   // 入队即标记
                        q.push(tmp);
                    }
                }
            }
        }
        return -1;
    }
};
```

## 关键理解点

| 理解点 | 用户当前表现 | 影响 | 建议 |
| --- | --- | --- | --- |
| 状态即字符串 | `unordered_map<string,int>` 直接以 4 位串为键 | 正确且自然——隐式图中"节点 = 状态描述"，是否入图由生成时判定 | 归纳一句：节点不必是数字编号，能用哈希键表达即可 |
| 回绕处理 | 字符加减后手工修正 `'0'`/`'9'` | 正确；另一种写法是 `(c - '0' + 1) % 10 + '0'` 的算术回绕，两行并一行 | 两种写法都过关；想清算术版如何一次写对 |
| 扩展中判终点 | 生成 tmp 后立即比较 target | 早于入队返回，节省一层搜索；与出队判终点（1091 风格）等价正确 | 知道两种判终点的位置都正确，注意别在标记后又判定导致重复入队即可——本写法无此问题 |
| 前置检查 | `0000` 死锁、target 为 0000 各自短路 | 两个边角都显式处理，正确 | 想清若无 target==0000 检查会怎样——BFS 会全图搜完返回 -1，所以该检查是正确性必需 |
| deadends 只作拦截 | 死锁串仅用于生成时过滤 | 正确：死锁不是节点，是禁入状态，不必预占 dist | 已达标 |

## 算法优缺点

| 方案 | 优点 | 缺点 | 适用情况 |
| --- | --- | --- | --- |
| 用户解法（隐式图 BFS） | `O(10⁴·8)` 量级最优；不预建全图；字符串状态直白 | 无实质缺点 | 隐式图最短路的标准写法 |
| 状态编码为 int | `(dist 数组 int)` 比 map 常数小 | 编码/解码两个方向都要写对，易错 | 追求常数时可选 |
| 双向 BFS | 搜索空间从单侧 10⁴ 降到两端相遇的乘积开方级 | 实现复杂度上升显著 | 状态空间更大时才值得（本题不必） |

## 最优解法

1. 死锁集合 + dist 哈希表（或位数组）；起手死锁 / 起点即终点两检查。
2. BFS 隐式生成 8 邻居：四位 ±1，字符回绕。
3. 扩展中判定目标，返回 `dist[cur] + 1`；非死锁未访问入队并标记。
- 关键不变量：从任一状态拨一位到达的状态恰 8 个；BFS 层 `k` 的状态最小拨动数为 `k`。
- 最优时间复杂度：`O(B × 8)`，`B = 10⁴`
- 最优空间复杂度：`O(B + |deadends|)`

### 最优解代码

```cpp
class Solution {
public:
    int openLock(vector<string>& deadends, string target) {
        unordered_set<string> dead(deadends.begin(), deadends.end());
        if (dead.count("0000")) return -1; // 起手即锁死
        if (target == "0000") return 0;     // 起点即答案
        unordered_map<string, int> dist;    // 出现即已访问
        queue<string> q;
        dist["0000"] = 0;
        q.push("0000");
        while (!q.empty()) {
            string cur = q.front(); q.pop();
            for (int i = 0; i < 4; i++) {          // 四个拨轮位
                for (int delta : {-1, 1}) {       // 两种拨动
                    string next = cur;
                    // 算术回绕：'0'-'9' 环形加减
                    next[i] = static_cast<char>('0' + (next[i] - '0' + delta + 10) % 10);
                    if (next == target) return dist[cur] + 1; // 扩展中判终点
                    if (!dead.count(next) && !dist.count(next)) {
                        dist[next] = dist[cur] + 1; // 入队即标记
                        q.push(next);
                    }
                }
            }
        }
        return -1;
    }
};
```
