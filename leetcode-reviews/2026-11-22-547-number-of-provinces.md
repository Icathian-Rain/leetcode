- 难度：中等

- 资料来源：[LeetCode 中国版官方题目页](https://leetcode.cn/problems/number-of-provinces/)，2026-11-22 查询
- 约束要点：`1 <= n <= 200`；矩阵对称、对角线为 1；`isConnected[i][j]` ∈ {0, 1}

## 用户思路概述

1. 输入是邻接**矩阵**，先转成邻接**表** `graph`（O(n²) 遍历，这一步无法省——矩阵本身就有 n² 个格子要读，但对角线自连在转表后变成自环邻居，需注意）。
2. `vis` 用 **-1 兼作未访问**，已访问存分量编号 `ans`——数组内容本身就是"省份编号表"，一物两用。
3. 外层循环枚举城市：未访问则 `ans++`，BFS 把整个连通分量标记为 `vis[v] = ans`。
4. 返回 `ans` 即分量数。

## 用户解法复杂度

- 时间复杂度：`O(n²)`（建表 n² + BFS 每点每边一次）
- 空间复杂度：`O(n²)`（邻接表最坏；`vis` 仅 O(n)）
- 复杂度来源：读入矩阵已经 O(n²)，这是本题的下界；额外的建表加倍常数但不改变量级。

## 用户代码注释版

> 只在点评文档中展示加注释版本；不把这些注释写回 `src/*.cpp` 的用户原代码。

```cpp
class Solution {
public:
    int findCircleNum(vector<vector<int>>& isConnected) {
        int n=isConnected.size();
        vector<vector<int>> graph(n);
        for(int i=0; i<n; i++) {
            for(int j=0; j<n; j++) {
                if(isConnected[i][j]==1) {
                    graph[i].push_back(j);   // 矩阵转邻接表；对角线 1 会引入自环 u->u
                }
            }
        }
        vector<int> vis(n, -1);              // -1 = 未访问；非 -1 = 所属分量编号
        int ans=0;
        for(int i=0; i<n; i++) {             // 外层枚举：每个连通分量恰好触发一次 ans++
            if(vis[i] != -1) continue;
            ans++;
            queue<int> q;
            q.push(i);
            vis[i]=ans;
            while(!q.empty()) {
                auto u=q.front(); q.pop();
                for(auto v:graph[u]) {
                    if(vis[v] == -1) {
                        q.push(v);
                        vis[v]=ans;         // 入队即标记：填的是当前分量编号
                    }
                }
            }
        }
        return ans;
    }
};
```

## 关键理解点

| 理解点 | 用户当前表现 | 影响 | 建议 |
| --- | --- | --- | --- |
| 外层循环计数 | 未访问才 `ans++`，BFS 标记整个分量 | "从哪里开始搜 = 所有未访问节点"的标准实现——与 785 外层结构同构 | 复盘时把 785/547 的外层循环并排对照，确认两题只是"分量内做的动作"不同 |
| vis 存分量编号 | `vis[i] = ans` 而非布尔 | 顺带得到"每个城市属于哪个省"的信息；一步到位不是多余设计 | 意识到这是可视化的素材；若只要数量，布尔也够 |
| 入队即标记 | push 前先填 `vis[v]` | 正确；避免重复入队 | 与 785 染色同时点对齐，本周标记载体谱系的又一次 |
| 建表必要性 | 先转邻接表再 BFS | 正确但额外消耗 O(n²) 空间与一趟遍历；矩阵可以直接边遍历边扩展 | 对照最优解：BFS 扩展时直接扫 `isConnected[u]` 一行，省建表 |
| 自环输入 | 对角线 1 进入 `graph[u]` 成为 `u->u` 自环 | 无害：`vis[u] != -1` 时被跳过，不会死循环 | 知道自己这步"碰巧正确"——若矩阵把自环设为有意义的操作就会出错 |

## 算法优缺点

| 方案 | 优点 | 缺点 | 适用情况 |
| --- | --- | --- | --- |
| 用户解法（先建表 + BFS） | 结构清晰，邻接表形式与本周其余题统一 | 多一趟 O(n²) 建表与 O(n²) 空间 | 习惯邻接表工作流时 |
| 直接 BFS 扫矩阵 | 免建表；邻接关系随取随用 | 每次 BFS 扫整行含 0 的格子行宽固定 | 矩阵输入的更简写法（本题空间更优） |
| DFS 才分量计数 | 代码最短 | 递归深度 n=200 无风险但非必要 | 与 BFS 等价 |
| 并查集 | 一遍扫上三角合并，免队列 | 需要路径压缩等结构 | 第 12 周主线重写本题 |

## 最优解法

1. `vis` 布尔数组，`ans` 计数。
2. 外层枚举城市，未访问则 `ans++` 并 BFS：出队 `u` 后**直接扫 `isConnected[u]` 一行**取邻居。
3. 返回 `ans`。
- 关键不变量：外层每 `ans++` 恰好发现一个新连通分量；BFS 保证分量内全员标一次。
- 最优时间复杂度：`O(n²)`（矩阵输入的固有下界）
- 最优空间复杂度：`O(n)`（免建邻接表）

### 最优解代码

```cpp
class Solution {
public:
    int findCircleNum(vector<vector<int>>& isConnected) {
        int n = static_cast<int>(isConnected.size());
        vector<char> vis(n, 0); // 0 = 未访问；char 省空间意即可
        int ans = 0;
        for (int i = 0; i < n; i++) { // 每发现一个未访问节点 = 新分量
            if (vis[i]) continue;
            ans++;
            queue<int> q;
            vis[i] = 1;
            q.push(i);
            while (!q.empty()) {
                int u = q.front(); q.pop();
                for (int v = 0; v < n; v++) {
                    // 直接扫矩阵一行取邻居，免建邻接表
                    if (isConnected[u][v] && !vis[v]) {
                        vis[v] = 1; // 入队即标记
                        q.push(v);
                    }
                }
            }
        }
        return ans;
    }
};
```
