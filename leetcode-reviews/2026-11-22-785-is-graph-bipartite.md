- 难度：中等

- 资料来源：[LeetCode 中国版官方题目页](https://leetcode.cn/problems/is-graph-bipartite/)，2026-11-22 查询
- 约束要点：`1 <= n <= 100`；`graph[u]` 为邻接数组，无自环、无平行边、满足对称性；**图可能不连通**

## 用户思路概述

1. `color` 数组 0/-1/1 三态：0 兼作"未染色的已访问标记"。
2. 外层循环枚举每个节点作为 BFS 起点——不连通图每个连通分量独立判定。
3. BFS 染色：起点染色 1；邻居未染色则染相反色 `-color[u]` 入队；已染色且与当前同色立即返回 false。
4. 全部分量染完无冲突返回 true。

## 用户解法复杂度

- 时间复杂度：`O(n + e)`（每点每边至多处理一次）
- 空间复杂度：`O(n)`（color 数组 + 队列）
- 复杂度来源：每条边从两个端点各检查一次（对称表遍历天然如此），整体仍是线性遍历。

## 用户代码注释版

> 只在点评文档中展示加注释版本；不把这些注释写回 `src/*.cpp` 的用户原代码。

```cpp
class Solution {
public:
    bool isBipartite(vector<vector<int>>& graph) {
        int n=graph.size();
        vector<int> color(n, 0);   // 0 = 未染色（兼未访问），1/-1 为两色
        for(int i=0; i<n; i++) {   // 外层循环：覆盖所有连通分量
            if(color[i] != 0) continue;
            queue<int> q;
            color[i] = 1;           // 起点 Arbitrary 染色：起点在哪个集合不影响判定
            q.push(i);

            while(!q.empty()) {
                auto u=q.front(); q.pop();
                for(auto v: graph[u]) {
                    if(color[v] == 0) {
                        color[v] = -color[u];   // 邻居染反色，入队即染色
                        q.push(v);
                    } else if(color[v] == color[u]) {
                        return false;          // 已染同色：奇冲突即非二分图
                    }
                }
            }
        }
        return true;
    }
};
```

## 关键理解点

| 理解点 | 用户当前表现 | 影响 | 建议 |
| --- | --- | --- | --- |
| 不连通图处理 | 外层循环枚举所有未染色节点 | 正确处理"图可能不连通"的题面条件——只从节点 0 搜一遍是本题最常见错误 | 归纳一句：**从哪里开始搜 = 所有未访问节点**，这正呼应本周复盘主线 |
| 入队即染色 | `color[v] = -color[u]` 后才入队 | 免去 visited 数组；若改为"出队时染色"会导致重复入队 | 意识到染色时点必须早于邻居枚举，这是"填值即标记"在颜色题上的形态 |
| 冲突判定位置 | 扩展邻居时发现同色立即返回 | 正确且早退；另一派写法是 DFS 返回布尔上传冲突 | 已达标 |
| 邻接表直接遍历 | 邻居来自 `graph[u]` 数组 | 正确：题目直接给邻接表，不需要额外建图 | 已达标 |

## 算法优缺点

| 方案 | 优点 | 缺点 | 适用情况 |
| --- | --- | --- | --- |
| 用户解法（BFS 染色） | 线性复杂度；迭代实现无爆栈风险；三态 color 简洁 | 无实质缺点 | 判二分图的标准写法 |
| DFS 染色 | 代码更短递归直白 | `n=100` 无爆栈风险，但递归风格在更大图上要谨慎 | 与 BFS 等价 |
| 并查集（把边两端并起来查冲突） | 一遍扫边即可；并查集脉络在第 12 周展开 | 需要额外结构，本题用染色更轻 | 第 12 周回头实现对照 |

## 最优解法

1. 三态 color：0 未染，1/-1 两色。
2. 外层枚举所有节点，未染色则 BFS 该连通分量：入队即染色。
3. 扩展邻居：未染色染反色入队；已染色与当前同色返回 false。
- 关键不变量：二分图 ⟺ 图中**无奇环** ⟺ 染色过程不出现相邻同色。无论起点染哪个颜色，判定结果不变（对应翻转整个分量）。
- 最优时间复杂度：`O(n + e)`
- 最优空间复杂度：`O(n)`

### 最优解代码

```cpp
class Solution {
public:
    bool isBipartite(vector<vector<int>>& graph) {
        int n = static_cast<int>(graph.size());
        vector<int> color(n, 0); // 0 = 未染色，1/-1 = 两个集合
        for (int i = 0; i < n; i++) {
            if (color[i] != 0) continue; // 已属于某个处理过的分量
            queue<int> q;
            color[i] = 1; // 起点染哪色不影响判定（整分量翻转等价）
            q.push(i);
            while (!q.empty()) {
                int u = q.front(); q.pop();
                for (int v : graph[u]) {
                    if (color[v] == 0) {
                        color[v] = -color[u]; // 入队即染色（填值即标记）
                        q.push(v);
                    } else if (color[v] == color[u]) {
                        return false; // 相邻同色 = 出现奇环
                    }
                }
            }
        }
        return true;
    }
};
```
