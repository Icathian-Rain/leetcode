- 难度：简单

- 资料来源：[LeetCode 中国版官方题目页](https://leetcode.cn/problems/find-the-town-judge/)，2026-11-23 查询
- 约束要点：`1 <= n <= 1000`；`trust` 互不相同且 `ai != bi`；法官条件为"出度 0 + 入度 n-1"且唯一

## 用户思路概述

1. 直接统计每人的入度 `inDig` 与出度 `outDig`（编号转 0 基）。
2. 找到同时满足 `inDig == n-1 && outDig == 0` 的唯一编号，返回 `i+1`；找不到返回 -1。

## 用户解法复杂度

- 时间复杂度：`O(n + t)`（t = trust 条数，一遍统计 + 一遍扫描）
- 空间复杂度：`O(n)`（两个度数数组）
- 复杂度来源：图不需要真正建出来——只统计度数即可回答，这是本题最轻的正解形态。

## 用户代码注释版

> 只在点评文档中展示加注释版本；不把这些注释写回 `src/*.cpp` 的用户原代码。

```cpp
class Solution {
public:
    int findJudge(int n, vector<vector<int>>& trust) {
        vector<int> inDig(n, 0), outDig(n, 0);
        for(auto t: trust) {
            int u=t[0]-1, v=t[1]-1;   // 编号转 0 基：u 信任 v ⇒ u 出度 +1、v 入度 +1
            outDig[u]++;
            inDig[v]++;
        }
        for(int i=0; i<n; i++) {
            if(inDig[i] == n-1 && outDig[i] == 0) {  // 法官两条件：全员信任我 + 我不信任人
                return i+1;
            }
        }
        return -1;

    }
};
```

## 关键理解点

| 理解点 | 用户当前表现 | 影响 | 建议 |
| --- | --- | --- | --- |
| 度数刻画 | 入度 + 出度两个数组 | 把"法官"的三个条件压缩成两个度数条件，题面到结构的翻译干净 | 归纳一句：**特殊节点的性质若能写成"边端点的计数"，就不需要图遍历** |
| 不建图 | 只有度数数组，无邻接表 | 空间与代码量都是最轻形态 | 对照 207/210：判断"点性质"只靠计数，判断"全局顺序"才需要邻接表 |
| 两条件缺一不可 | `n-1 && 0` 同时判 | 正确防止只满足一半的假法官（如环中人人入度 = 出度 > 0） | 想清只查入度会错在哪个反例：`n=3, trust=[[1,3],[2,3],[3,1]]`——3 入度 2 出度 1，漏查出度即误判 |
| 唯一性处理 | 找到即返回（首个即唯一的论证见下） | 正确：若两人都入度 n-1，则各自至少需要对方的一票，与二人出度 0 矛盾 | 能口头论证"满足条件者至多一人"——这是题目条件 3 被自动满足的原因 |

## 算法优缺点

| 方案 | 优点 | 缺点 | 适用情况 |
| --- | --- | --- | --- |
| 用户解法（出入度双计数） | `O(n+t)` 最优；不建图最轻 | 无 | 本题最优形态 |
| 单数组净度（`in - out` 合一） | 两个数组压成一个，扫一遍边 | 法官条件 `net == n-1` 与出度 0 不完全等价，需附加条件 | 想省一个数组时；直觉性弱一档 |
| 并查集/图遍历 | 不必要 | 过度设计 | 不适用于本题 |

净度法的正确形态：`score[v]++ / score[u]--`，法官判定为 `score[i] == n-1`。等价性成立（入度恰 n-1 且出度 0 时净度恰 n-1；出度 > 0 时净度 < n-1），但这个"等价"需要一步论证——双数组的直白正是它优于净度法的地方。

## 最优解法

1. 出度、入度两数组（或合一净度数组）。
2. 一遍 trust 做统计；一遍扫描找 `in == n-1 && out == 0` 唯一者。
- 关键不变量：入度 n-1 的人若不到 n-1 个信任来源则必缺票；满足两条件者至多一人（互票矛盾）。
- 最优时间复杂度：`O(n + t)`
- 最优空间复杂度：`O(n)`

### 最优解代码

```cpp
class Solution {
public:
    int findJudge(int n, vector<vector<int>>& trust) {
        vector<int> in(n, 0), out(n, 0);
        for (const auto& t : trust) {
            out[t[0] - 1]++; // t[0] 信任别人：出度
            in[t[1] - 1]++;  // t[1] 被信任：入度
        }
        for (int i = 0; i < n; i++) {
            // 法官：全员信任我（入度 n-1）且我不信任任何人（出度 0）
            if (in[i] == n - 1 && out[i] == 0) return i + 1;
        }
        return -1;
    }
};
```
