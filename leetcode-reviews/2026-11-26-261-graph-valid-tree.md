## 用户思路概述

1. 前置检查：`edges.size() != n-1` 直接返回 false——"恰 n-1 条边"是树的必要条件，先挡掉边数不符的两类反例。
2. 逐边加入：若两端已 `connected`（说明此边成环），立即返回 false。
3. 全部边无冲突加入后，n-1 条边、无环、且每条边都在当时合并了两个不同分量 ⟹ 恰好连通成单棵树，返回 true。

## 用户解法复杂度

- 时间复杂度：`O((n + E) · α(n))`，E ≤ n-1（被预检拦住超出的），即 `O(n·α(n))`
- 空间复杂度：`O(n)`
- 复杂度来源：一条反证最省的路径——两条判据合并使用：恰 n-1 条 + 逐边无冲突，免去了显式的"连通分量 == 1"终态检查。

## 正确性论证（本日核心复盘点）

- 树 ⟺ 连通 + 无环 + n-1 条边（三条中取二即得第三）。
- 用户解法实际用了"无环 + 恰 n-1 条边"两条：n-1 条边逐条加入且每条当时 unite 成功 ⟹ 无环且合并发生 n-1 次 ⟹ 分量数 = n - (n-1) = 1 ⟹ 连通。**第三条是推出的，不用查**。
- `edges.size() != n-1` 的预检不只是加速：没有它时，无环但边数 < n-1（森林不连通）会导致误判 true——预检是正确性必需，不是可有可无的剪枝。

## 用户代码注释版

```cpp
class UnionFind {
    // ...（fa/sz/cnt 三件套，同 684 文件，略）
};
class Solution {
public:
    bool validTree(int n, vector<vector<int>>& edges) {
        UnionFind uf(n);
        if(edges.size() != n-1) {
            return false;        // 边数 ≠ n-1：直接否（树的必要条件）
        }
        for(auto e: edges) {
            int x=e[0], y=e[1];
            if(uf.connected(x, y) == true) {
                return false;    // 同根再加边：成环
            }
            uf.unite(x, y);
        }
        return true;            // n-1 条边全部无冲突加入 = 连通且无环 = 树


    }
};
```

## 算法优缺点

| 方案 | 优点 | 缺点 | 适用情况 |
| --- | --- | --- | --- |
| 用户解法（预检 + 增量并查集） | 三判据两用一推，最省路径 | 无 | 本题标准解 |
| 判据二：n-1 条边 + BFS/DFS 查连通 | 同样两步 | 要建邻接表多一轮遍历 | 并查集不可用时 |
| 三判据各查一遍（边数 + BFS 连通 + DFS 找环） | 最直白 | 三轮扫描多余 | 不推荐——理解等价性后自然会省 |

## 最优解法

1. 边数 != n-1 返回 false（正确性必需）。
2. 逐边加入并查集：同根即 false。
3. 途中全过即 true。
- 关键不变量：成功合并次数 = n-1 ⟹ 终态分量数恰 1；无环由"每边当时合并两个不同分量"保证。
- 最优时间复杂度：`O(n · α(n))`
- 最优空间复杂度：`O(n)`

### 最优解代码

```cpp
class Solution {
public:
    bool validTree(int n, vector<vector<int>>& edges) {
        // 判据一：树必有恰 n-1 条边（少了不连通，多了必有环）
        if (edges.size() != static_cast<size_t>(n) - 1) return false;
        // 判据二：n-1 条边全部"当时合并两个不同分量"地加入
        // => 无环 + 分量数恰好归一（连通），两条同时成立
        vector<int> fa(n), sz(n, 1);
        iota(fa.begin(), fa.end(), 0);
        auto findIt = [&](int x) {
            while (fa[x] != x) {
                fa[x] = fa[fa[x]]; // 隔代压缩
                x = fa[x];
            }
            return x;
        };
        for (const auto& e : edges) {
            int rx = findIt(e[0]), ry = findIt(e[1]);
            if (rx == ry) return false;   // 成环：非树
            if (sz[rx] < sz[ry]) swap(rx, ry);
            fa[ry] = rx;
            sz[rx] += sz[ry];
        }
        return true;
    }
};
```
